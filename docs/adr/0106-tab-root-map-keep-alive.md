# ADR-0106 — 탭 루트 사이에서는 여정맵을 숨겨 둔다 (keep-alive)

- 상태: **채택.**
- 날짜: 2026-11-05.
- **사용자 결정**(2026-11-05): 「여정맵 안에서의 전환은 잘 되는데 네비게이션을 통한 화면 전환은 여전히 느리다」 → 탭 사이에서 여정맵을 지우지 않고 숨겨 두는 방식으로 진행(「진행」). 범위는 탭 루트끼리의 전환만.
- 다루는 축: 하단 네비게이션으로 탭 루트(여정 · 롤플레이 · 설정)를 오갈 때 여정맵을 지우는가 숨기는가, 숨긴 동안 막을 것.
  **다루지 않는 것**: 레슨 · 컷 화면에서 지도로 돌아올 때의 비용(지도 계산 줄이기 — 따로), 롤플레이 · 설정 화면의 keep-alive.

## 맥락

1. **기기 측정**(Galaxy A52s, ADR-0105 측정 빌드 + Lynx 엔진 로그 · `dumpsys gfxinfo`): 롤플레이 → 여정맵 탭 전환이 약 0.7 ~ 0.8초 — 탭 → 백그라운드 화면 계산 약 270 ms → 메인 스레드 요소 생성 · 레이아웃 약 320 ms → 후속 갱신 약 100 ms. 프레임 9개 중 6개 늦음(최대 150 ms), 레이아웃 노드 파괴 로그 3,012줄. 롤플레이로 갈 때는 약 0.28초.
2. 셸은 지금 화면 하나만 그린다(`renderScreen(screenNow)`) — 탭을 바꾸면 여정맵(18편 · 수백 노드)이 통째로 사라졌다가 돌아올 때 처음부터 다시 만들어진다. 50 ms 측정(`measureTask`)에는 렌더링이 잡히지 않아 보이지 않았다.

## 결정

### D1. 탭 루트끼리는 여정맵을 남긴다

- 지금 화면이 탭 루트(`journey-map` · `roleplay-list` · `settings`)이면 셸은 여정맵을 늘 그리고(`renderAppContent`), 여정이 아닌 탭은 그 위에 겹쳐 그린다.
- 여정이 아닐 때 여정맵 상자는 `visibility: hidden` · `user-interaction-enabled={false}` · `accessibility-elements-hidden`이다 — `display: none`이 아니라 레이아웃을 유지해, 숨긴 동안 받기가 끝나 지도가 바뀌어도 측정(발자국 · 스크롤)이 0이 되지 않는다.
- 탭 루트가 아닌 화면(레슨 · 컷 · 알림 · 설정 하위 화면 등)으로 가면 지금처럼 지운다 — 방금 끝낸 유닛 발자국 등장(ADR-0100) · 다음 유닛 자동 스크롤 · 첫 유닛 안내가 「다시 열림」에 기댄다.

### D2. 숨긴 동안 지도가 하지 않는 것 (`JourneyMapScreen` `active={false}`)

- 화면 겹침 신호(`useScreenLayer`) · 시스템 뒤로가기 가로채기(`useLayerBack`)를 하지 않는다.
- 자동 스크롤을 하지 않는다(잠금).
- 첫 유닛 안내(스크림 — 지도 안의 유일한 `position: fixed`)를 띄우지 않는다.
- 열린 말풍선은 숨겨질 때 닫는다.

## 대가

1. 다른 탭에 있는 동안에도 여정맵이 메모리에 남는다.
2. 다른 탭에서도 지도는 레이아웃을 유지한다 — 받기로 카탈로그가 바뀌면 숨긴 채로 다시 계산한다(지금도 지도 탭에서는 같은 일).
3. 여정 탭으로 돌아올 때 자동 스크롤이 다시 돌지 않는다 — 떠날 때의 자리 그대로다(지금은 이 실행의 마지막 자리를 복원하므로 사용자에게는 같다).
4. 지도 위에 서 있던 진행 불러오기 실패 줄은 돌아와도 스크린리더가 **다시 읽지 않는다**(전에는 다시 마운트되며 한 번 더 읽었다). 줄은 그대로 보이고 낭독 가림이 풀리면 다시 찾아 읽을 수 있다.
5. 기존 통합 테스트 가운데 「다른 탭에서 지도가 문서에 없다」 · 「돌아오면 다시 마운트된다」를 단언하던 11개를 숨김 · 그대로 남음으로 바꿨다(I5 · I11 · I12 포함).

## 테스트 계획

| 계층 | 적용 | 볼 것 |
|---|---|---|
| unit | 해당 없음 | 순수 판정은 「탭 루트인가」 하나라 ui에서 함께 본다 |
| ui | 적용 | 탭 루트별 그림(여정: 지도만 보임 / 롤플레이 · 설정: 지도 숨김 속성 + 그 탭) · 탭 루트가 아니면 지도 없음 · `active={false}` 지도가 겹침 신호 · 뒤로가기 · 자동 스크롤 · 안내를 하지 않음 · 숨겨질 때 말풍선 닫힘 |
| integration | 적용 | 앱에서 여정 → 롤플레이 → 여정: 지도 요소가 같은 요소로 남음(다시 만들지 않음) · 롤플레이 탭에서 시스템 뒤로가기가 숨긴 지도에 가로채이지 않음 |
| e2e | 해당 없음 | 기기 확인 — 같은 시나리오의 탭 전환 시간 |

## 측정

기기에서 롤플레이 → 여정 전환 시간(Lynx 엔진 로그 · 프레임 통계)을 이 변경 전후로 남긴다(성능 보고서).
