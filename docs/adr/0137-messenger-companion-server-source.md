# ADR-0137 — 메신저를 컴패니언 서버에 잇기 1~2단계 (서버 모드 출처)

- 상태: **채택 — 1~2단계.**
- 날짜: 2026-11-12.
- **사용자 결정**
  - 「ai 안달려잇나 정해진 답만하네」 → 1~2단계 진행.
  - 서버에 아직 안 붙는 기능은 앱 안에서만 둔다.
  - 시험 계정 크레딧은 지급하지 않는다.
  - 기기 확인 뒤 정한 것: 지문은 말풍선 없는 「*…*」 회색 기울임 줄로 · 내 글 뜻(🌐)은 없앤다 · 새 추천 답변은 판을 저절로 연다 · 덕수쌤 아바타(`ducksoo-casual`).
- 이어받는 결정
  - [ADR-0113](0113-messenger-chat-ui.md) 메신저 UI · [ADR-0117](0117-messenger-chat-turns-coins-new-friend.md) 1.5 · [ADR-0124](0124-chat-stream-native-sse.md) 호스트 SSE
  - [ADR-0125](0125-messenger-safety-ui.md) 고지 · 막힘 · [ADR-0128](0128-messenger-access.md) 시험 계정에게만 · [ADR-0129](0129-correction-card-and-rating.md) 교정 카드
  - 컴패니언 서버 [ADR-0131 ~ 0136](0134-companion-sse-streaming.md) · 통합 결정 4(인물 다섯 · 해금)

## 결정

### D1. 출처는 하나, 서버 모드는 덧붙임
- 가짜 출처(`createFixtureChatSource`)에 `remote` 포트(`ChatRemote` — 기록 · 첫 인사 · 턴)를 끼우면 서버 모드다.
- 서버로 가는 것: 방 목록(씨앗) · 기록 · 첫 인사 · 보내기 · 교정 · 추천 답변 · 고지 · 위기.
- 그 밖 기억 · 대화 설정 · 👍👎 · 다시 보내기 · 사진 · 음성 · 이야기 시점 · 방 지우기는 같은 출처가 앱 안에서만 한다(3단계에서 서버로).
- 결선: 로그인한 시험 계정이고 앱 진입점이 포트를 끼웠을 때만 서버 모드다(`setMessengerChatRemote`). 출처는 사용자 id마다 새로 만든다(계정 전환 · 시험 표시 변화). 테스트는 진입점을 지나지 않아 가짜다.

### D2. 인물 다섯은 앱 표
- 서버 목록에는 이름 · 아바타 · 해금이 없다 — `companion-roster.ts`가 진다(학습 내용 선언으로 한글 허용).
- 덕수쌤은 처음부터 연다. 정윤경 u02 · 미나 u03 · 한도윤 u04 · 서재민 u07 막간(INT)에서 연다 — 해금 표에 세 줄을 더했다.
- 이미 막간을 끝낸 계정은 기존 보정(ADR-0117 D3, `use-new-friend-backfill`)이 시트 없이 연다 — 해금 기록은 기기에 있어 출처를 새로 만들어도 남는다.
- 새 친구 시트는 서버 방이 열기 전엔 비어 있어 인물 표의 첫 말(`sheetOpening`)로 선다. 방을 열면 서버 인사가 온다(시트 말과 다를 수 있다).

### D3. 서버 JSON은 손으로 푼다
- 계약 패키지의 zod 스키마는 번들 상한 때문에 앱에 넣지 않는다 — 타입 · 판 번호만 맞춘다.
- `companion-parse.ts`가 푼다: 기록 · 인사 · 사전 오류 · 교정 카드(바뀐 범위는 앞뒤 같은 글자를 뺀 한 범위) · 칩(로마자 없음).
- `companion-turn.ts`는 SSE를 접는 리듀서다. 모르는 · 틀린 이벤트는 버린다.

### D4. 보이는 모양
- 캐릭터 말은 말풍선(segment)마다 하나다. 번역은 아래 줄.
- 행동 · 서술 지문은 말풍선 없이 「*…*」 회색 기울임 줄이다(새 메시지 갈래 `action`). 낭독은 별표를 뗀다.
- 서버 모드 방은 내 글 뜻(🌐)이 없다(`thread.origin === "server"`). 서버는 내 글 뜻을 주지 않는다.
- 새 추천 답변은 판을 저절로 연다 — 답 · 인사를 기다리던 중에 온 것만(방을 열며 읽은 기록은 아님), 방 설정 「보기 자동」을 따르고, 쓰던 글이 있거나 이미 열려 있으면 그대로 둔다. 서버 모드만이다(가짜 출처는 답마다 보기 묶음을 돌린다).
- 답을 기다리는 동안 보내기는 막힌다(서버는 한 번에 한 턴 — 409 `turn_in_progress`).
- 낭독: 방을 열며 읽은 기록은 읽지 않고, 답은 턴이 끝난 뒤 다 자란 말을 한 번씩 읽는다.
- 다시 보내기(교정 카드)는 서버 모드에서 단추가 없다 — 서버의 `replaces_message_id`에 잇는 것은 3단계.

### D5. 실패
- 일시 차단 · 이용 시간 상한 · 연령 제한 → 입력 줄 자리 안내(ADR-0125).
- 크레딧 부족 · 체험 소진 → 회색 줄 「크레딧이 없어요」.
- 그 인물과 대화할 수 없음(무료 등급은 체험 인물만 — 서버 판정) → 「아직 대화할 수 없어요」. 첫 인사가 이 까닭이면 빈 방 대신 같은 줄.
- 그 밖 → 「보내지 못했어요」. 5개 언어.

## 버린 대안
1. **계약 패키지의 zod 디코더를 그대로 씀** — 번들 상한을 크게 넘는다. 손 해석기 + 같은 모양의 단위 테스트로 갈음.
2. **서버 출처를 새로 따로 만듦** — 앱 안에서만 둘 기능(기억 · 설정 · 평가 · 미디어)을 다시 짜야 한다. 1~2단계는 덧붙임으로.
3. **행동을 말풍선에 괄호로** — 대사와 섞여 구분이 안 됐다(기기 확인).

## 대가
- 목록 미리보기는 방을 한 번 연 뒤에만 서버 글이다.
- 손 해석기는 계약 패키지 스키마와 자동 대조하지 않는다 — 계약 판(`contract_version` 1)이 바뀌면 손으로 맞춘다.
- 무료 등급 시험 계정은 덕수쌤(체험 20통)만 대화된다(지금 서버 정책). 다른 인물은 결제 등급 · 크레딧이 있어야 한다.
- 번들 +38.4 kB(상한 4,642,000).
