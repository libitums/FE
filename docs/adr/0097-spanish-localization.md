# ADR-0097 — 스페인어를 셋째 다른 UI 언어로 연다

- 상태: **채택 — 클라이언트 + 콘텐츠.** 서버 코드 변경 0. 콘텐츠 수준은 올리지 않는다. 글꼴 · 호스트 글꼴 파일 변경 0.
- 날짜: 2026-11-04.
- **사용자 결정**(2026-11-04): 「스페인어 추가 작업 및 내장본 반영하고 레이아웃 검수까지」.
- 다루는 축: [ADR-0091](0091-vietnamese-localization.md) · [ADR-0093](0093-indonesian-localization.md)의 구조(문구표 · 콘텐츠 번역표)에 셋째 언어를 더하고, 내장 에피소드 · 버킷 수준 3 묶음에 번역표를 싣는 것. 구조 자체는 바꾸지 않는다.
  **다루지 않는 것**: 언어별 번역 파일 분리(아래 「재검토 조건」), 스토어 등록 정보, 랜딩.

## 결정

### D1. 언어 코드는 `es`, 목록 자리는 그대로(인도네시아어 다음)

- `isEntryLanguageAvailable("es") === true`. 목록 `en · vi · id · es · ja`와 라벨 `Spanish` · 국기는 이미 있었다(2026-09-21 디자인).
- 기기 태그는 나라 · 지역과 상관없이 `es`다(`es-ES` · `es-419` · `es-MX` …).

### D2. 콘텐츠 번역표에 `translations.es`를 받는다

- `ContentLanguage` = `vi | id | es`. 정규화 규칙은 ADR-0091 D1 그대로(틀린 항목만 빼고 `invalid-translation` 경고 하나). `localizeEpisode`는 언어 표를 이름으로 찾으므로 바뀌지 않는다.
- **내장 u00 ~ u10**에 `translations.es`(그 편의 `vi` 표와 같은 키)를 싣고 내장 목록의 sha256 · bytes를 다시 계산한다(판 번호는 그대로 — #357과 같다).
- **버킷 수준 3 묶음(u00 ~ u13)** 에도 싣는다. 버킷 판(2026-11-03.1)이 내장본(2026-10-30.1)보다 높아 온라인 사용자는 버킷 판을 쓰므로, 내장본만으로는 스페인어 콘텐츠가 보이지 않는다. 판은 `2026-11-04.1`. 업로드는 사람이 한다.

### D3. 문구표 `es`는 영어와 같은 모양의 완전한 표다(번역 초안)

- `uiCopyEs: UiCopy` — 구획 파일 `ui-copy-es-*.ts`. 파일 머리에 「원어민 검수 필요」.
- 중립 중남미 스페인어, 학습자에게는 **`tú`**(앱의 영어 톤). 이야기 속 점원 · 주인이 손님에게 하는 존댓말(한국어 `-세요` · `-시-`)은 `usted`로 옮긴다.
- 학습자의 성별을 모르므로 학습자를 가리키는 형용사는 성별 없는 표현으로 바꾼다(「새로 오셨나 봐요?」 → 「¿Acabas de llegar?」). 이야기가 성별을 정한 인물(u12 주인공 등)은 따른다.

### D4. 글꼴은 바꾸지 않는다

- Jost · League Spartan이 `á é í ó ú ü ñ ¿ ¡`와 대문자를 모두 가진다(fontTools로 확인).

## 테스트 계획

| 계층 | 무엇 |
|---|---|
| unit (episode-core) | TR8: `translations.es` 정규화 |
| unit (app) | EL4(고를 수 있는 넷), UL5d(`es` · `es-ES` · `es-419` · `es-MX`), LZ7(`es` 표 적용 · 없으면 같은 객체), ES1 ~ ES3(문구표 완전성 · 번역 비율), UC4(문구표 키 집합) |
| integration | 스페인어 사용자가 내장 콘텐츠를 번역으로 본다 · 설정 › Language에서 스페인어를 고르면 바로 바뀌고 저장된다 |
| 콘텐츠 | 내장 11편 · 버킷 14편이 지금 앱 코드로 열리고 sha256이 목록과 맞으며 번역표 경고 0. 모든 번역에서 한글 · `{자리표시}` · 줄바꿈 보존 |
| 레이아웃 | 스페인어는 영어보다 길다 — Android 에뮬레이터에서 진입 · 지도 · 레슨 · 결과 · 설정 화면의 잘림 · 넘침을 본다 |

## 대가

- 번들 + 스페인어 문구표 · 내장 번역표(성능 보고서 `es-localization-01`). 콘텐츠 번역표는 버킷 파일에 실려 다른 언어 사용자도 함께 받는다.
- 번역은 초안이다(검수용 표: 업로드 묶음의 `검수용-스페인어-번역표.csv`).

## 재검토 조건

- **ADR-0093의 재검토 조건(「언어가 셋 이상이 되면 번역표를 언어별 파일로」)에 닿았다.** 이번에는 사용자 결정대로 지금 구조로 싣고, 분리는 ADR-0094(번역 파일 분리 — 초안, 아직 병합 전)에서 따로 정한다 — 에피소드 하나에 번역표 셋(편마다 약 30 KB)이 실린다.

## 적용 기록

- ⟨2026-11-04⟩ **레이아웃 검수**(iOS 시뮬레이터 iPhone 17 Pro, 에이전트 실행 · 사람 미확인): 언어 선택(미리보기 카드) · 설정 · 프로필 · 이름과 나라 · 알림 · 여정맵 · 스텝 말풍선 · 레슨(듣기 · 단어 고르기 · 빈칸 · 음절 조립 · 문장 순서 · 새 단어 카드) · 정답 배지 · 나가기 대화 상자 · 결과 화면 · 롤플레이 목록 · 온보딩 세 장 · 로그인(저장 언어 `es`인 새 기기). **잘림 · 넘침 없음.** 두 줄로 감기는 지시문(「¿Qué palabra corresponde a la imagen?」)도 가운데 정렬로 선다.
  - 콘텐츠 문장(문항 지시문 · 에피소드 제목 · 롤플레이 제목 · 이름과 나라 예문)은 **버킷 판(2026-11-03.1, 스페인어 표 없음)이 내장본을 이겨 영어**였다 — 업로드 묶음을 올리면 바뀐다. 내장본을 쓰는 튜토리얼(같은 판)에서는 「Hola」 · 「¿Qué escuchaste?」 · 「Completa el espacio en blanco.」처럼 스페인어가 화면까지 닿았다.
  - 기존 상태(이번 범위 밖): 결과 화면 등급 「AMAZING」은 화면 상수라 모든 언어에서 영어, 언어 · 나라 이름(`Spanish` · `South Korea`)은 번역하지 않는다, 로그인 전 진입 흐름은 저장 언어가 없으면 영어다(기기 언어 경로 없음).
