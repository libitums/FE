# ADR-0115 — 무제한 티켓 표시: 주황 칩 · 결과 화면 알약 · 무제한 모달 (시험 계정만 결선)

- 상태: **채택 — 클라이언트.** 서버 · 호스트 · 분석 이벤트 · 토큰 패키지 변경 0.
  ⚠ **기기 확인이 아직 없다** — [무제한 티켓 e2e](../e2e/unlimited-ticket.md) UT-E1 ~ E5 · UT-A1 ~ A9는 실행된 회차가 없다.
- 날짜: 2026-11-09.
- **사용자 발화 · 결정**(2026-11-09): 「무제한 티켓 추후 요금제로 추가할 예정이라 디자인을 좀 고급지게 바꿔야할 거 같은데」 → 시안 페이지에서 금색 넷(A~D)을 본 뒤 「**주황색 형태로** 좀 더 개선해보자」 → 주황 셋(O1~O3) 가운데 **O1 입체 주황 면**, 빛 훑기 **몇 초마다 반복**, 결과 화면 **줄도 바꿈**, 모달 **세 상태를 다 만들고 시험 계정만 결선** · 곧 끝남은 다시 그린 둘(링 · 기록)보다 「**원래 판**」. 시안: https://claude.ai/artifact/E155HMiarc3cQQdNvNwRvB (v6).
- 다루는 축: 무제한 티켓이 일반 티켓과 다르게 「값진 상태」로 보이는 방법 — 칩 · 결과 화면 · 칩을 누르면 뜨는 모달.
  **다루지 않는 것**: 결제 · 구독 상태 데이터와 스토어 연동, 설정 「내 요금제」 화면(구매 복원), 맵 말풍선의 티켓 태그, 요금제 이름.

## 결정

### D1. 무제한 칩은 「입체 주황 면」이다 — 숫자 대신 그린 무한 기호

- `components/UnlimitedTicketChip.tsx`. 크기 · 여백은 지표 칩(`stat-chip`)과 같고 면만 `#FFC07A → brand-secondary → #E2560A` 그라데이션, 위쪽 빛 · 아래 짙은 단 · 안쪽 흰 테. 흰 티켓 아이콘 + 흰 무한 기호(`components/infinity-icon.ts`, 선 그림). 글자 「∞」는 쓰지 않는다 — Jost에서 가늘고 작게 찍혔다.
- 머리 바(높이 44, 그림자)와 결과 화면(높이 40, 그림자 없음)이 같은 컴포넌트를 쓴다. `StatChip.valueText`는 지웠다.
- 빛 훑기: 4200 ms 주기 가운데 앞 약 600 ms 동안 흰 띠가 지나간다(`unlimited-ticket-chip-motion.css`, `lint:motion` allowlist). 움직임 줄이기에서는 띠 요소가 서지 않는다.

### D2. 결과 화면은 「티켓을 쓰지 않았다」를 한 번 더 말한다

- 「N tickets left」 줄 자리(같은 여백)에 `LessonCompleteUnlimitedLine` — 연주황 알약 · 주황 무한 기호 · 「No ticket used · Unlimited」.
- 「Next lesson」 · 「Final test」 버튼의 티켓 태그는 무제한이면 숫자 1 대신 흰 무한 기호, 낭독 「Next lesson. No ticket needed」. 비용 값이 `0 | 1 | "unlimited"`가 되었다(`catalogResultNextOf`가 시험 계정이면 `"unlimited"`). 무제한이면 이미 끝낸 유닛을 다시 여는 경우에도 무한 기호다([추론] — 시험 계정은 비용 계산이 이미 0이라 「원래 1장 들 유닛」을 가르지 않는다).

### D3. 칩을 누르면 무제한 모달 — 상태는 순수 함수가 정한다

- 입력 `UnlimitedPass` = `{ kind: "guest" }` | `{ kind: "subscription", startedAtMs, endsAtMs, autoRenews, planLabel? }`. `unlimitedPassView(pass, now)`가 넷 가운데 하나로 바꾼다(`lib/unlimited-pass.ts`):

| 모양 | 조건 | 모달 |
|---|---|---|
| `guest` | 시험 계정 | 「GUEST PASS」 알약 · 「Every lesson and roleplay is open on this account.」 · 「Got it」(닫기) |
| `renews` | 자동 갱신 | 요금제 알약(이름이 있을 때 — 단색 fg-brand 면, 흰 글자 5.46:1) · 「Renews on」 + 날짜 · 「Member since」 · 「Manage subscription」 |
| `ends` | 갱신 꺼짐 · 남은 날 > 7 | 「Ends on」 + 날짜 · 「Manage subscription」 |
| `ending-soon` | 갱신 꺼짐 · 남은 날(올림) ≤ 7, 끝난 뒤 포함(0일) | 노랑 「N days left」 · 「Ends <날짜>」 · 「N of M days」 · 남은 비율 막대 · 「Keep unlimited」 + 「Manage subscription」 링크 |

- 뼈대는 티켓 모달(`TicketStatModal`)과 같다 — 짙은 막 · 뒤로 · 큰 값 · 제목 · 아래 · 문구 · 버튼. 큰 값은 주황 무한 기호(단색 — SVG 그라데이션 렌더를 확인하지 않았다), 뒤에 정적인 주황 원형 번짐.
- 날짜는 기기 지역 시간의 달력 날짜이고 언어별 문구 함수가 쓴다(`unlimitedModal.date` · `shortDate`).

### D4. 결선은 시험 계정 하나다

- `AppHeader`의 `ticketsUnlimited: boolean`을 `unlimitedPass?: UnlimitedPass`로 바꿨다. `AppSession`이 `testerAccess ? guestUnlimitedPass : undefined`를 넘긴다. 있으면 칩이 무제한 칩이고, 누르면 레이어 `"unlimited"` → `UnlimitedTicketModal`. 없으면 지금 티켓 모달 그대로.
- 구독 판의 두 콜백(`onManageSubscription` · `onKeepUnlimited`)은 받되 아무도 넘기지 않는다 — 결제가 붙을 때 이 자리에 `subscription` 상태와 함께 들어온다.
- 이것은 [ADR-0085](0085-tester-access.md) D3의 「누를 수 없음(모달을 열지 않음)」을 바꾼다(그쪽 개정 기록).

## 근거

- 일반 칩과 갈리는 것이 글자 하나뿐이면 돈을 낸 상태라는 느낌이 나지 않는다. 금색은 앱 팔레트 밖이라 주황 안에서 「켜진」 모양을 만들었고, 납작한 주황 버튼과는 위쪽 빛 · 흰 테 · 그라데이션으로 가른다.
- 모달 진입점을 새로 만들지 않고 티켓 칩을 그대로 쓴다 — 사용자의 질문(「내 티켓 상태」)이 같고 답만 「몇 장」에서 「언제까지」로 바뀐다.
- 버린 대안: 금색 테두리 · 블랙 패스 · 골드 면(팔레트 밖) · O2 테두리만(덜 특별함) · O3 「PLUS」 라벨(이름 미정 · 칩이 넓어짐) · 곧 끝남의 링 + 전후 비교 · 기록 + 남은 날 칸(사용자가 원래 판을 고름).

## 대가

1. 새 리터럴 색 둘(#FFC07A · #E2560A) — 토큰 패키지에 맞는 단계가 없다. 무제한 칩만 쓴다(모달 요금제 알약은 접근성 회차에서 단색 fg-brand로 바꿨다).
2. 끝없이 도는 빛 훑기는 WCAG 2.2.2(레벨 A — 5초 넘게 움직이는 것은 멈출 수 있어야 한다)에 미달한다. 앱 안에서 멈출 수단은 없고 OS 움직임 줄이기로만 꺼진다 — 대가 6의 사용자 결정으로 수용했다.
3. 무제한 칩이 숫자 칩보다 약 10px 넓다(아이콘 둘). 작은 기기 머리 줄 폭은 기기에서 본다(UT-E1).
4. 구독 판은 테스트만 있고 실제로 그려지는 일이 없다 — 결제가 붙을 때까지 죽은 갈래다.
5. 다섯 언어 문구는 번역 초안이다(원어민 검수 전).
6. ⟨접근성 점검 2026-11-09⟩ 칩 그라데이션 밝은 쪽에서 흰 아이콘 대비가 1.3 ~ 2.8:1로 비텍스트 3:1(1.4.11)에 못 미친다(지적 M1). 칩에 글자가 없어 아이콘이 유일한 단서다. **사용자 결정(2026-11-09, 기기에서 본 뒤): 「잘 보이는 거 같아서 둘 다 유지」** — 칩 색(권고 `#F46B18 → #E2560A → #B94208` · 위쪽 빛 0.12 이하를 채택하지 않음)과 빛 훑기 무한 반복(지적 M2 — 권고 「한 번 5초 이하 재생 후 멈춤」을 채택하지 않음)을 그대로 둔다. 1.4.11 · 2.2.2 미달을 **수용한 부채**다 — 저시력 사용자 불만이나 심사 지적이 오면 권고안으로 바꾼다.
7. 머리 모달이 떠 있어도 뒤의 화면(맵 노드)이 보조기술에 노출되는 기존 결함(지적 M4 — 연속 · 트로피 · 티켓 모달 공통, ADR-0016 D9)을 이 변경이 고치지 않는다. 시험 계정 칩이 버튼이 되어 들어오는 길이 하나 늘었다. 「Next lesson」 태그의 흰 아이콘 2.39:1(지적 m1)도 일반 계정 「1」 태그와 같은 기존 값이다. 둘 다 후속.

## 재검토 조건

- 요금제 · 결제가 붙을 때 — `subscription` 상태의 출처(스토어 영수증 · 서버)와 두 콜백의 행선지를 정하고, 설정 「내 요금제」 화면을 함께 연다.
- 요금제 이름이 정해질 때 — 칩에 이름 라벨(O3)을 붙일지 다시 본다.
- 기기에서 무한 기호 선 그림 · 그라데이션이 어긋나면 그림을 채운 모양으로 바꾼다.
