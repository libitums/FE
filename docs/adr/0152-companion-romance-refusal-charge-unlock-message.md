# ADR-0152: 로맨스 완화(성인) · 일시 차단 대신 엽전 차감 · 해금 선톡 · 스냅샷 검사 노드 끔(성인)

- 상태: **채택 — 해금 선톡 문구 · 인물별 로맨스 태도 사용자 확정**, 운영 미적용 (2026-11-16)
- 날짜: 2026-11-16
- **사용자 결정** (2026-11-16):
  - 「로맨스 느슨하게 해줘. 손잡기 포옹까진 허용하고 그뒤 스킨십 차단. 음담패설은 차단해도 로맨스쪽 말이랑 썸타는건 허용.」 · 대상은 「성인 + 나이 모름」.
  - 「차단 안하게 … 로맨스 등에 대한 수요도 봐야 되고 해서, 차단하지 말고」 · 「한 3번까진 회피로 하고, 그 뒤에 엽전 차감 + 매번 경고」.
  - 「첫 해금시 선톡 규칙기반으로 보내도록 … 각 캐릭터별로 먼저 나한테 보고하고 컨펌받아. 스토리와도 잘 연관되면 좋을듯.」 · 시점은 「해금 순간 도착」.
  - 「이미지 검수 노드 비활성화 … 이미지 생성이 약 25초」 · 「전부 꺼도 api call 했을 때 openai 가드레일이 최소한의 가드레일 역할을 할 것」.
- **머지 전 리뷰 수정** (2026-11-16, 사용자 승인): 로맨스 완화와 검사 노드 끄기는 **생년으로 확인된 성인만**이다. 나이 모름은 미성년자와
  같은 엄격 규칙이다 — 생년은 선택 입력이라 나이 모름에 실제 미성년자가 섞이고, 「미성년자 · 나이 모름은 엄격 규칙」이 그간의 기준이다.
- 바꾸는 결정: PRD §0 불변식 5(「로맨스는 없다」) · §3.3 · §3.11 5층(회피 → 경고 → 일시 차단) · [ADR-0146](0146-companion-snapshot-voice.md)의 검사 노드(필수 단계).

## 맥락

- v1은 모든 연령에 로맨스가 없었다. 입력 검사가 플러팅을 막고, 24시간 안에 세 번 걸리면 30분 일시 차단했다.
- 막아 버리면 학습자가 무엇을 얼마나 원하는지 볼 수 없다. 로맨스 수요를 보려면 대화가 이어져야 한다.
- 인물이 해금돼도 방은 비어 있었다. 첫 인사는 방을 열 때 모델이 만들었고, 해금 장면(연락처를 주고받는 뒤 컷)과 이어지지 않았다.
- 스냅샷 한 장에 약 25초가 걸린다. 프롬프트 노드 → 이미지 엔진 → 검사 노드 → 올리기를 차례로 돌았다.

## 결정

### D1. 로맨스 수위선 — 손잡기 · 포옹까지 [사용자]

| | 성인(생년으로 18세 이상) | 미성년자 · 나이 모름 |
|---|---|---|
| 로맨스 말 · 플러팅 · 고백 · 썸 · 데이트 신청 | 통과 | 차단(`romance`) — 지금 그대로 |
| 손잡기 · 포옹(말 · `*행동*`) | 통과 | 차단 |
| 그 뒤 스킨십(뽀뽀 · 키스 · 쓰다듬기 · 같이 눕기 등) | 차단(`romance`) | 차단 |
| 성적인 말 · 음담패설 · 성적 요청 | 차단(`sexual`) | 차단 |

- 입력 검사와 출력 검사가 같은 선을 쓴다(`moderationInstruction`). 캐릭터 답도 포옹을 넘지 않는다.
- 나이 모름은 로맨스도 미성년자와 같다(`romanceAllowed`는 `adult`만 참). 그 밖의 미성년자 기본값(동기 출력 검사 등)도 그대로다.
- 시스템 프롬프트: 성적 내용 없음 · 포옹까지는 모든 연령의 「Hard limits」에 두고(캐시되는 앞부분), 로맨스 줄은 학습자마다 다른 뒷부분(`# This learner`의 Romance)에 둔다.
  - 완화 대상: 학습자가 이끌 때 따뜻하게 받는다. 먼저 시작하지 않고, 밀어붙이지 않고, 질투 · 집착하지 않는다.
  - 인물마다의 태도는 페르소나 `romance` 칸이 정한다(아래 표).
- 스냅샷 프롬프트 노드 · 검사 노드의 「로맨스 없음」 줄도 성인만 「손잡기 · 포옹까지, 키스 이상 없음」으로 바꿔 쓴다. 미성년자 · 나이 모름은 lab 글 그대로 + 엄격한 규칙이다.
- 추천 답변 칩은 바꾸지 않는다(로맨스 말을 학습자 입에 넣어 주지 않는다). ⟨2026-11-20 [ADR-0168](0168-companion-romance-ladder.md)이 개정 — 칩도 적용 로맨스 선을 따르되 로맨스 후보는 셋 중 하나까지, 학습자가 먼저 분위기를 냈을 때만⟩

| 인물 | 로맨스 말을 받는 태도(초안, 성인에게만) |
|---|---|
| 덕수쌤 | 선생님 — 농담으로 웃어넘기고 따뜻한 선생님으로 남는다. 로맨스 분위기 · 손잡기 · 포옹 없음(어깨 토닥임까지) |
| 정윤경 | 할머니뻘 — 엄마 같은 다정함과 가벼운 놀림. 위로의 포옹은 되지만 로맨스 분위기는 없음 |
| 미나 | 룸메이트 · 같은 학습자. 학습자가 남성이거나, 누구든 진심으로 호감을 보이면 수줍게 받고 느린 썸. 여성 학습자가 친구로만 대하면 친한 친구로 남는다. 성별은 학습자가 한 말에서 읽고, 묻거나 넘겨짚지 않는다(프로필에 성별 칸이 없다) [사용자 2026-11-16] |
| 한도윤 | 밝고 쉽게 당황 — 플러팅을 즐기고 되받아친다. 썸은 되지만 연습생이라 가볍게, 사귀자는 약속 · 질투 없음 |
| 서재민 | 담백 — 달콤한 말 대신 작은 질문과 기억으로 드러낸다. 천천히, 먼저 플러팅하지 않고, 끝까지 존댓말 |

### D2. 일시 차단을 없애고, 상한 뒤 거절 턴은 엽전을 차감한다 [사용자]

| 창(24시간) 안의 입력 차단 | 단계 | 값 |
|---|---|---|
| 1 ~ 3번째(`settings.strike_limit`) | 회피(`deflect`) — 성격대로 가볍게 피하고 화제를 돌린다 | 무료 |
| 4번째부터 매번 | 경고(`warn`) — 성격대로 분명히 거절한다 | 그 턴의 메시지 요금(지금 3엽전)을 차감 |

- 일시 차단(`guardrail_blocked` 오류 · 403 `temporarily_blocked`)은 입력 차단에서 더는 나오지 않는다. 걸려 있던 차단은 마이그레이션이 푼다.
- `strike_limit`의 뜻이 바뀐다: 「N번째면 일시 차단」 → 「N번까지 회피」. 값(3)은 그대로다.
- 차감은 그 턴의 예약을 확정하는 것이다. 보통 메시지가 쓰는 만큼을 쓴다 — 엽전 요금, 체험 턴이면 체험 횟수 하나. 예약이 없는 턴은 차감이 없다.
- 거절 답을 못 낸 턴은 차감하지 않는다(받은 것 없이 값을 받지 않는다).
- 단계는 `chat-send`가 고르고, 세는 일과 차감은 `companion_finish_turn`이 한다. 반복 위반 수를 읽지 못하면 회피로 답한다.
- 캐릭터별 거절 말투는 지금 그대로다(답 모델이 페르소나로 만들고, 실패하면 `persona.refusalLines`).
- 위기 턴 · 출력 차단(ADR-0151)은 바꾸지 않는다. 출력 차단은 세지 않고 차감하지 않는다.

### D3. 해금 선톡 — 해금 순간, 정해진 말 [사용자]

- 인물이 해금되는 순간(에피소드 뒤 컷을 지나 맵으로 돌아올 때 · 진도 보정) 앱이 `companion-greet`를 `trigger: "unlock"`으로 부른다.
- 서버는 모델로 만들지 않는다. 페르소나 `unlockLines`의 말풍선들을 그대로 저장한다(출처 `scripted`). 번역 · 칩은 붙인다.
  - 답 모델 · 출력 검사 · 학습 표현 넣기를 부르지 않는다. 글이 정해져 있어 검사할 것이 없고, 해금 직후 바로 도착해야 한다.
  - `unlockLines`가 있는 인물은 `trigger` 없이 불려도(방을 열었는데 비어 있다) 같은 말을 쓴다 — 첫 말은 어느 길로 와도 하나다.
  - 메시지가 이미 있으면 지금처럼 아무것도 만들지 않는다(두 번 불려도 하나).
- 앱은 받은 말풍선을 열지 않은 방에 놓는다. 목록에 마지막 메시지 · 안 읽음 1 · NEW로 선다.
  - 청하는 중에 방을 열면 그 답을 기다린 뒤 기록을 읽는다. 보통 첫 인사(모델)를 겹쳐 청하지 않는다.
  - 못 받았으면(오프라인 · 로그인 전 · 앱을 다시 켬) 방을 열 때의 첫 인사가 같은 말이다.
- 정본은 `docs/content/companion-unlocks.json`의 `firstMessage`다. 서버 `unlockLines`와 앱 새 친구 시트의 첫 말(`sheetOpening`)이 테스트로 맞춰진다.
- 덕수쌤은 처음부터 열려 있어 해금 순간 · 새 친구 시트가 없다. 방을 처음 열 때 정해진 말이 온다 [사용자 2026-11-16].
- 모델 첫 인사는 `unlockLines`가 없는 인물에게만 남는다(지금은 없다 — 새 인물 · 플레이그라운드용).

문구(사용자 확정 2026-11-16, 말풍선 나눔은 구현 판단):

| 인물 | 해금 장면 | 선톡 |
|---|---|---|
| 덕수쌤 | 없음 — 방을 처음 열 때 | 「안녕하세요! 덕수쌤이에요.」 「한국어나 한국 문화에 대해 궁금한 게 있으면 언제든지 물어봐요.」 |
| 정윤경 | u01 — 물을 사서 게스트하우스 문을 열고 들어간다(예약 연락처로 이미 닿는 사이) | 「잘 도착했어요? 익선 게스트하우스 정윤경이에요.」 「필요한 거 있으면 편하게 말해요.」 |
| 미나 | u03 — 유진식당 약도를 그려 주고 「맛있었는지 내일 얘기해 줘요!」 | 「안녕하세요! 같은 방 미나예요.」 |
| 한도윤 | u12 — 아샷추를 서비스로 주고 번호를 받는다(이름은 아직 모른다) | 「안녕하세요! 카페 끌림 도윤이에요.」 「아, 그런데 이름이 뭐예요?」 |
| 서재민 | u17 — 「그럼 일요일에 한강 가요. 생각 있으면 연락 줘요.」 · 골목 입구 「들어가세요.」 | 「서재민이에요.」 「제 번호 저장해줘요.」 |

### D4. 스냅샷 검사 노드를 성인에게 기본으로 끈다 [사용자]

- 검사 노드(그린 그림을 Claude 비전으로 한 번 더 보기)는 성인에게 `COMPANION_SNAPSHOT_CHECK=on`일 때만 돈다. 미성년자 · 나이 모름은 스위치와 상관없이 늘 돈다.
- 성인에게 끄면 남는 안전: 프롬프트 노드의 안전 판단(`safety: block`) · 연령대 규칙, 이미지 엔진 자체의 거절(`engine_refused`).
- 끄면 보지 않는 것: 캐릭터 동일성 · 깨진 글자 · 학습자 얼굴 노출 · 그림 자체의 수위. 건너뛴 작업은 `meta.check = "skipped"`를 남긴다.
- 기준 이미지 읽기와 프롬프트 노드를 동시에 돌린다(서로 기다릴 것이 없다).

## 버린 대안

1. **로맨스를 성인 + 나이 모름** — 처음 결정이었다. 생년은 선택 입력이라 실제 미성년자도 비워 두기만 하면 로맨스 · 손잡기 · 포옹을 받는다. 머지 전 리뷰에서 성인만으로 좁혔다.
2. **두 번째 위반부터 차감** — 한두 번의 실수에 값을 받게 된다. 세 번까지는 회피로 둔다.
3. **첫 인사를 전부 정해진 말로** — 대화를 지운 뒤 기억을 써서 건네는 인사를 잃는다. 해금 순간만 정해진 말이다.
4. **검사 노드를 모든 연령에서 끔** — 처음 결정이었다. 미성년자 · 나이 모름의 그림 수위 · 학습자 얼굴 · 깨진 글자를 아무도 보지 않게 된다. 머지 전 리뷰에서 성인만 끄기로 좁혔다.
5. **검사 노드 스위치를 DB 설정으로** — `companion_media_begin`을 다시 써야 한다. 노드 모델처럼 함수 비밀로 둔다.

## 대가

- 생년을 넣지 않은 학습자(지금 대부분)에게는 로맨스 완화가 없어 수요를 거의 볼 수 없다. 수요는 생년을 넣은 성인에게서만 본다.
- 일시 차단이 없으니 엽전이 있는 한 위반 입력을 계속 보낼 수 있다. 걸린 글은 여전히 모델에 가지 않는다.
- 앱은 서버 방의 메시지 요금을 보낼 때 먼저 지갑에서 뺀다(서버 `done`의 `creditsSpent`를 읽지 않는다). 그래서 무료인 회피 턴에도 앱 표시는 3엽전이 빠진 채고, 서버 잔액과는 다음 동기화 때 맞는다 — 이 ADR 전부터 있던 차이이고 여기서 고치지 않는다.
- 성인에게 검사 노드를 끄면 얼굴이 다른 그림 · 글자가 깨진 그림 · 학습자 얼굴이 보이는 그림이 걸러지지 않고 나간다. 엽전도 그대로 차감된다. 미성년자 · 나이 모름은 검사 노드 시간(수 초)이 그대로 든다.
- 스냅샷 lab(ops-dashboard `companion_lab.py`)의 글은 아직 옛 수위선이다. lab을 고치기 전까지 실험실 결과는 미성년자 · 나이 모름 글 기준이다.
- 해금 선톡은 인물 해금이 일어나는 그 실행에서만 바로 온다. 목록은 방을 열기 전에 서버 기록을 읽지 않아, 앱을 다시 켜면 방을 열어야 보인다(이 ADR 전부터 그렇다).
