# ADR-0089 — 끝낸 에피소드가 업데이트되면 지도에서 한 번 알린다

- 상태: **채택 — 클라이언트.** 서버 · 호스트 변경 0. 기기 저장소에 키 하나를 더한다.
- 날짜: 2026-10-28.
- **사용자 결정**(2026-10-28): 시안 G-A(가운데 대화상자)로 간다. 대화상자는 어느 에피소드 · 무엇이 바뀌었는지 적지 않는다(바뀐 곳이 여럿일 수 있어 「데려가기」도 없다). 문구는 가볍게 — 「Psst, something new! 👀」 · 「Cool, got it」. 「Don't show this again」 체크를 둔다. ⟨2026-10-28⟩ 지도의 NEW 태그는 빼기로 했다 — 본문도 「…your progress is safe.」에서 끝난다.
- 다루는 축: 이미 끝낸 에피소드에 콘텐츠 업데이트로 새 유닛(레슨 · 문화 · 막간 이야기)이 생겼을 때 — 판정, 안내를 띄우는 때, 기록.
  **다루지 않는 것**: 지도의 새 유닛 표시(NEW 태그 — 사용자 결정으로 뺌), 설정에서 안내 다시 켜기, 분석 이벤트, 체크 행의 ui-lynx 컴포넌트화.

## 결정

### D1. 「바뀐 에피소드」는 최종 테스트를 끝냈는데 안 끝낸 유닛이 남은 에피소드다 — 버전을 들지 않는다

- 유닛은 순서대로만 열리고 최종 테스트가 사슬의 끝이다(`catalogUnitStatus`). 그래서 최종을 끝낸 에피소드에 남은 안 끝낸 유닛은 끝낸 뒤 콘텐츠가 바뀌어 생긴 것이다(`screens/journey-map/catalog-update.ts` `catalogFreshUnitKeysOf`).
- **완료 키(`completionKeys`)로 보지 않는다.** 완료 키가 레슨 전체인 에피소드(u00)는 새 유닛이 생기면 완료가 풀려 안내 대상에서 빠진다(UF4).
- 콘텐츠 버전을 기록하지 않는다 — 진행만으로 가린다. 대가 1.

### D2. 안내는 지도 루트에서 다른 겹침이 없고 진행 조회가 끝났을 때 뜬다

- 조건(`AppSession`): 진행 조회 `loaded` · 앱 구간 · 화면이 `journey-map` · 화면 겹침(말풍선 · 모달) 없음 · 티켓 없음 대화상자 없음 · 에피소드 설문 없음 · 연속 학습 축하 없음.
- 대화상자는 티켓 없음 대화상자와 같은 틀(ui-lynx `Overlay` 위 앱 상자 — `Dialog`가 체크 행을 받지 못한다). 상태바는 ui-lynx 기본 스크림이라 표지 없이 어두운 아이콘이다(상태바 등록부 `default-scrim`).
- 시스템 뒤로는 「Cool, got it」과 같다(체크 상태를 따름).

### D3. 기록은 기기 범위 저장값 `libitum.catalog-update-notice`다

- 값: `{ versions: { [에피소드 id]: 콘텐츠 버전 } | null, muted: boolean }`. ⟨2026-10-28 정정⟩ 처음에는 진행 상태 서명(「에피소드:유닛,유닛」)을 적었는데, 새 유닛 하나를 끝내거나 에피소드를 클리어해도 서명이 바뀌어 다시 떴다(사용자 지적 「에피소드 클리어할 때 등 자주 뜬다」). **사용자 결정**: 콘텐츠 업데이트 뒤 처음 한 번만.
- 뜨는 조건: 새 유닛이 있는 에피소드(`catalogFreshEpisodeIdsOf`) 가운데 **기록의 버전과 지금 버전이 다른 것**이 있을 때. 기록이 `null`(첫 실행 · 이 기능 전 앱에서 올라옴)이면 새 유닛만으로 뜬다 — 새로 깐 사람은 끝낸 에피소드가 없어 뜨지 않는다.
- 적는 때: 닫을 때, 그리고 **띄울 것 없이 지도에 닿았을 때**(D2의 조건이 맞을 때) 지금 버전을 통째로 적는다. 그래서 유닛을 끝내거나 클리어해 진행이 바뀌어도 버전이 그대로면 뜨지 않고, 바뀐 판은 앱 시작에 적용되므로(스테이징) 결과적으로 업데이트 뒤 처음 지도에서 한 번 뜬다.
- `muted`는 「Don't show this again」을 체크하고 닫은 것 — 이후 어떤 상태에서도 뜨지 않는다. 되돌리는 길은 지금 없다(범위 밖).
- 서버로 가지 않고 로그아웃 · 계정 삭제에서도 지우지 않는다(`storage.ts` 기기 범위 예외 다섯째). 저장소가 없으면(Explorer 등) 띄우지 않는다 — 매번 뜨게 되므로.

## 대가

1. 진행으로 새 유닛을 가리므로, 시험 계정(ADR-0085)으로 유닛을 건너뛰고 최종을 끝낸 에피소드도 「새 유닛」이 있는 것으로 잡힌다. 버전 기준이라 그것만으로는 뜨지 않고, 그 에피소드가 업데이트될 때 함께 뜬다.
2. 「다시 보지 않기」는 모든 업데이트 안내를 끈다(에피소드별 아님). 켜는 길이 없다 — 앱을 지웠다 깔면 돌아온다.
3. 분석 이벤트가 없어 안내 노출 · 끄기 비율을 모른다.
4. 지도에 표시가 없어 어느 유닛이 새것인지는 학습자가 찾아야 한다 — 새 유닛은 열린(안 끝낸) 노드로 보인다.
