# ADR-0104 — 카탈로그 레슨 화면 종류별 첫 안내

- 상태: **채택.**
- 날짜: 2026-11-05.
- **사용자 결정**(2026-11-05): 튜토리얼(u00) 레슨에 오버레이 안내가 없다 → **문항 종류별로 처음 한 번** 띄운다. 시안 https://claude.ai/artifact/WEazvkQWaWfpPs2oLx18NK 의 여섯 종류 · 문구 · 다섯 언어 · 화살표 위아래 움직임. 「튜토리얼 내용이 나중에 바뀌어도 문제없이 작동해야 한다.」
- 다루는 축: 카탈로그 레슨의 활동 화면 위에 「처음 한 번」 뜨는 안내 — 대상 · 판정 입력 · 기억 · 떠 있는 동안의 화면 · 화살표 움직임.
- 이어받는 결정: [ADR-0054](0054-learning-item-guides.md)의 안내 모양(스크림 0.8 · 바탕 판 0.9) · 기기 기록(`libitum.learning-item-guides.seen`) · 아무 데나 탭 · 뒤로가기로 닫기 · 배타 포커스와 화면 루트 가림. **바꾸는 결정은 없다** — 0054의 「조각 하나」 안내(`sentence-order`)는 그대로이고 종류가 는다.
  **다루지 않는 것**: 여정 맵 첫 유닛 안내(`first-unit-guide`), 최종 테스트 · 이야기 화면, 튜토리얼에 없는 활동 화면(`typing` · `pair-match` · `read-aloud` · `speak-word`).

## 맥락

1. 튜토리얼이 카탈로그 에피소드가 된 뒤(ADR-0081) 레슨 화면에 안내가 하나도 없다 [코드]. 0054의 안내는 옛 문장 만들기 화면의 「조각 하나」 경우에만 뜬다.
2. 튜토리얼 본문은 버킷에서 바뀐다(ADR-0056 · 0087) — 문항 id · 순서 · 학습형이 바뀌어도 앱 업데이트 없이 안내가 맞아야 한다.

## 결정

### D1. 안내는 콘텐츠가 아니라 **활동 화면 종류**에 건다

- 판정 입력은 카탈로그 활동의 `form`(망라 `switch`가 있는 학습형)과, 문장 만들기에 한해 첫 문항의 조각 수뿐이다. 에피소드 id · 문항 id · 유닛 키 · 튜토리얼 여부를 보지 않는다.
- 그래서 튜토리얼 문항이 바뀌거나 빠져도, 그 화면 종류를 **어느 에피소드에서든 처음 만날 때** 한 번 뜬다. 튜토리얼에 새 화면 종류가 생기면 안내 없이 열린다(망가지지 않음).

| `form` | 종류(`LearningItemGuideKind`) |
|---|---|
| `vocab-card` | `activity-vocab-card` |
| `word-choice` | `activity-word-choice` |
| `listening` | `activity-listening` |
| `syllable-build` | `activity-syllable-build` |
| `sentence-order` | `activity-sentence-order` — 첫 문항 조각이 **둘 이상**일 때만. 하나면 0054의 `sentence-order`가 화면 안에서 뜨므로 이 안내는 미룬다 |
| `culture-card` | `activity-culture-card` |
| 그 밖 | 없음 |

- 문항이 없는 활동은 없음.

### D2. 판정 · 기억

- 순수 함수 `activityGuideKindFor({ form, firstChipCount })` → 종류 | null. 화면은 판정하지 않는다.
- 기억은 0054와 같은 키 · 같은 배열(종류 문자열)이다. 옛 앱은 모르는 종류를 버린다(되돌려 설치해도 무해).
- 판정은 활동이 설 때 한 번 — 떠 있는 동안 입력이 바뀌어도 다시 판정하지 않는다(0054 훅과 같음). 저장소가 없으면 띄우지 않는다.
- **틀린 문제 다시 풀기 화면에서는 띄우지 않는다** — 이미 한 번 푼 화면이다.

### D3. 떠 있는 동안

- 안내는 활동 화면 뒤의 형제(`position: fixed`, 화면 전체)이고 아무 데나 탭 · 뒤로가기로 닫힌다 — 그동안 뒤 화면은 탭을 받지 않는다.
- 뒤 화면 격리: 안내 판의 배타 포커스(0054 D6) + 활동의 `LearningShell` 루트 가림. 화면마다 손대지 않도록 셸은 **안내 층이 주는 컨텍스트**도 `obscured`로 읽는다.
- 소리가 있는 활동(듣기)의 자동 재생은 막지 않는다 — 안내가 「다시 들으려면 스피커를 누르세요」라고 말한다.

### D4. 화살표는 위아래로 움직인다

- 아래 화살표가 10 px 오르내린다(`learning-item-guide-arrow-bob`, CSS `@keyframes`). 주기는 토큰 `duration.d9`(1000 ms) · 가속 `easing.easing`이고 **5회(약 5초)로 끝난다** — 저절로 시작한 움직임을 5초 안에 멈춘다(WCAG 2.2.2, 시작 버튼 숨쉬기 3회와 같은 관례). 시안의 1.2 s 무한 반복에서 바꾼 점이다. 0054의 안내에도 같이 적용된다(같은 부품).
- 움직임 줄이기(`useMotion() === "reduced"`)면 클래스를 붙이지 않는다 — 정지.

### D5. 문구 — 다섯 언어

- 영어는 시안 그대로. vi · id · es · ja는 번역 초안(원어민 검수 필요). 버튼 이름(Check · Next)은 각 언어 문구표의 값과 같은 낱말을 쓴다.

## 대가

1. 안내가 떠 있는 동안 듣기 자동 재생 소리가 난다.
2. 문장 만들기의 일반 안내는 첫 문항이 조각 하나인 활동에서는 미뤄진다 — 다음에 만나는 여러 조각 활동에서 뜬다.
3. 기존 설치(이미 레슨을 해 본 사용자)에도 처음 만나는 화면마다 한 번씩 뜬다 — 0054와 같은 선택.

## 테스트 계획

| 계층 | 적용 | 볼 것 |
|---|---|---|
| unit | 적용 | `activityGuideKindFor`: 여섯 form → 종류, 그 밖 · 문항 없음 → null, 문장 만들기 조각 1 → null · 2 이상 → 종류 / 저장값 해석이 새 종류를 보존 / 다섯 언어 문구가 모든 종류에 비어 있지 않음 · 영어 확정 문구 |
| ui | 적용 | `LearningItemGuide`가 새 종류 문구를 그림 · 화살표 움직임 클래스(standard) · 정지(reduced) / `LearningShell`이 안내 컨텍스트로 루트를 가림 |
| integration | 적용 | 카탈로그 레슨: 처음 서는 활동에 안내 → 탭으로 닫힘 · 기록 → 같은 종류 다음 활동엔 없음 / 다시 풀기 화면엔 없음 / **튜토리얼 문항 순서 · 에피소드가 달라도** 화면 종류로 뜸 / 모두 본 설치엔 없음 |
| e2e | 해당 없음 | 기기 e2e는 CI에 없다. 출시 전 실기 확인: 첫 실행 튜토리얼에서 여섯 안내 · TalkBack/VoiceOver 격리 · 움직임 줄이기 · 듣기 첫 안내의 낭독이 자동 재생 음성에 묻히지 않는가(대가 1) |

## 측정

없음: 첫 사용 안내라 이벤트를 따로 두지 않는다. 튜토리얼 이탈은 기존 퍼널(레슨 시작 → 완료)로 본다.
