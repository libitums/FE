# ADR-0093 — 인도네시아어를 둘째 다른 UI 언어로 연다

- 상태: **채택 — 클라이언트.** 서버 변경 0. 콘텐츠 수준은 올리지 않는다. 글꼴 · 호스트 글꼴 파일 변경 0.
- 날짜: 2026-11-03.
- **사용자 결정**(2026-11-03): 다음 언어는 인도네시아어. 근거는 지금 광고 권역(필리핀 · 말레이시아 · 싱가포르)과 같은 동남아이고 말레이시아 사용자도 상당 부분 읽는다는 것 — 기기 언어 수요는 아직 재지 않았다.
- 다루는 축: [ADR-0091](0091-vietnamese-localization.md)의 구조(문구표 · 콘텐츠 번역표)에 둘째 언어를 더하는 것. 구조 자체는 바꾸지 않는다.
  **다루지 않는 것**: 언어별 번역 파일 분리(언어가 셋 이상이 되면 — 재검토 조건), 스토어 등록 정보, 랜딩.

## 결정

### D1. 언어 코드는 `id`, 목록 자리는 베트남어 다음이다

- `EntryLanguage`에 `id`(라벨 `Indonesian`)를 더하고 `entryLanguages` = `en · vi · id · es · ja`. `isEntryLanguageAvailable("id") === true`.
- 국기는 기존 틀(40×28, 모서리 4)로 그린 빨강 · 하양 두 띠.
- **기기 태그 `in`도 `id`다** — 옛 Android(자바 `Locale`)는 인도네시아어를 `in`으로 낸다(`uiLanguageFromDeviceTag`).

### D2. 콘텐츠 번역표에 `translations.id`를 받는다

- `ContentLanguage` = `vi | id`. 정규화 규칙은 ADR-0091 D1 그대로(틀린 항목만 빼고 `invalid-translation` 경고 하나).
- `localizeEpisode`는 언어 표를 이름으로 찾으므로 바뀌지 않는다.

### D3. 문구표 `id`는 영어와 같은 모양의 완전한 표다(번역 초안)

- `uiCopyId: UiCopy` — 구획 파일 `ui-copy-id-*.ts`. 파일 머리에 「원어민 검수 필요」.
- 말투는 앱의 영어 톤에 맞춰 **친근한 `kamu`** 로 통일한다(번역 초안이 `Anda`와 섞여 있던 것을 맞췄다).

### D4. 글꼴은 바꾸지 않는다

- 인도네시아어는 라틴 기본 글자뿐이고 Jost가 모두 가진다(fontTools로 확인 — 기본 라틴 · 숫자 · `é` · 따옴표 · 줄표). 강조 토큰 다시 정의 없음(베트남어의 `app-lang-vi` 같은 클래스가 없다).

### D5. Android 알림 채널 `values-in`

- Android 리소스는 인도네시아어를 옛 코드 `in`으로 찾는다 — `values-in/strings.xml`.

### D6. 설정에 「Language」를 둔다 — 가입 뒤에도 언어를 바꾼다

- 사용자 지적(2026-11-03): 「언어 선택 화면이 설정에 없네」 — 지금까지는 언어를 진입 흐름에서 한 번만 골랐다.
- 설정 › 계정 묶음의 「이름 · 나라」 다음에 `language`(설명은 지금 언어 이름, `entryLanguageLabel`). 누르면 설정 탭 스택에 `language-settings`를 쌓고, **진입 흐름의 언어 선택 화면을 그대로** 다른 결선으로 그린다.
- **고르는 즉시 바꾸고 저장한다**(`changeUiLanguage`) — 화면 전체가 그 자리에서 그 언어로 바뀐다. `Continue` · 뒤로는 설정 루트로 돌아간다.
- 이벤트 `language_settings_opened`(속성 없음) — 열람만 센다.

### D7. 언어 선택 화면에 미리보기 카드를 둔다 — 고른 언어로 어떻게 보이는지

- 사용자 지적(2026-11-03): 「번역이나 버튼 등이 해당 언어로 보여진다는 시각적인 효과가 부족」. 시안 셋 가운데 **A(목록 위 미리보기 카드) — 사용자 결정**(https://claude.ai/artifact/GWp43sUsg5KZ1e6UTwUNK4).
- 카드: 안내(「What did you hear?」) · 한국어 예문 「감사합니다」 · 로마자 · 뜻 · 「Check」 버튼(보이기만). 안내 · 뜻 · 버튼은 지금 UI 언어 문구표(`languageSelect.preview` · `common.check`)라, 언어를 고르면 화면 제목 · Continue와 함께 바로 바뀐다.
- 한국어 예문 · 로마자는 학습 내용이라 문구표가 아니라 화면 상수(`languagePreviewSample`, 한글 리터럴 검사의 허용 선언)다.
- **설정 › Language에서 열면 단계 진행 막대(3/3)를 그리지 않는다**(`showSteps={false}`) — 가입 단계가 아니다.

## 테스트 계획

| 계층 | 무엇 |
|---|---|
| unit (episode-core) | TR7: `translations.id` 정규화 |
| ui | LS-U7: 미리보기 카드가 한국어 · 로마자 · 지금 언어의 안내 · 뜻 · 버튼을 보인다. LS-U8: `showSteps={false}`면 단계 막대가 없다 |
| unit (app) | EL3 · EL4(다섯 언어 · 고를 수 있는 셋), UL5c(`id` · `id-ID` · `in` · `in-ID`), LZ6(`id` 표 적용 · 없으면 같은 객체), ID1 ~ ID3(문구표 완전성 · 번역 비율), UC4(문구표 키 집합) |
| integration | IV3: 번역표가 있는 콘텐츠를 인도네시아어 사용자가 번역으로 본다. IL9: 설정 › Language에서 인도네시아어를 고르면 탭이 바로 바뀌고 저장되며 돌아오면 설정. IT1: 설정 항목 일곱 |
| 실기 | iOS 시뮬레이터에서 `id`로 지도 · 레슨 · 결과 |

## 대가

- 번들 + 인도네시아어 문구표(아래 성능 보고서). 콘텐츠 번역표는 버킷 파일에 실려 영어 사용자도 함께 받는다 — 언어가 둘일 때는 받아들인다.
- 번역은 초안이다.

## 재검토 조건

- 언어가 셋 이상이 되면 → 번역표를 에피소드에서 떼어 언어별 파일로 받는다(고른 언어만).
