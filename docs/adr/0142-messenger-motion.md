# ADR-0142 — 메신저 대화방 움직임 1순위

- 상태: **채택.**
- 날짜: 2026-11-14.
- **사용자 결정:** 시안 [PmBPj86YS1uijqjWSMVJEn](https://claude.ai/artifact/PmBPj86YS1uijqjWSMVJEn)에 「진행」 — 고를 칸은 기본안(점 A 튀기 · 등장 A 비스듬히 올라옴).

## 결정
1. **입력 중 점** — 이미 점 셋이 차례로 튄다(`components/chat` `chat-dot`). 그대로 둔다.
2. **말풍선 등장** — 처음 나타나는 글만 감싸개 하나로 움직인다(`chat-entrance.ts`). 상대 글은 왼쪽 아래(−10, 8px), 내 글은 오른쪽 아래(10, 8px)에서 d6 · enter-expressive.
   - 방을 열 때 있던 글, 한 번에 셋 이상 들어온 묶음(기록 불러오기)은 움직이지 않는다.
   - 내 글은 서버가 받으면 id가 바뀌어 줄이 다시 서므로 보낸 시각(`at`)으로 같은 글을 알아본다.
3. **보내기** — 단추가 누를 때마다 pressed 배율로 눌렸다 튄다(d5). 두 클래스를 번갈아 달아 연달아 눌러도 다시 돈다. 보낸 글은 2의 등장으로 올라온다.
4. **스트리밍** — 블록(segment)마다 새 말풍선이 서므로 2의 등장이 블록 단위로 적용된다. 한 말풍선 안에서 글이 자라는 부분의 조각별 흐림 → 또렷은 하지 않는다(ui-lynx `ChatBubble` 글을 조각으로 나눠야 함).
- 움직임 줄이기면 감싸개 · 튀기가 없다. 길이 · 가속 · 배율은 토큰만.

## 버린 대안
- ui-lynx `ChatBubble`에 등장을 넣기 — 학습 메신저(막간)도 같은 부품을 써 기록 화면에서도 움직이게 되고, ui-lynx 번들 여유가 0.5 kB뿐이다.
