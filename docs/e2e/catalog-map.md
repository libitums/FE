# 여정 맵의 카탈로그 에피소드 구획과 표지 컷 화면 (3b-2)

튜토리얼 아래에 서는 카탈로그 에피소드 구획(에피소드 간 잠금 · 잠긴 레슨 노드 · 머리 카드 제목)과, 그 표지 노드가 여는 컷 화면
(원격 그림 · 타자기 · 배경 페이드 · 로마자 토글 · 지문 · 독백 패널 · 완료)을 기기에서 확인하는 **수동 절차**다. 결정은
[ADR-0024](../adr/0024-journey-units-and-special-unit-placement.md) D15, 화면은 [화면 명세](../screens.md) 「여정 탭」의 여정 맵 ·
카탈로그 표지(컷) 행, 콘텐츠의 출처는 [ADR-0056](../adr/0056-episode-content-delivery.md), 측정 이벤트는
[ADR-0029](../adr/0029-product-analytics-posthog.md) D14 적용 기록 ⟨2026-10-12⟩이 진다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | 구획 만들기 · 잠금(`catalogCoverStatus` · `canStartCatalogCover`) · 셀렉터 토큰 · 제목 줄 나눔(`catalogTitleLines`) · 컷 표시 모델(독백 괄호 · 번역 자리 · 토글) · 진행 활동 수 · 갱신 이벤트 |
| ui | 카탈로그 구획 · 잠긴 노드 · 머리 카드 `titleLines` · 컷 화면 상호작용(토글 · 타자기 중 `Next` · 완료 한 번) · 접근성 이름 · 동작 줄이기 |
| integration | 앱을 띄워 맵에 구획 셋 · 표지 완료 → 진행 저장 요청 본문 · 다음 실행 유지 · 넷째 에피소드 pending → 갱신 뒤 일반 구획 · 그림 없는 컷 |

**이 문서만 보는 것**: 기기에서 실제로 그려지는 모습 — 낱말 중간 끊김 · 원격 그림 · 애니메이션 · 패널 변형 · 기울임 · 가림.

> ⟨2026-10-13⟩ **3c에서 레슨 · 최종 노드가 열렸다.** 아래 E3 · E4의 기대(「레슨 · 최종 노드는 눌러도 변화 없음」 · 표지 아래 `COMING SOON` 캡션 · 낭독
> `Lesson 1, coming soon, locked`)는 **3b-2 빌드의 것**이고 지금 빌드에서는 성립하지 않는다 — 레슨은 사슬로 열리고 캡션은 걷혔으며 낭독 이름은
> `Episode 1. Lesson 1` + 상태 접미사다. 지금 빌드의 절차와 회차는 [카탈로그 레슨 e2e](catalog-lessons.md)가 진다. 아래 회차 기록은 그때의 관찰이라 고치지 않는다.
> E13(그림 실패)도 그 문서의 E9로 이어진다.

## 전제

- [공통 전제](README.md#공통-전제) — 자체 호스트 앱, 로그인된 상태.
- iOS: iPhone 17 Pro 시뮬레이터, **Release** Host + 내장 번들(`--bundle-url=main.lynx`). Debug는 `localhost:3000`의 다른 작업 트리 코드를
  읽을 수 있다([README 「자동화」](README.md#ios)).
- `apps/mobile/.env.local`에 Supabase 값이 있어야 원격 그림 · 매니페스트 요청이 나간다. 값은 기록에 적지 않는다.
- 진행 상태 두 가지가 필요하다 — (A) 튜토리얼 최종 테스트 **미완료** 계정, (B) **완료** 계정. 저장 서버에 진행이 남으므로 같은 계정으로 둘을 오갈 수
  없다.

통과·실패는 `통과` / `실패: <관찰>` / `판정 불가: <이유>` / `미확인`으로만 적는다.

| E2 | 가장 긴 제목(`익선 게스트하우스 여성 도미토리` · `익선 게스트하우스 프런트`)의 구획까지 내린다 | 제목이 **띄어쓰기에서만** 끊겨 두 줄 안에 선다 — 낱말 중간에서 끊기면 실패. 한 줄이 넘치는 제목은 작은 글자 |
| E3 | 레슨 · 최종 노드를 누른다 | 회색 자물쇠, 라벨 `Lesson 1` … `Lesson 8` · `Final test`. 눌러도 화면 · 시트 변화 없음. 표지 아래 `COMING SOON` 캡션 하나 |
| E4 | VoiceOver로 노드를 훑는다 | 레슨 `Lesson 1, coming soon, locked`, 잠긴 표지는 잠김 접미사, 캡션은 포커스되지 않음 |
| E5 | (B)로 맵을 연다 | `Episode 1.` 표지만 열림(연주황 면), 2 · 3은 잠김 |

| E8 | 지문 컷(컷 3 · 4 · 6) | 화자 아래 작은 지문 두 줄 — 한국어 한 줄 + 영어 한 줄. 영어 줄은 기울임. 한글 줄이 기우는지 기록(안 기울어도 크기 · 색으로 구분되면 통과) |
| E9 | 대사 패널을 누른다 · 다시 누른다 · 그림 빈 곳을 누른다 | 번역 줄이 로마자로 → 영어로. 패널 탭으로 컷이 넘어가지 않음. 그림 탭은 무변화. 로마자를 고른 채 컷을 넘기면 로마자 유지 |
| E10 | VoiceOver로 패널을 두 번 탭 | 토글되고 낭독이 바뀐다. 독백 컷은 괄호 대신 화자 뒤 `thinking` |
| E11 | 밝은 그림(컷 3 편의점)에서 번역 줄 | 불투명 패널이라 또렷하다 |
| E12 | 마지막 컷 `Continue`(연타 포함) | 맵으로 한 번만 돌아오고 표지 완료(초록 체크) · 머리 카드 `1 / 10`. 학습 완료 화면을 거치지 않는다 |

| E14 | 컷 중간에 나가기 · 시스템 뒤로 | 맵으로, 표지 미완료 유지, 다시 열면 컷 1부터 |
| E15 | 최대 Dynamic Type | 패널이 스크롤되고 `Next`가 화면 안 |
| E16 | (가능하면) 서버 매니페스트에 넷째 에피소드 | 본문 전에는 준비 중 꼴 + `COMING SOON`, 갱신이 본문을 받으면 같은 실행에서 일반 구획 |
| S1 | (B)로 표지를 끝낸 뒤 앱을 다시 켠다 | 표지 완료가 남는다(서버 저장 왕복) |

## 미확인

- **Android** — 절차만 있고 실행한 회차가 없다.
- **보조기술 실기**(E4 · E10) — 시뮬레이터에 VoiceOver가 없다. 접근성 이름은 ui 테스트가 지고, 실기 낭독은 미확인이다.
- **그림 실패 경로**(E13) — 비행기 모드 회차는 없다. 다만 2차 회차에서 **실패가 관찰됐다**: u01 컷 2(`pre-2`)는 서버에 그림이 없어(404) 로드되지 않는데, 화면에는 **컷 1의 골목 그림이 그대로 남았다**(E13 기대 「앞 컷 그림이 남지 않는다」에 어긋남). 이번 컷은 내레이션과 그림이 맞아 눈에 띄지 않지만 장소가 바뀌는 컷에서는 틀린 그림이 남는다. **3c 첫 항목으로 넘김**(`NarrativeBackground`가 튜토리얼과 공유라 실패 처리를 바꾸면 튜토리얼 회귀 위험 — 3c에서 실패 시 이전 층을 걷고 단색 바탕). 서버에 pre-2 · post-2 그림이 올라가면 실사용에서는 일어나지 않는다. ⟨2026-10-13⟩ **3c가 처리를 넣었다** — 그림 층이 로드 실패를 받으면 앞 컷 그림을 걷고 단색 바탕을 보인다([ADR-0058](../adr/0058-catalog-learning-session.md) D13). ui · integration은 통과했고 **기기 확인은 [카탈로그 레슨 e2e](catalog-lessons.md) E9가 진다**(그 문서에 결과가 적히기 전까지 이 항목은 미확인이다).
- **로마자 토글 · 중간 나가기 기기 관찰**(E9 · E14) · **(A) 상태의 세 표지 잠김**(E1 후반) · **E15**(최대 Dynamic Type) · **E16**(넷째 에피소드 — 서버 매니페스트에 없음).
- **표지 완료 → 서버 저장 → 다른 기기**(S1의 서버 쪽) — 원격 DB에 카탈로그 진행 마이그레이션이 적용되지 않았다
  ([ADR README 보류 표](../adr/README.md#보류-표)). 적용 전에는 서버가 `catalogProgress`를 합집합하지 않는다.
  ⟨2026-10-13⟩ 마이그레이션은 **적용됐다**(보류 표의 그 행 — 닫힘). 다른 기기에서 진행이 이어지는지는 여전히 보지 않았다.

## 알려진 제약

- **맵 머리 카드가 가운데 정렬 글자의 앞부분을 가린다.** 머리 카드는 스크롤 밖 고정 오버레이라 카드 높이에 걸린 줄의 왼쪽을 덮는다 — 카탈로그
  표지 아래 캡션이 `…MING SOON`, 튜토리얼 표지 라벨이 `…pisode intro`로 보인다(⟨2026-10-13⟩ 준비된 구획의 그 캡션은 3c에서 걷혔다). 스크롤하면 카드 밖에서 온전히 읽힌다. 3b-2가 만든 것이 아니라 기존
  레이아웃이고 별도 과제다(보류 표).
- **한글 지문은 기울지 않는다.** 한글 폰트에 기울임 글꼴이 없어 영어 지문만 기운다. 크기 · 색으로 대사와 구분된다.
