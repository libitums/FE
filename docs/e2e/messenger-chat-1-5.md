# 메신저 1.5단계 — 기기 확인

계약은 `messenger-chat-1-5` spec(§17 사용자 결정 포함)이 정하고 결정은 [ADR-0117](../adr/0117-messenger-chat-turns-coins-new-friend.md)이 진다. 1단계 UI는 [messenger-chat-ui.md](messenger-chat-ui.md)가 지킨다. 자동 테스트(MC2-U · MC2-UI · MC2-I)는 무료 수 · 날짜 키 · 관문 · 가격 · 말풍선 도구 상태 · 교정 조각 · 해금 판정 · 원장 · 지갑 · 새 친구 시트 단계와 최종 통과 → 시트 → 메신저 탭 방 연결을 지킨다.
**Lynx 실기 타이머(background `setTimeout`) · px 높이 · 속성 선택자 없음 · 진동 · 스크린리더 낭독 · 작은 화면 · 소리 없음**은 테스트 환경에 없으므로 기기에서만 판정한다. (1단계에서 자동 테스트가 모두 green이었는데 기기에서 결함 여덟이 나온 것이 이 문서가 있는 이유다 — 특히 타이머와 높이.)

## 준비

### 빌드 · 기기

- 기기: iOS 시뮬레이터 iPhone SE 3세대(375 × 667) · iPhone 17 Pro(402pt) · Android AVD 360dp(Pixel_8을 `wm density 480`으로 줄임) · 320dp(`wm density 560` 정도로 더 줄임, 시트 · 판이 잘리는지 보는 용도) · 저사양 R6_API30(API 30 · 2GB). 가능하면 실기 한 대씩.
- 일반 디버그 빌드(`pnpm bundle:host` → Host.app Debug + `--bundle-url=main.lynx`)로 MC2-E1~E7 · E9 · E10을 본다. **MC2-E2의 타이머 · MC2-E8 일부는 스토어와 같은 구성 빌드**(Android `assembleBundled` · iOS Release)로도 한 번 본다 — 디버그에서만 되고 릴리스에서 깨지는 결함이 1단계에서 있었다. 빌드 전 새 worktree면 `apps/mobile/.env.local` · `google-services.json` · `local.properties`를 메인 체크아웃에서 복사한다.
- **소리를 끄고(음소거 스위치 · 미디어 볼륨 0) 진동은 켠다.** 이 앱에서 소리는 시험 중 항상 끈다(사용자 규칙). MC2-E3의 「효과음 없음」은 소리를 켠 채 따로 한 번만 확인하고 곧바로 다시 끈다.
- 1.5는 **해금 · 무료 수 · 하루 한 번 판 기록이 기기에 남는다.** 회차 사이마다 앱 데이터를 지운다(Android `pm clear` · iOS 앱 삭제 후 재설치, 또는 시뮬레이터 `simctl uninstall`). 저장 키: `libitum.messenger.free-turns`(날짜 · 쓴 수 · 판 기록) · `libitum.messenger.unlocked`(해금한 인물 목록).

### 미나 해금에 닿는 길 (에피소드 3 중간 이야기 유닛 = `u03-mina`의 `INT`)

⟨2026-11-10 개정⟩ 미나는 에피소드 3의 **중간 스페셜 유닛 — 막간 이야기(`INT`, look 형식 「조금 전, 201호」)**를 끝내야 열린다(ADR-0117 D3, 컴패니언 통합 결정). 끝까지 보고 「To be continued…」 배너가 닫히거나, 시작 화면에서 Skip해 처음 끝낸 것으로 적히면 해금이 확정되고, **맵으로 돌아온 뒤 약 2초**에 시트가 선다. 최종 테스트 통과는 해금과 무관하다. 순서대로 쓰고, 어느 길을 썼는지 실행 기록에 적는다.

1. **시드된 진행 번들(권장)** — 개발 구성에서 에피소드 1~2 완료 · 에피소드 3 S1 ~ S4 완료(막간 직전)까지의 진행을 저장소에 심은 임시 번들을 만든다. 진입점이나 저장 시드를 바꾸는 임시 변경은 [dev-probe-nav](../../apps/mobile/src/app/dev-probe-nav.ts) 방식을 따라 **제품 경로가 읽지 않게** 하고, 끝나면 `git diff -- apps/mobile/src/app` 0줄과 임시 번들이 `apps/ios/main.lynx.bundle` · `apps/android/app/src/main/assets/`에 남지 않았는지 확인한다.
2. **로그인 없는 확인** — 비회원(「Continue without an account」)으로 들어가도 되고, 이때 해금 · 원장은 같은 로컬 저장소를 쓴다.
3. **빠른 길이 없을 때** — 진짜 에피소드 3 막간까지 학습으로 간다(최종보다 짧다). 시드 없이 못 닿으면 이유를 적고 「부분」으로 기록한다.
4. 시험을 마치면 임시 시드 · 번들을 버린다.

**이미 막간을 끝낸 계정**(다 깬 계정 · 새 설치)은 앱을 켜고 진도를 읽은 뒤 시트 없이 미나가 열리고, 메신저 목록에 첫 메시지가 NEW · 안 읽음 1로 와 있어야 한다(ADR-0117 D3 보정). 이 경우 시트를 보려면 해금 기록이 없는 새 설치에서 막간 직전 진도가 필요하다.

해금 판정은 「이미 열린 인물이면 시트 없음」이므로 MC2-E5의 「다시 끝내도 시트 없음」은 맵에서 같은 막간을 다시 열어 끝까지 보면 된다.

### 엽전 · 계정 상태

- **엽전 잔액은 앱의 실제 보유 엽전(#405, 처음 통과 +10)이 번 값**이고, 메신저가 쓴 값은 **이번 실행 메모리에만** 빼는 가짜 원장이다(앱을 다시 켜면 쓴 엽전은 되살아난다 — 알려진 한계 2). 씨앗은 보유 엽전 **100**으로 맞춘다(개발 구성의 엽전 시드 또는 학습으로 번 값). 시드 방법이 없으면 MC2-E7의 소비 단계를 「부분」으로 기록한다.
  - 사진 요청 ◎60 → 잔액 40 → 음성 요청 ◎40 → 잔액 0 → 한 번 더 요청하면 모자람.
  - 엽전 보내기(T3/T2 이후) 한 번 = ◎10.
- **시험 계정 vs 무료 계정**: 무료 계정(기본)은 무료 하루 3턴 · 엽전 보내기가 보인다. 무제한 티켓은 대화와 무관하다(학습 전용 — ADR-0117 D8). **시험 계정**(`isTesterAccessActive`)은 턴 줄 · 띠 · 판 · 엽전 보내기가 **전부 없어야** 한다(MC2-E7). 시험 계정이 없으면 그 단계만 「미실행」으로 둔다.
- **무료 수 초기화**: 같은 날 다시 3으로 만들려면 앱 데이터를 지운다. 자정 초기화(MC2-E6)는 기기 시각을 자정 직전으로 옮겨 본다 — iOS 시뮬레이터는 시스템 시계가 호스트를 따르므로 **실기 또는 Android AVD**(`adb shell date`/설정에서 자동 시간 끄기)로 본다. 시험 뒤 자동 시간을 다시 켠다.
- 문구 언어는 영어 UI로 본다. 다른 언어(vi · id · ja · es)는 MC2-E10의 한 줄 눈검사만 한다.

### 지켜볼 것

눈(배치 · 점프 · 잘림) · logcat `FATAL EXCEPTION` · iOS 콘솔 오류 · 스크린리더(VoiceOver · TalkBack) · 큰 글자(iOS 접근성 최대 · Android 글꼴 크기 최대) · 움직임 줄이기.
끝나면 에뮬레이터 `emu kill` · `wm density reset` · 시스템 시각 되돌림 · 임시 번들 제거.

## 알려진 한계 (1.5단계 — 실패가 아니라 상태를 남길 것)

1. **가짜 출처**: 뜻(로마자 · 번역) · 교정 · 정해 둔 답장 · 새 친구 첫 메시지는 모두 가짜 출처(픽스처 표 + 자리 표시)가 만든다. 내용이 입력과 어긋나는 것은 결함이 아니다. 서버 응답은 2단계.
2. **엽전 소비는 로컬뿐**: 쓴 값은 메모리 원장이라 재시작하면 되살아나고, 서버 차감 · 검증이 없다. 번 엽전은 앱의 실제 값을 따른다.
3. **AX5에서 T3 판의 잔액 줄은 화면 밖**: 가장 큰 접근성 글자에서는 고정 줄이 화면을 넘어 잔액 줄이 보이지 않는다(ADR-0117 한계 5). Go unlimited를 뺀 뒤 다시 재서 보이면 기록한다.
4. **큰 글자에서 T3 판 · 새 친구 시트는 안에서 스크롤한다**(⟨2026-11-10⟩ 접근성 C1 · M1 반영): 판 · 시트에 px 최대 높이가 걸리고 본문만 스크롤하며, 단추(Keep chatting · Back to chats · 잔액 줄 / Reply · Later)는 스크롤 밖에 고정된다. T3 판이 열려도 로그가 최소 96은 남고, 시트 위 24는 scrim으로 남는다. 기기에서 본 적이 없다 — 단추가 잘려서 못 누르면 「실패」, 보이기만 빠듯하면 「부분」.
5. **번역 원어민 검수 전**: vi · id · ja · es 문구는 원어민 검수가 끝나지 않았다. 어색한 문구는 결함이 아니라 검수 목록에 올린다(어긋나 잘림 · 줄바꿈 오류는 결함).
6. **메신저에 Go unlimited가 없다**: 무제한 티켓은 학습 전용이다(ADR-0117 D8). 대화의 무제한은 시험 계정뿐이다.
7. **해금 상태가 기기에 남는다**: 회차 사이 앱 데이터를 지우지 않으면 시트가 다시 뜨지 않는다.

## 접근성 확인

- 모든 새 단추(지구본 · 연필 · Keep chatting · 엽전 보내기 · Back to chats · Reply · Later)에 라벨이 있고, 눌림 영역이 24 이상(목표 44)이다. 이웃 단추를 잘못 누르는지 함께 본다.
- 상태는 색만으로 전하지 않는다 — 도구 단추의 켜짐은 색 + 펼침/접힘 낭독, 교정의 바뀐 글자는 진한 주황 + 낭독, 머리 줄의 회색 → 주황은 문구로도 읽힌다.
- 내 말풍선 안 흰 글자(오렌지 위 대비 3.02 · 점 2.97)는 사용자 결정(§17 DM · DD)으로 **시안대로 두는 예외**다. 대비 부족을 결함으로 올리지 말고 가독성이 실제로 떨어지는지만 기록한다.
- 움직임 줄이기에서 스켈레톤 빛 · 점 깜빡임 · 얼굴 튐이 멈추고 정보는 그대로 전달된다.
- 진동 · 소리만으로 전하는 정보가 없다 — 시트 도착은 진동 + 화면 + 낭독으로 모두 전해진다.
- 큰 글자 최대에서 머리 · 턴 줄 · 도구 줄이 잘리지 않고, T3 판 · 시트는 본문이 안에서 스크롤되며 닫기 · 주 단추가 늘 보이는지를 따로 적는다(한계 4).
