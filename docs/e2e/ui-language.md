# UI 언어 문구표 — 영어 UI 둘러보기 — iOS 수동 e2e

`ui-language.e2e.test.ts`로 옮길 흐름이다. 자동 E2E는 not applicable(runner/command 없음) —
이 문서를 세우는 것이 이 계층의 「테스트」다([README](README.md)). 계약은
`.agent-harness/work/ui-language-catalog/spec.md`, 셈하는 자리는 같은 폴더 `test-plan.md` §6이고
이 문서는 그 절차 사본이다 — E1~E8을 여기서 더하거나 빼지 않는다. 그 폴더는 추적되지 않으므로 저장소에
남는 결정과 근거는 [ADR-0031](../adr/0031-ui-language-catalog.md)이 진다.

## 범위

앱의 안내 · 버튼 · 판정 · 접근성 이름이 **영어 문구표**에서 나오고, 화면에 한국어가 학습 콘텐츠
자리에만 남는지, 영어가 길어져도 레이아웃이 깨지지 않는지, VoiceOver가 영어로 읽는지, 재실행 뒤에도
유지되는지를 본다. 저장은 언어 선택 화면에서 언어를 **확정할 때**(`Intermediate English` 선택)
`libitum.ui.language`에 한 번 일어난다(spec §5).

**관찰할 수 없는 것**: 저장된 언어가 영어 밖일 때의 화면 — 고를 수 있는 언어가 영어뿐이다. 통합
테스트 IL1 · IL2가 대역으로 진다.

## 전제

- **Debug 호스트**(시뮬레이터 iPhone 17 Pro)에서 돈다. E5(VoiceOver)는 실기에서 사람이 판정한다.
  레이아웃(E7 · E8)은 **가장 좁은 폭 375pt 기기 하나**를 더한다.
- **새 설치**에서 시작한다(삭제 후 재설치 — 저장소에 언어 키가 없어야 한다).
- 로그인은 **팀 공유 테스트 번호**로 한다(번호와 코드는 저장소에 적지 않는다 —
  [진입 흐름](entry-flow.md) 「전제」). 우회 경로는 없다.
- 기록은 행마다 결과 · 날짜 · 빌드를 적는다. 한 항목이라도 어긋나면 `실패: <관찰>`로 적는다.
- 한국어 판정: 화면의 **텍스트와 VoiceOver 이름**에 한글이 없어야 한다. 예외는 학습 콘텐츠(제시문 ·
  보기 칩 · 대사 · 받아쓰기 대상 · 문화 노트의 「」 안)뿐이다.

## 절차

| id | 시작점 → 행동 | 관찰할 최종 결과 |
|---|---|---|
| E1 | 새 설치 → 온보딩 → 전화번호 로그인(팀 공유 테스트 번호) → 언어 선택에서 `Intermediate English` → 여정 입장 → 여정 맵 | 맵 · 머리 · 하단 탭 · 스텝 말풍선에 한국어 0(학습 콘텐츠가 없는 화면) |
| E2 | 탭 셋(`Journey` · `Roleplay` · `Settings`) · 알림 · 설정 · 프로필 · 약관을 차례로 연다 | 각 화면에 한국어 0. 약관은 영어 초안 |
| E3 | 스텝 하나를 끝까지(듣기 → 낱말 고르기 → 문장 순서 → 말하기 → 쓰기 → 문화 → 문화 퀴즈 → 평가 → 학습 완료). 나가기 대화상자도 연다 | 안내 · 버튼 · 판정 · 진행 · 대화상자가 영어. 제시문 · 칩 · 받아쓰기 대상은 한국어, **듣기 보기는 영어 뜻 풀이** |
| E4 | 에피소드(표지 · 프롤로그 · 서사 · 메신저 · 전화 · 비주얼 노벨 · 최종 테스트), 롤플레이 목록, 플러스 대화상자를 연다. 나가기를 눌러 본다 | 이름 `Jimin` · `Yuna`, 제목 영어, 대사 한국어. 여정에서 연 나가기 `Back to map`, 롤플레이에서 연 나가기 `Back to list` |
| E5 | **VoiceOver 켠 채 실기**로 표본을 읽힌다 | 탭 `Journey, selected` · 스텝 `First greetings, current` · 로그인 버튼 로딩 `…, loading` · 설정 토글 `Auto-play, on` · 채점 `Result, correct`가 **영어로 낭독**되고 한국어 음성으로 읽히지 않는다. 낭독 한 줄마다 인식한 문구를 기록한다 | · 한국어가 섞인 이름 표본: 낱말 고르기 보기 `<한국어>, selected` · 문장 순서 칩 `<한국어>, position 2` · 쓰기 제시문 `<앞>, blank, <뒤>` — 한국어 구간이 한국어 음성, 접미사가 영어 음성으로 읽히는지 기록
| E6 | 앱을 완전히 종료 → 재실행(재방문자) | 스플래시 → 맵, 영어 유지. 진입 흐름을 다시 보지 않는다. 크래시 0 |
| E7 | design H1 · M1 · M2 · M3 · M7 · M10을 **가장 긴 영어 문구**로 화면당 스크린샷 1장씩(375pt 기기 포함) | **H1**: 문화 · 문화 퀴즈 제목이 `Back to map` 옆에서 두 줄로 접히고 화면 밖으로 넘치지 않음. **M1**: 전화 · 비주얼 노벨 · 평가 · 문화 나가기 라벨이 제목과 폭을 나눠도 넘침 0(전화는 상태 줄 가장 긴 조합). **M2**: 스텝 말풍선 `Asking for directions`가 3줄 이상 되지 않음. **M3**: 롤플레이 카드가 두 줄 + 말줄임, 잘린 제목의 접근성 이름이 전문. **M7**: 플러스 머리 설명 `Practice similar situations`가 넘치지 않음. **M10**: 설정 · 약관 · 프로필 · 알림 제목이 뒤로 버튼과 겹치지 않음(`Privacy and terms` 최장) |
| E8 | 큰 글씨(Dynamic Type 최대)로 H1 · M1을 다시 | 기존 `large-text-reflow` 규칙 화면만 — 넘침 0 |

M4 · M5 · M6 · M8 · M9는 design상 「확인만」이다 — E2 · E4를 도는 동안 눈에 띄는 넘침이 있으면
`실패`로 적고 어느 M인지 함께 쓴다.
