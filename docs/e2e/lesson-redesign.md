# 학습 문항 리디자인 — 13 mini 스크롤 없음 · 캔버스 대조 · 접근성

카탈로그 레슨의 학습 문항 화면이 **iPhone 13 mini에서 문항 시작 · 답한 뒤 모두 세로 스크롤 없이 서는지**, 시안 캔버스 수정안과 **같은 구조 · 토큰인지**, 로마자 기울임 · 판정 배지 자리 · 줄 배치 `Check` · 대화 조립 아바타 · 문화 확인 장면과 해설 판이 기기에서 그대로 서는지, VoiceOver · TalkBack이 무엇을 읽는지를 확인하는 **수동 절차**다.
결정은 [ADR-0081](../adr/0081-lesson-item-redesign.md), 화면 명세는 [화면 명세](../screens.md) 「카탈로그 레슨」 행 ⟨2026-10-22⟩, 소리 · `Slow`는 [학습 문항 음성 e2e](item-audio.md), 큰 글자의 합친 흐름은 [학습 껍데기 큰 글꼴](learning-shell-large-font.md)이 진다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | 밀도(756 문턱 · 높이 모름 = compact · 긴 글 내림) · 한글 단계와 색 · 로마자 조각(빈칸 채우기 정답 자리) · `OptionSelector` 계약(variant · 판정 축 · 뜻 줄 · 이름 · 개수 하한) · `ChatBubble` `annotation` · 문화 짝 카드 · 따옴표 대사 · 해설 · 줄 배치 아래 버튼(Check 켜짐 조건) · 음절 칸 상태 · `counterpart_avatar` 디코드 · 자산 목록 · 내장 그림 가드 · `episode_item_answered` 결선 |
| ui | 셸 판정 자리 · 해설 판 · 흐름 안 버튼 · 밀도 클래스, 글 역할 클래스, 문항 보기 렌더 · testid · 판정 표시, 듣기 조작 부품, 여섯 학습 화면의 구조, 문화 확인 장면 · 답한 뒤 접힘, 정답 상자 |
| integration | 앱을 띄워 내장 레슨에서 줄 배치 `Check` 전 채점 없음 · `Check` 한 번 채점, 문화 확인 해설 · `Continue`, 아바타 주소(받은 파일 · 원격 · 없음), 문항 판정 이벤트 |

**이 문서만 보는 것**: 실제 **높이**(jsdom에는 레이아웃이 없다 — 13 mini에서 넘치는가), 캔버스와 나란히 본 모양, 기울임이 기기 서체에서 서는가, Lynx가 밑줄 색 · 두께를 그리는가, 장면 그림의 자른 자리, 아바타 그림 로드 · 실패, 스크린리더 낭독 순서.
Maestro 흐름은 두지 않는다 — 판정이 「캔버스와 같은가」 · 「들리는 것」이라 사람이 본다.

## 13 mini 「스크롤 없음」을 판정하는 법

한 문항마다 **문항 시작**과 **답한 뒤**(문화 확인은 해설 판이 선 뒤, 줄 배치는 `Check` 뒤) 두 상태를 본다.

1. 그 상태에서 스크린숏을 뜬다.
2. 다음을 모두 만족하면 **스크롤 없음**이다.
   - 세션 헤더 · 지시문(또는 판정 배지) · 무대 카드 · 보기(또는 조각 뭉치 · 파형) · 아래 버튼이 **한 화면 안에 다 보인다** — 아래 버튼의 아래 끝이 홈 표시줄 위 안전 영역 안에 있다.
   - 작업 영역을 손가락(시뮬레이터는 마우스 끌기)으로 위로 끌어도 **아무것도 움직이지 않는다**(끈 뒤 스크린숏이 같다 — 상태 표시줄 시계는 빼고 본다).
   - 아래 흐림 띠(합친 흐름의 단서 — [ADR-0022](../adr/0022-scroll-regions-and-fixed-affordances.md))가 없다.
3. 하나라도 어긋나면 **한 스크롤**로 적고, 그 문항이 아래 「안전망 문항」에 드는지 본다. 들면 `안전망(수용)`, 아니면 `실패: <넘친 몫>`.
4. 첫 회차의 첫 화면에서 **인셋을 먼저 확인한다** — 세션 헤더가 상태 표시줄 아래(위 50)에서 시작하고 아래 버튼이 홈 표시줄 위(아래 34)에 있다. 인셋이 0으로 보이면 이 절차의 예산이 맞지 않는다 — 판정을 멈추고 `판정 불가: 인셋 0`으로 적는다(별도 결함).

**안전망 문항(사용자 수용 — [ADR-0081](../adr/0081-lesson-item-redesign.md) 「대가」 2)**: u03 대화 조립 `S2-02` · `S2-10` · `S4-09` · `S4-12` · `S4-18`(창고 3 ~ 4행), 해설이 긴 문화 확인(u01 ~ u03 질문 카드 갈래)의 답한 뒤. 이 문항은 한 스크롤이어도 실패가 아니다 — 잘림 없이 끝까지 닿는지만 본다.

## 캔버스 대조 표 (EU1)

캔버스 수정안의 아트보드와 13 mini 스크린숏을 나란히 둔다. **「같다」의 기준은 구조(위 → 아래 순서 · 무엇이 카드 안이고 밖인가)와 토큰(색 · 글자 단계 · 모서리)이다** — 줄바꿈 위치 · 픽셀 높이는 브라우저 글꼴과 달라 판정하지 않는다. 의도적으로 다른 값은 「알려진 차이」 열에 있고 차이로 적지 않는다.

| 공통 | TextRoles · OptionSubtle | 로마자 = 기울임 · 옅은 회색, 뜻 = 구분선 아래 굵은 글자, 보기 기본 테두리 `gray-300` · 눌림 · 선택 · 판정 상태 | 판정 배지가 지시문 자리(지시문 글은 안 보임, 아래가 밀리지 않음) | 셸 아래 기본 버튼은 그대로(Check만 ui-lynx `Button` — Q7) | 미확인 |

u01 · u03 대표 문항(EU2)은 같은 열로 한 줄씩 더한다 — 특히 **문화 확인 질문 카드**(u01 — 장면 없음, 한글 → 로마자 → 구분선 → 뜻)와 **문장 조립**(위 줄 = 영어 문장, 로마자는 `Check` 뒤).

## 접근성 확인 항목 (EU5)

각 항목에 `기록: <들린 그대로>`를 남긴다. iOS · Android 따로.

| id | 단계 | 들려야 하는 것 |
|---|---|---|
| AX1 | `S7` · 문장 조립 — 조각을 놓기 전 `Check`에 초점 | `Check`가 **꺼진 상태로 읽힌다**(VO `dimmed` · TalkBack `disabled`) → 조각 하나를 놓은 뒤 다시 초점 → 켜진 버튼으로 읽힌다. 다 놓아도 저절로 판정 낭독이 나지 않는다 |
| AX2 | `S11` 창고 조각 · 칸 | 조각 = `Your line: <한글>, <뜻>` / `Partner's line: <한글>, <뜻>`(화자 포함). 칸은 지금 이름(`Partner, turn 1: …` / `You, turn 2, empty`). 아바타는 읽히지 않는다 |
| AX3 | `S13` 장면 | 상대 말풍선 = `<화자>: <한글>, <로마자>, <뜻>` 한 번(자손이 따로 읽히지 않음). 장면 그림 · 구분선 · 아바타는 읽히지 않는다. 보기 = 한글 + 뜻 |
| AX4 | `S13` 보기를 고름 | 고르는 순간 `<제목>. <해설 영어>`가 **한 번** 들린다. 해설 판에 초점 → 제목 + 해설이 한 요소로. 남은(고른) 보기는 판정과 함께 꺼진 상태로 |
| AX5 | `S4` 타일을 쓴 뒤 창고 | 쓴 타일 = `<음절>, used` + 꺼진 상태. 칸 낭독은 지금 규칙 |
| AX6 | `S2` · `S6` 보기를 고름 | 판정 낭독이 화면마다 **한 번**. 나머지 보기가 꺼진 상태로 읽힌다(다시 고를 수 없음). 판정 배지가 지시문 자리로 옮겨 낭독 순서가 머리 → 판정 → 카드 → 보기인지 |
| AX7 | `S3` 그림 · `S5` 그림 | 그림 이름 `Picture: <뜻>` 그대로, 한글이 읽히지 않는다(정답 노출 없음) |
| AX8 | `S2`(짝 소리 고르기 문항이 있는 u01 레슨) · 문장 조립 — 답하기 전 | 답 전에 로마자가 읽히지 않는다(정답 노출 없음 — 짝 소리 고르기 · 문장 조립) |

## 결과
