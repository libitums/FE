# 학습자 프로필 — 이름 · 나라 입력 (3d-2)

학습자가 이름과 나라를 넣고, 그 값이 레슨 문장의 `{이름}` · `{나라}`에 서는 것을 기기에서 확인하는 **수동 절차**다 — 세 진입점(온보딩 넷째 스텝 · 에피소드 전 · 설정)이
계약대로 서는지, 나라 고르기와 미리보기가 기기에서 어떻게 보이는지, 서버 저장이 원격 DB 적용 전후로 어떻게 다르게 도는지.
결정은 [ADR-0059](../adr/0059-learner-profile.md), 화면은 [화면 명세](../screens.md)의 온보딩 · 「학습자 프로필 묻기」 · 「Name and country」 행,
측정 이벤트는 [ADR-0029](../adr/0029-product-analytics-posthog.md) D14 적용 기록 ⟨2026-10-13 — 3d-2⟩, 개인정보는 [iOS 개인정보](../ios-privacy.md) 「학습자 프로필」이 진다.

| 이미 지는 층     | 무엇을                                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| unit             | 이름 검증(접기 · 금지 문자 · 30자) · 나라 표 199행과 로마자 규칙 · 검색 순위 · 치환 스크립트 셋과 연음 · 캐시 디코드 · 동기화 걸음 · 가드 판정 · 폼 판정 · 설정 줄 요약 · 이벤트 |
| ui               | 양식 · 나라 고르기 · 뼈대 · 세 변형(온보딩 넷째 스텝 · 에피소드 전 · 설정)의 렌더 · 오류 · 낭독 · 접근성 이름 · 동작 줄이기                                                    |
| integration(앱)  | 온보딩 → 손님 칸 → 로그인 뒤 업로드 · 가드 → 저장 / `Skip` → 원래 시작 · 설정 수정 → 다음 레슨 · RPC 실패 · 404 → 기기 캐시 · 계정 삭제 뒤 캐시 삭제 · 실데이터 u01 ~ u03       |
| integration(DB)  | 본인 저장 · 조회, 타인 행 불가침, 비로그인 거절, 잘못된 입력 `22023`, 사용자 삭제 시 행 삭제, 표 직접 접근 거부                                                                 |

**이 문서만 보는 것**: 기기의 모습과 조작감(시스템 자판 · 한글 조합 입력 · 199줄 스크롤), 실제 원격 DB 왕복, 다른 기기 로그인, VoiceOver 실기.

## 전제

- [공통 전제](README.md#공통-전제) — 자체 호스트 앱. iOS: iPhone 17 Pro 시뮬레이터, 이 브랜치의 번들. 다른 작업 트리의 개발 서버를 읽지 않게 한다([README 「자동화」](README.md#ios)).
- **원격 DB 적용 전 / 후 두 번** 돈다. 마이그레이션 `20261013120000_learner_profiles.sql`이 원격에 없으면 서버 저장이 404로 실패하고 기기 캐시로만 돈다(그것도 계약이다 — E8).
- **[데이터] 이름 · 나라가 화면에 서는 곳은 u02 · u03의 최종 테스트뿐이다.** u02 `RP-01`(「{이름}(으)로 예약했어요.」), u03 `RP-01`(「저는 {이름}이에요.」) ·
  `RP-04`(상대 대사 「{이름}은/는요?」 · 내 대답 「저는 {나라}에서 왔어요.」). **레슨 문항의 같은 대사는 고정 이름 「은지」**라 레슨 화면에는 학습자 이름이 서지 않는다
  ([콘텐츠 계약](../specs/episode-content-json-contract.md) Q31). 그래서 문장 확인은 최종 테스트까지 가야 한다 — 에피소드 1의 최종 테스트를 통과해야 u02가 열린다.
- 「토큰이 든 에피소드」는 u02 · u03이다 — 에피소드 전 묻기는 u02 표지부터 선다. u01에는 서지 않는다.
