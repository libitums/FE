# 학습 보상 엽전 e2e (ADR-0116)

기기에서 사람이 보는 절차다. 준비: 진행이 있는 계정(튜토리얼 표지를 끝낸 상태 이상). 원격 DB 마이그레이션 `20261109120000_learning_progress_coin_units.sql` 적용 여부를 적는다.

| # | 절차 | 기대 |
| --- | --- | --- |
| YR-E1 | 여정 맵을 연다 | 머리에 연속 · 트로피 · 티켓 다음 엽전 칩 「0」(이 기능 전 진행은 소급하지 않음). 눌러도 아무 일 없음 |
| YR-E2 | 끝내지 않은 레슨을 통과한다 | 보상 카드 「+ 10 REWARD」(엽전 · 황동 카드). 카드가 올라온 뒤 엽전 10개가 하나씩 머리 엽전 칩으로 날아가고 닿을 때마다 칩이 1씩 올라 10. 마지막 엽전이 닿을 때 칩 아이콘 톡 |
| YR-E3 | 맵으로 돌아온다 / 앱을 다시 켠다 | 맵 칩 10, 다시 켜도 10 |
| YR-E4 | 같은 레슨을 다시 통과한다 · 미통과한다 | 엽전 카드 없음(등급 카드만) · 칩 그대로 · 날기 없음 |
| YR-E5 | 다른 기기에서 같은 계정으로 다른 레슨을 통과한 뒤 첫 기기를 다시 켠다 | 두 기기의 엽전이 합쳐진다(10 + 10 = 20). 서버 `learning_progress.progress.coinUnits`에 두 유닛 |
| YR-E6 | 동작 줄이기 · VoiceOver | 날기 없이 칩 숫자만 바뀜. 칩 「N coins」, 카드 「Reward, 10 coins」로 읽힘, 날아가는 엽전은 읽히지 않음 |

**iOS 시뮬레이터 iPhone 17 Pro 2026-11-09: YR-E2 화면 부분 통과** — 결과 화면만 띄운 임시 진입점(보유 30 · 보상 10, 저장소에 넣지 않음)으로 녹화. 엽전이 카드 아이콘에서 머리 칩으로 줄지어 날고 칩이 20 → 30으로 찼다. 앱 흐름(실제 레슨 통과 · 저장) · Android · 동작 줄이기 · YR-E1 · E3 ~ E6은 미실행. [성능 기록](../performance/reports/yeopjeon-reward-iphone-17-pro-simulator-01.md).
