# 무제한 티켓 표시 e2e (ADR-0115)

기기(iOS · Android)에서 사람이 보는 절차다. **미실행** — 2026-11-09 현재 테스트(unit · ui · integration)만 돌았다. 그라데이션 면 · 빛 훑기 · 선 그림(무한 기호) · 원형 번짐은 테스트 렌더러가 그리지 않으므로 이 절차로만 판정한다.

준비: 시험 계정(ADR-0085 — `app_metadata.duru_tester = true`)과 일반 계정 하나. 표시는 토큰이 갱신될 때 실린다 — 앱을 다시 켜거나 다시 로그인한다.

## 구현 전과의 차이

| 자리 | 전 | 후 |
| --- | --- | --- |
| 머리 티켓 칩(시험 계정) | 흰 칩 · 주황 티켓 · 글자 「∞」 · 누를 수 없음 | 주황 그라데이션 칩 · 흰 티켓 · 흰 무한 기호 그림 · 빛 훑기 · 누르면 무제한 모달 |
| 결과 화면 칩 | 같은 흰 칩 「∞」 | 같은 주황 칩(그림자 없음 · 빛 훑기) |
| 결과 화면 줄 | 없음 | 「No ticket used · Unlimited」 연주황 알약 |
| 「Next lesson」 태그 | 없음 | 흰 무한 기호 태그 |

## 절차

| # | 절차 | 기대 |
| --- | --- | --- |
| UT-E1 | 시험 계정으로 여정 맵을 연다 | 머리 세 번째 칩이 밝은 주황 → 짙은 주황 면, 위쪽이 살짝 밝고 바닥이 살짝 짙다. 흰 티켓 + 흰 무한 기호가 또렷하다(선이 끊기거나 채워지지 않는다). 숫자 · 「∞」 글자 없음. 약 4초마다 흰 띠가 왼쪽에서 오른쪽으로 지나간다. 칩 높이가 연속 · 트로피 칩과 같고 줄이 넘치지 않는다(작은 기기 포함) |
| UT-E2 | 설정 → 손쉬운 사용 → 동작 줄이기를 켜고 맵으로 돌아온다 | 빛 띠가 지나가지 않는다. 칩 모양은 그대로 |
| UT-E3 | 칩을 누른다 | 짙은 막 위에 주황 무한 기호(뒤에 주황 번짐) · 「Unlimited tickets」 · 「GUEST PASS」 알약 · 안내 두 줄 · 「Got it」. 「Got it」 · 왼쪽 위 뒤로 · Android 시스템 뒤로가기로 닫힌다 |
| UT-E4 | 레슨 하나를 끝까지 한다 | 결과 화면 머리 칩이 주황 칩(빛 훑기, 그림자 없음), 보상 카드 아래 「No ticket used · Unlimited」 알약, 「Next lesson」 버튼 오른쪽에 흰 무한 기호 태그 |
| UT-E5 | 일반 계정으로 같은 흐름 | 칩 숫자 · 칩 탭 → 기존 티켓 모달(칸 셋) · 결과 「N tickets left」 줄 · 새 레슨 「1」 태그 — 전과 같다 |

## 보조기술 관찰

| # | 절차 | 기대 |
| --- | --- | --- |
| UT-A1 | VoiceOver(또는 TalkBack)로 머리 칩 | 「Unlimited tickets, 버튼」. 두 번 탭으로 모달이 열리고 첫 초점이 뒤로 또는 「Unlimited tickets, GUEST PASS」 머리 |
| UT-A2 | 결과 화면 | 알약 「No ticket used · Unlimited」 한 번(가운뎃점을 「middle dot」으로 읽는지 적는다), 다음 버튼 「Next lesson. No ticket needed, 버튼」 |
| UT-A3 | 모달을 연 채 오른쪽으로 계속 쓸어 넘긴다 | 모달 요소(뒤로 · 머리 · 문구 · Got it)만 돈다. **뒤쪽 맵 노드로 새면 적는다** — 머리 모달 공통의 기존 결함 후보(ADR-0016 D9, 접근성 지적 M4) |
| UT-A4 | 모달을 열 때 · 닫은 뒤의 초점 | 실제 첫 초점과 닫은 뒤 초점 자리를 그대로 적는다 — 초점을 옮기는 장치는 아직 없다(ADR-0016 D8 후속) |
| UT-A5 | VoiceOver 두 손가락 문지르기 | 모달이 닫히는지 적는다 |
| UT-A6 | 「GUEST PASS」 낭독 | 낱자로 읽는지 적는다 |
| UT-A7 | TalkBack(Android)으로 UT-A1 ~ A3 반복 | 같은 기대 |
| UT-A8 | 가장 큰 글자 크기(iOS 손쉬운 사용 · Android 글꼴 크기) | 칩 줄 · 모달 문구 · 버튼이 잘리지 않는다 |
| UT-A9 | Android 움직임 줄이기(애니메이션 제거) · 결과 화면에서도 | 빛 띠 없음 |

- 구독 판(갱신 · 갱신 꺼짐 · 곧 끝남)은 결제 데이터가 없어 **기기에서 열 수 없다** — ui 테스트(UM2 ~ UM4)만 본다.
- 색 대비는 기기에서 재지 않는다 — 작업 기록의 접근성 보고서 계산표를 따른다. 흰 아이콘 on 칩 그라데이션 밝은 쪽은 3:1 미만(지적 M1) — 사용자가 기기에서 본 뒤 유지로 결정(2026-11-09, ADR-0115 대가 6). 빛 훑기 반복(M2)도 유지.

## 실행 기록

- **2026-11-09 · iPhone 13 mini · Release(작업 트리, 리뷰 회차 전 번들) · 시험 계정 — 부분 관찰(사용자).** 설치 뒤 사용자 말 「잘보이는거같아서 둘다 유지」 — UT-E1의 칩 아이콘이 또렷하게 보인다는 관찰과 빛 훑기 반복 유지 결정이다. UT-E1의 나머지(줄 폭 · 주기) · E2 ~ E5 · A1 ~ A9는 기록이 없어 **미실행**으로 둔다.
