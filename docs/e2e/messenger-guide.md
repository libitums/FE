# 수동 e2e — 메신저 첫 입장 안내 (ADR-0139)

| id | 확인 | 기대 |
|---|---|---|
| MG-E1 | 새 설치 · 시험 계정 · 여정 맵 | 하단 탭 메신저 아이콘에 주황 NEW |
| MG-E2 | 메신저 탭 | 화면이 어둡고 덕수쌤 줄만 떠 있음 + 말풍선, 탭 NEW 사라짐 |
| MG-E3 | 「Chat with 덕수쌤」 | 덕수쌤 방 → 첫 인사 뒤 코치마크 1/2(입력 칸 고리) → 2/2(전구 고리) → Got it |
| MG-E4 | 앱 재실행 | 안내 · 탭 NEW 다시 안 뜸 |
| MG-E5 | 미나 해금(에피소드 3 완료 + 뒤 컷, ADR-0141) | 탭 NEW 다시 → 미나 방 열면 사라짐 |
| MG-E6 | VoiceOver · TalkBack | 말풍선 한 요소, Skip · Next 단추 |
