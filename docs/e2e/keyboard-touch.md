# 한국어 자판 크기 · 눌림 — 기기 확인

결정은 [ADR-0112](../adr/0112-keyboard-touch-input.md)가 진다. 자동 테스트는 칸 배치(10칸 격자 · 쉼표 없음) · 한 누름 = 한 입력(touchstart 입력 · 같은 누름의 tap 버림 · tap만 오면 입력) · 지우기 반복(지연 · 간격 · 상한 · 멈춤) · 눌림 안전 타이머 · 키 진동 결선을 지키지만,
**실제 손가락으로 빠르게 · 두 손가락으로 · 미끄러지며 눌렀을 때, 말풍선이 잘리지 않는지, 진동이 손에 느껴지는지, 스크린리더로 한 번씩 입력되는지**는 기기에서만 판정한다.

## 준비

- 키보드가 서는 화면은 학습의 타자 활동(`TypingActivity` — 받아쓰기 · 번역 · 패턴)이다. 로그인 없이 보려면 [dev-probe-nav](../../apps/mobile/src/app/dev-probe-nav.ts)처럼 진입점을 잠깐 바꾼 측정용 번들을 쓰고, 확인 뒤 `git diff -- apps/mobile/src/app`이 0줄인 것으로 되돌렸음을 남긴다. 측정용 번들이 `apps/ios/main.lynx.bundle` · `apps/android/app/src/main/assets/`에 남지 않게 지운다.
- 기기: iPhone 실기 · iOS 시뮬레이터(iPhone SE 3세대 375pt · iPhone 17 Pro 402pt · iPad mini) · Android 실기(저가 · 중가) · AVD(412dp Pixel_8, API 30 · 2GB, `wm density`로 360dp).
- 판정: 눈(배치 · 눌림 · 말풍선) · 입력창 글자 · 손(진동) · logcat `FATAL EXCEPTION` · `adb shell dumpsys vibrator_manager`(진동 기록 — `usage: TOUCH` · `ignored_for_settings`).

## 접근성 확인

- 칸 전체가 터치 대상이다. 자모 칸은 폭 31.4(320pt) ~ 42.4(430pt) × 높이 54, 1.5칸 키 · 띄어쓰기는 모든 폭에서 44 이상이고 모든 칸이 24 × 24 이상이다(design.md 6절).
- 쌍자음 힌트는 칸 라벨에 섞이지 않는다 — 스크린리더는 지금처럼 「ㅂ」을 읽고, 윗글쇠가 켜지면 「ㅃ」을 읽는다.
- 진동만으로 전하는 정보가 없다 — 눌림은 색 · 말풍선 · 입력창 글자로도 보인다.

## 실행 기록

### 2026-11-09 — iOS 시뮬레이터(iOS 26.5) · Debug 호스트 + 측정용 번들(`--bundle-url=main.lynx`) · 에이전트 실행, 사람 미확인

- **KT-E1 부분 통과** — iPhone 17 Pro · iPhone SE(3세대) · iPad mini(A17 Pro, 창 모드)에서 네 줄 31키가 폭을 채우고, 힌트가 키 오른쪽 위에 보였다. 측정용 화면은 앱 셸 없이 떠서 머리가 상태 표시줄에 겹쳤다 — 측정용 화면 탓이고 자판과 무관하다.
- **KT-E3 통과(탭 연속)** — `idb ui tap`으로 ㅇ ㅏ ㄴ ㅇ ㅁ ㅐ ㅇ 일곱 번 → 입력창 「안ㅇ맹」(일곱 자모가 한 번씩). 중복 · 누락 0.
- **접근성 트리(KT-E9의 일부)** — `idb ui describe-all`: 키 31개가 모두 `AXButton`, 라벨이 예전과 같다(ㅂ … Shift · Delete · Space · Period · Question mark). 힌트 「ㅃ」은 따로 노출되지 않는다. 칸끼리 맞닿음(ㅇ 칸 끝 x 141.67 = ㄹ 칸 시작, 높이 54).
- HostTests `SoundEffectsModuleTests` 8/8(iPhone 17 Pro) — `key` 종류 · 모든 입력에서 던지지 않음.

### 2026-11-09 — Android AVD(Pixel_8 API 37 412dp 제스처 내비 · R6_API30 API 30 2GB 392dp → `wm density 480`으로 360dp), 둘 다 `-read-only` · `bundled` + 측정용 번들 · 에이전트 실행, 사람 미확인

- **KT-E1 부분 통과** — 412dp · 392dp · 360dp 모두 폭을 채움, 제스처 바 위 여백 정상.
- **KT-E3 통과(탭 연속)** — `input tap` ㅇ ㅏ ㄴ ㄴ ㅕ ㅇ → 「안녕」. API 30에서 윗글쇠 → ㅂ → ㅏ → 「빠」(윗글쇠가 한 번만 켜짐 — 같은 누름의 tap이 다시 끄지 않음).
- **KT-E2 통과** — ㅇ과 ㄹ 사이 틈(보이는 키 밖) 탭 → ㄹ 한 번.
- **KT-E5 통과** — ㅎ에서 키보드 밖으로 120ms 스와이프 → ㅎ 한 번.
- **KT-E6 부분 통과** — ㅏ를 2.5초 누름 중 화면: 키 면 진하게 · 위에 「ㅏ」 말풍선 · 입력창은 닿는 순간 「하」로 조합. 첫 줄 말풍선 잘림은 보지 않았다.
- **KT-E7 부분 통과** — 15자모 입력 뒤 지우기 1.2초 누름 → 「안」까지 지워짐, 손을 뗀 뒤 2초 동안 그대로(멈춤).
- **KT-E8 부분 통과(기록)** — `dumpsys vibrator_manager`: 키마다 `usage: TOUCH · Prebaked=TICK` `finished`, 빠른 연속은 앞 것이 `cancelled_superseded`. 시스템 `haptic_feedback_enabled 0`에서 같은 키 → `ignored_for_settings`(진동 없음), 되돌리면 다시 `finished`. API 30은 진동 서비스 로그 `Vibrator perform`(26 ~ 32 경로). 손 체감은 에뮬레이터라 판정하지 않는다.
- logcat `FATAL EXCEPTION` 0건(두 AVD), `Cannot vibrate key tap` 0건.
- 정리: 두 AVD `emu kill` · `wm density reset` · 측정용 번들 삭제 · 진입점 `git diff` 0줄.

### 2026-11-09 (접근성 점검 반영 뒤) — iPhone SE(3세대) 시뮬레이터 · 측정용 번들 · 에이전트 실행, 사람 미확인

- **KT-E6 첫 줄 통과** — ㅂ · ㅔ를 2.5초 누름: 말풍선이 판 위로 나와 **잘리지 않고**, ㅂ은 왼쪽 · ㅔ는 오른쪽 가장자리에 붙는다.
- **찾아서 고침** — 윗글쇠를 켜고 ㅂ을 누르면 입력은 「ㅃ」인데 말풍선은 「ㅂ」이었다(윗글쇠가 한 번 쓰이고 꺼진 뒤 다시 그려서). 말풍선이 누른 순간의 글자를 들게 고쳤고(ui 테스트 KT-UI18 red → green), 다시 눌러 말풍선 「ㅃ」을 확인했다.
- 켜진 윗글쇠를 누르는 동안 아이콘 · 큰 글꼴 잘림 면은 이 회차에 따로 판정하지 않았다(ui 테스트 KT-UI16 · UI17).
