# 수동 e2e — 연속 학습 엽전 보상 (ADR-0143)

전제: 서버에 `20261128120000_streak_rewards.sql`이 적용된 프로젝트(운영 적용 전에는 개발 · 브랜치 DB), 로그인 계정, 기기 소리 끔.
연속 일수는 서버 `learning_days`로 만든다(개발 DB에서 그 계정의 날을 넣고 앱을 다시 연다).

| id | 확인 | 기대 |
|---|---|---|

| SR-E2 | Collect | 모달이 걷히고 엽전 여섯이 오른쪽 위 엽전 칩으로 날아가 칩이 15 오름 → 모달 닫힘. 다시 🔥 칩 → 3일 칸 초록 꼬리표 · Continue |
| SR-E3 | 연속 5일 계정으로 🔥 칩 | 3일 칸 초록 +15, 7일 칸 엽전 +40, 「14-day goal +70」 막대 5/14, 「Amazing work! 2 more days to +40 Yeopjeon.」, Continue |
| SR-E4 | 연속 9일 계정으로 🔥 칩 | 줄이 새 주(8 ~ 14일) — 14일 칸 +70, 큰 목표 「30-day goal +150」 |
