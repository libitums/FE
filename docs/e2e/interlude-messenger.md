# 문자 막간 — 시간 표시 화면 · 메신저 · 답장 시트

문자(`form: "message"`) 막간([ADR-0088](../adr/0088-interlude-story-unit.md) D5)이 시간 표시 화면 뒤 메신저로 그려지고,
메시지가 시간에 따라 쌓이며 답장 시트에서 고른 답에 맞는 줄이 이어지는지 보는 **수동 절차**다.

| 이미 지는 층 | 무엇을 |
| --- | --- |
| unit | 문자 막간 → `story.chat`(CH1 ~ CH4) · 진행 계산 · 기다리는 시간 · 표시 모델(SM1 ~ SM6) |
| ui | 시간 표시(밝은 아이콘 표지) → 머리 이름 · 시간 흐름 · 시트 · 분기 · 끝 한 번 · 시트 닫고 다시 열기(SMU1 ~ SMU6) |
| integration | 문자 Story → 시간 표시 → 메신저 → 답장 → 분기 줄 → Finish story → INT 기록 · S5 열림(SMI1) |

## 전제

- [막간 이야기 e2e](interlude-story.md)와 같다 — 테스트 버킷 또는 커밋하지 않는 임시 내장 픽스처로 u04 · u06 · u08 · u10 막간 판을 읽는다.
- iPhone 17 Pro 시뮬레이터, Debug 호스트 + 내장 번들(`--bundle-url=main.lynx`).

## 단계

| id | 조작 | 기대 |
| --- | --- | --- |
| ME1 | u04 Story → `Start` | 막간 배경 그림 위 짙은 덮개, 가운데 `STORY · EPISODE 4` · 「조금 전」 · `A little earlier`, 아래 `Tap to continue`, 상태 표시줄 아이콘 밝음 |
| ME2 | 기다린다(약 2.6초) | 메신저 — 흰 머리, 가운데 `미나`, 상태 표시줄 아이콘 어두움 |
| ME3 | 기다린다 | 입력 중(…) 뒤 미나 메시지가 하나씩, 말풍선마다 왼쪽 위 아바타, 번역 한 줄 |
| ME4 | 답장 차례 | 마지막 말을 읽을 시간 뒤 바텀 시트 `How will you reply?` · 인용 · 주황 보기 둘 |
| ME5 | 둘째 보기 | 시트 닫힘, 오른쪽 주황 말풍선, 입력 중 뒤 둘째 보기의 분기 줄(첫째 보기 줄은 안 보임) |
| ME6 | 답장 시트에서 바깥을 누르거나 끌어내린다 | 시트에 닫기 · 손잡이가 없고 닫히지 않는다, 입력창은 그대로 `Message` |
| ME7 | 끝까지 | 사진 메시지가 9:16 카드로 잘림 없이 서고, 마지막 뒤 `Finish story` → 검은 면 주황 「To be continued…」 배너 → 맵, Story 끝남 |
| ME8 | u06 · u08 · u10 | 같은 흐름, 메시지 여러 개가 연달아 올 때 하나씩 읽을 틈이 있다 |
| ME9 | `profiles`가 있는 문자 막간 | 상대 말풍선 아바타가 그 그림, 없으면 이름 첫 글자 |

## 기록 ⟨2026-10-28⟩

- 회차: iPhone 17 Pro 시뮬레이터(iOS 26.5), Debug 호스트 + 내장 번들, 임시 내장 픽스처(새 묶음 u01 ~ u10, 버전 `2026-10-26.9`, 막간 · `-v2` 그림), 시험 계정(모든 유닛 열림). 회차 뒤 픽스처를 되돌렸다.
- ME1 **통과**(u08) — 카페 처마 그림 위 덮개, `STORY · EPISODE 8` · 「조금 전, 카페 처마 밑」 · 영어 줄 · `Tap to continue`, 상태 표시줄 아이콘 밝음.
- ME2 **통과** — 흰 머리 · `미나`, 아이콘 어두움.
- ME3 **통과** — 메시지가 하나씩, 말풍선마다 아바타 「미」, 사진 메시지 카드.
- ME4 **통과**(첫 시도에서 인용이 빈칸 — 시트 설명 자리가 기기에서 접혀 인용을 내용 자리로 옮긴 뒤 통과).
- ME5 **통과** — u08 둘째 보기 → 「알아요! 저 벌써 다 젖었어요!」, u04 둘째 보기 → 「유진식당이요!」.
- ME7 **통과** — u04 열세 줄 대화가 끝까지 자동으로 내려가고, 분기 없는 셋째 고르기 뒤 공통 줄, `Finish story` → 맵.
- ME6 **통과**(u04) — 시트에 닫기 · 손잡이가 없고 바깥을 눌러도 닫히지 않음.
- 프로필 아바타 **통과**(u04, 픽스처가 문자 막간에 `profiles: [{ speaker: "미나", image_url: "content/images/profiles/mina-casual.webp" }]`를 더함) — 운영 버킷 그림이 말풍선 아바타로 섬.
- ME8(u06 · u10) · Android · VoiceOver **미확인**.
