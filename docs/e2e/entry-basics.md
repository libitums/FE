# 입장 선택 — 기초부터 / 바로 입장 · 알림 권한은 첫 스토리 뒤 — 기기 확인

결정은 [ADR-0176](../adr/0176-entry-basics-choice.md), 전이 표는 [진입 흐름 계약](../specs/entry-flow.md) §3이 진다.
자동 검사(unit · ui · integration)가 순서 · 이벤트 · 표식을 지킨다. 아래는 **기기에서만** 판정한다.

## 전제

- 새 설치, 서버 기록이 없는 새 계정(EC7 ~ EC9) 또는 「Continue without an account」(그 밖).
- iOS: `--bundle-url=main.lynx`로 이 작업 트리의 번들. Android: `assembleBundled`.
- 먼저 소리를 끄고, 끝나면 기기를 끈다.
