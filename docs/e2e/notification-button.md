# 상단 알림 버튼 — 원형 44 · 선형 종 · 칩 높이 44 · 눌림

탭 루트(여정 맵 · 롤플레이 · 설정)와 학습 화면이 함께 쓰는 상단 줄(`TopBar`)의 알림 버튼이 **44pt 원형**(아이콘 24 + 안쪽 여백 8 × 2 + 테두리 2 × 2)에 **선형 종**(`@libitums/icons` 0.5.0 `notification-03`, 색 `color.fg.neutral`)으로 서고,
같은 줄의 연속 학습 · 트로피 칩이 **44pt**로 버튼과 높이가 맞는지, 누르면 95 %로 줄고 동작 줄이기에서는 줄지 않고 면만 어두워지는지를 확인하는 **수동 절차**다.
눌림 · 막 규칙은 [ADR-0053](../adr/0053-motion-policy.md) D3 적용 기록 ⟨2026-10-19⟩, 패키지 버전은 [ADR-0014](../adr/0014-design-system-consumption-verified.md) D5 적용 기록 ⟨2026-10-19⟩이 진다.
알림 화면으로 가는 흐름 자체는 [알림 e2e](notifications.md)다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | 칩 클래스(`statChipClassName` — 면 · 높이 갈래) · 눌림 순수 함수(`topBarNotificationsClassName` · `hasTopBarNotificationsShade`) · CSS 텍스트(`top-bar.css` 여백 · 전환 · `:active` scale 토큰 · reduced 규칙 · 막 · 아이콘 24, `stat-chip.css` `touch-target` 세로 여백 8) |
| ui | `TopBar` — 칩 둘의 클래스 · 아이콘 `content` · `current-color` · standard / reduced 렌더의 클래스 · `data-motion` · 막이 첫 자식 · 이름 · 역할 · tap. `StatChip` — `height` 갈래 |
| integration | 실제 App — 세 탭 + 학습 화면의 아이콘 · 칩 클래스(`App.header` NBI1) · reduced 막 · tap → 알림 화면(`App.motion` NBI2) |

**이 문서만 보는 것**: 실제 기기의 크기 · 정렬(픽셀) · 눌림 축소 비율 · 막 색 · 낭독.

## 미확인 · 후속

- **눌림 · 동작 줄이기(NBE3 · NBE4)** — 축소 비율과 막 색을 스크린샷으로 잰다.
- **학습 화면 상단 줄(NBE2)** — 모양은 같은 `TopBar`라 같아야 한다.
- **학습 화면의 알림 버튼은 눌러도 열리지 않는다(이번 변경 전부터)** — `LearningShell`의 `onOpenNotifications` 기본값이 빈 함수라, 버튼이라고 낭독하고 눌림 반응까지 보이면서 아무 일도 하지 않는다.
  이번 변경이 만든 동작이 아니고 고치지 않았다 — 학습 화면에서 알림을 열지, 버튼을 읽기 전용으로 둘지는 후속 결정이다. 이 문서의 NBE3 기대(알림 화면이 열린다)는 여정 맵에서만 본다.
- **VoiceOver(NBE5)** · **롤플레이 · 설정 탭(NBE6)** · **Android(NBA1)**.
