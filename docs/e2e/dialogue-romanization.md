# 대화 · 레슨 문장 로마자 — 기기 확인

결정은 [ADR-0188](../adr/0188-dialogue-romanization.md)이 진다. 자동 테스트(unit · ui · integration)는 변환 규칙 · 원천 고르기 · 줄의 있고 없음 ·
DOM 순서 · 낭독 문자열 · 저장값 → 화면 결선을 지킨다. **실제 글꼴로 그렸을 때 잘리지 않는지 · 작은 화면에서 대화 상자와 버튼이 겹치지 않는지 ·
여덟 화면 언어의 설정 문구 길이**는 기기에서만 판정한다 — 테스트 환경에는 레이아웃 측정이 없다.

## 준비

- 빌드: 이 브랜치의 번들 + `--bundle-url=main.lynx`(로컬 번들). 소리는 먼저 끈다(시뮬레이터 · 에뮬레이터 음소거).
- 기기: iOS 시뮬레이터 작은 화면(iPhone 13 mini 또는 SE 급), Android 에뮬레이터(읽기 전용 · `-no-audio`, `assembleBundled`).
- 새로 설치(저장 키 없음 = 로마자 **켬** 기본)로 시작한다. 저장 키는 `libitum.session-option.show-choice-romanization`(ADR-0108).
- 대상: 튜토리얼 u00 표지 컷(가장 먼저 만나는 대화) · 막간 메신저 · 막간 전화 · 레슨 단어 선택 제시문 · 문화 확인 장면, 그리고 설정 › Learning 토글.
