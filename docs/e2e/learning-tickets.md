**iOS 시뮬레이터 · Android 2026-11-25 — 개정 3, 창 모양만 흉내**: iPhone 17 Pro · iOS 26.5(전용 시뮬레이터, 11-24에 지은 Debug Host 앱에 번들만 넣음) · Android AVD Pixel_8(`-read-only -no-audio`, `assembleBundled`). 가입 · 서버 지급 없이, 진입점이 가입 보상 창만 언어 · 끝 시각 · 손님 여부를 바꿔 차례로 세우게 잠시 바꾼 번들(커밋하지 않음, 탭 없음 — 소리 나지 않음)로 봤다. 두 줄(en 「tomorrow, 9:41 PM」 · vi 「21:41 ngày mai」 · my 「မနက်ဖြန် ညနေ 9:41」) · 손님 이어받기 + 두 줄(「today, 9:05 AM」) · 한 줄(지금 창 그대로)이 두 플랫폼에서 잘림 없이 섰다. Android에서 버마어 엽전 줄 설명이 음절 가운데서 줄이 바뀌어 짧게 고쳤다(「သူငယ်ချင်းများနှင့် ချတ်ပါ။」, 고친 뒤 한 줄 확인 — iOS 버마어 캡처는 고치기 전 문구). 실행 로그에 JS 오류 없음. 실제 가입 · Got it 날기 · 구독 계정 · 스크린리더는 미실행(WG-E1 ~ E5, 통합 테스트 WG-I1 ~ I4의 관찰뿐).
