# 여정 맵 발자국 — 끝낸 유닛 → 다음 유닛 · 클리어 복귀 모션 · 한 열 맵 · 모션 축소

결정은 [ADR-0100](../adr/0100-map-footprints.md)가 진다. 자동 테스트(unit · ui · integration)는 구간 선택 · 기하 · 셀 측정 결선 · 등장 클래스 · 기억 소비를 지키지만, **기기에서 발자국이 실제 유닛 사이에 놓이는지(측정 좌표 · z-order) · 복귀 모션의 타이밍 · 끝낸 에피소드가 여럿일 때의 스크롤 성능**은 기기에서만 판정한다.

## 준비

- iPhone 17 Pro 시뮬레이터 · `pnpm bundle:host` 뒤 Debug 호스트 + `--bundle-url=main.lynx`.
- 끝낸 유닛이 있는 계정(또는 진행 시드) — 에피소드 1의 표지 · 레슨 둘 이상 끝낸 상태가 가장 보기 쉽다.

## 흐름

| id | 조건 · 절차 | 판정 |
|---|---|---|
| EF-1 | 두 열 맵(기본 글자 크기), 끝낸 유닛이 있는 구획 | 끝낸 유닛에서 다음 유닛으로만 발자국(회색 12 × 14, 20px 간격, 좌우 번갈아)이 잇는다. 양 끝은 유닛 가장자리에서 6px 떨어짐. 잠긴 · 미완 구간 · 에피소드 사이에는 없음. 발자국이 유닛 · 라벨 위에 겹치지 않음 |
| EF-2 | 레슨 하나를 끝내고 맵으로 돌아옴 | 그 유닛이 끝남 색으로 선 뒤 약 0.3초부터 발자국이 다음 유닛 쪽으로 하나씩(0.1초 간격) 찍히고, 다음 유닛은 열림 색. 맵을 떠났다 다시 돌아오면 모션 없이 정지 |
| EF-3 | 접근성 글자 크기 최대(한 열 맵) | 한 열에서도 발자국이 유닛 사이(세로)로 잇고 겹침 0 |
| EF-4 | 움직임 줄이기 켬 · EF-2 반복 | 발자국이 한 번에 서고 튕김 없음 |
| EF-5 | 에피소드 3개 이상 끝낸 계정 · 맵 스크롤 | 스크롤이 끊기지 않음(발자국은 스크롤마다 다시 재지 않는다). 맵 진입 시 발자국이 뒤늦게 서도 한 번만 |
| EF-6 | 표지 일러스트가 있는 에피소드(u01 ~ u03) | 표지 → 레슨 1 발자국이 노드 네모 가장자리에서 시작(일러스트 여백 87 반영) |
| EF-7 | Android 에뮬레이터(가능하면) | EF-1 · EF-2 같은 판정 |
