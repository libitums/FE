# 새 에피소드 형식 ② — 문화 카드 · 문화 확인 · 음절 조립 화면과 문화 노드

새 형식의 화면이 없던 유형이 화면을 얻은 뒤 카탈로그 에피소드가 기기에서 **풀리는지**를 확인하는 **수동 절차**다 — 맵의 문화 단계가 `Culture` 노드로 서는지,
그 노드가 문화 카드 셋 → 문화 확인 셋(보기 아래 번역)을 열고 통과 · 실패가 기록에 걸리는지, `Lesson 3`의 음절 조립이 붙여 서고 · 되돌아가고 · 문자열로 판정되는지, 낭독이 무엇을 말하는지.
결정은 [ADR-0066](../adr/0066-episode-format-screens.md), 화면은 [화면 명세](../screens.md) 「여정 탭」의 문화 카드 · 음절 조립 · 카탈로그 레슨 행, 파일 모양은
[콘텐츠 계약](../specs/episode-content-json-contract.md) §6 · §7.2가 진다. PR ①의 흐름(단계 · 완료 키 · 트로피 · 새 유형의 단어 선택 · 대화 조립 화자)은 [새 에피소드 형식 e2e](episode-format.md)가 지고 여기서 되풀이하지 않는다.

> ⟨2026-10-22 — [ADR-0080](../adr/0080-item-audio-and-slow-playback.md)⟩ 아래 unit 행의 **`LISTEN_BUILD` = `audio-missing`은 소리 없는 문항의 것이다** — 소리가 있으면 문장 순서 화면(상대 말풍선 자리에 재생 줄 · 대본 없음)으로 선다. 그 확인은 [학습 문항 음성 e2e](item-audio.md) EU8이다. 음절 조립은 판정 순간 정답 음성을 한 번 낸다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | 세 유형의 매핑(판정 순서 · 보기 번역은 전부 있을 때만) · `LISTEN_BUILD` = `audio-missing` · 철자 탐색(같은 음절 두 장 · 여러 글자 타일) · 음절 리듀서와 문자열 판정 · 카드 걸음 · 계획(`CULT` 채점 3 · 표시 6) · 문화 키 판별 · 노드 role · 한 줄 배치 · 낭독 문자열(칸 수 포함) |
| ui | 문화 카드(줄 순서 · 빈 필드 · 버튼 · `onFinish` 한 번 · 소제목 비요소) · 음절 조립(붙임 · 되돌림 · 칸이 차면 잠김과 `Check` · 정답 상자 · 낱말 줄의 낭독 전환) · 단어 선택 보기 번역 줄과 세로 배치 · 맵 문화 노드(라벨 · 아이콘 · 낭독) |
| integration | 실제 내장본으로 앱을 띄워 — `CULT` 통과(카드 셋 → 확인 셋 → `PERFECT` → 기록 · 이벤트 · `RP` 열림) · `CULT` 실패(`Try again`은 첫 카드부터 · 기록 없음) · `S3`의 음절 조립 섞인 단계 · u02 `일주일`의 두 `일` 바꿔 놓기 · 세 에피소드의 `Culture` 노드와 한 줄 배치 |

**이 문서만 보는 것**: 실제 데이터가 기기에서 그려지는 모습 — 카드의 긴 본문 · 한국어 줄바꿈 · 번역 줄이 든 보기의 높이 · 음절 칸의 모양 · 타일을 누르는 손맛 · 노드의 아이콘과 줄 · 낭독.

## G2 — 카드 덱 + 앞 · 뒤 뒤집기 (2026-10-19) — 미실행

문화 카드 화면이 G2 시안(사용자 선택)으로 바뀌었다 — 덱 위 `n / N` · 뒤 두 장 · 맨 앞 카드의 **앞면**(사진 또는 브랜드 면 위 `CULTURE` · 한국어 제목 · 영어 제목 · `Tap to flip`)과
**뒷면**(한국어 제목 · 로마자 · 영어 본문 · `In Korean` 상자 · 뒤집기 표시) · 점. 카드나 아래 버튼(`Flip card`)이 뒤집고, 뒷면의 버튼(`Next card` · 마지막은 `Next` / `See results`)이 넘긴다.
결정은 [ADR-0072](../adr/0072-culture-card-flip.md). 단위 · ui · 통합 테스트가 면 · 버튼 · 이름 · 동작 줄이기 클래스 · 사진 실패를 덮는다 — **아래는 기기에서만 보이는 것이다.**

전제: 위 「전제」와 같다. 내장 콘텐츠의 `image_url`은 전부 빈 값이라 **사진 카드는 콘텐츠가 주소를 채운 빌드**(예: `content/images/u01-water/cult-1.jpg`)나

## 미확인

- **문화 단계 실패 경로(SS3)** · 통과 뒤 맵에서 `Culture` 끝 · `Final test`가 열리는 순간(SS2 끝) — 새 설치 또는 `S8`까지 끝낸 계정으로.
- **노드의 한 줄 배치 · 열린 상태 아이콘 · 잠김 상태(SS1).**
- **u02 · u03** — 특히 u02 `Lesson 3`의 `일주일`(`일` 두 장)과 `와이파이`(`이` 두 장), 보기 셋이 모두 짧은 u02 문화 확인(`전화번호` · `비밀번호` · `방 번호`)의 세로 배치.
- **고친 뒤의 빌드**: 빈 칸 간격(관찰 ②)과 접근성 수정 A1 · A2가 든 빌드(`c2388169`)를 기기에서 돈 회차가 없다.
- **VoiceOver 실청취(SS5)** — 접근성 감사가 「기기에서만 닫힌다」로 남긴 것을 함께 본다.
  - 잎 `<text>`의 가림 속성이 실기에서 정말 무동작이었는지(A1의 전제 — 고친 뒤에는 `In Korean`이 정지로 잡히지 않아야 한다).
  - 한국어 제목 · 한국어 본문 · **1음절 창고 타일**(`일` · `이` · `괜`)을 VoiceOver(UI 언어 영어, 언어 자동 감지 기본값)가 한국어 음성으로 읽는지. 음절 조립에서는 이것이 곧 문항이 풀리는지를 정한다 — `일`과 `이`가 영어 음성으로 구별되지 않으면 u02 `일주일`을 소리만으로 풀 수 없다.
  - 타일이 창고에서 칸으로 옮겨 간 직후 포커스가 어디에 남는지([문장 조립 e2e](sentence-order.md) E3과 같은 관찰). 낱말 줄이 요소 ↔ 비요소로 바뀔 때(빈 줄 → 첫 타일, 놓는 중 → 채점) iOS가 트리를 다시 읽는지.
  - 문화 카드에서 `Next`를 누를 때 새 카드가 아무 말 없이 바뀌는 것(포커스는 버튼에 그대로, 발화 없음 — 단어 카드와 같다)이 세 장 연속으로 길을 잃게 하는지. 잃게 하면 [ADR-0016](../adr/0016-assistive-technology-semantics.md) D8 후속의 우선순위를 올린다.
  - 칸이 다 찬 동안 창고 타일의 `disabled`가 어떻게 들리는지(ADR-0016 D10 셋째 예외).
  - 글자 배율 2.0 · 320폭에서 문화 카드 한국어 제목이 어떻게 접히는지, 긴 영어 본문이 스크롤 영역보다 클 때 VoiceOver가 읽으며 스스로 스크롤하는지.
