# 태국어 · 미얀마어 화면 문구 — iOS 수동 e2e

[ADR-0158](../adr/0158-story-translations-thai-burmese.md) 개정(2026-11-20)의 기기 확인 절차다. 자동 E2E 러너는 없다([README](README.md)).
글꼴은 시스템 대체 글꼴(타이: Thonburi, 미얀마: Myanmar Sangam MN · Noto Sans Myanmar)이라 **줄 간격 · 잘림**을 눈으로 본다.

## 전제

- 가장 좁은 폭 기기 하나 — **iPhone 13 mini 시뮬레이터**(375pt). 세션마다 새 시뮬레이터를 만들고 끝나면 지운다.
- 번들은 `.env.local` 없는 빌드로 충분하다(비회원 「Continue without an account」 흐름).
- 앱 소리를 끄고 진행한다. 기기 언어는 앱이 읽지 않는다 — 언어는 온보딩 언어 단계 또는 설정 › 언어에서 고른다.

## 절차

| id | 시작점 → 행동 | 관찰할 최종 결과 |
|---|---|---|
| TB-E1 | 새 설치 → Get started → Continue without an account → 이름 · 나라 → 언어 단계에서 `Thai · ภาษาไทย` | 고르는 즉시 제목 · 미리보기 카드 · 단추가 태국어. 성조 표시가 단추 · 제목에서 잘리지 않음 |
| TB-E2 | 여정 입장 화면 → 시작 → 여정 맵 | 입장 제목 · 시작 단추 · 맵 꼭지 이름(`บทนำ`) · 탭 배지(`ใหม่`) 태국어, 배지 알약 안에서 성조 표시가 잘리지 않음 |
| TB-E3 | 설정 탭 · 머리의 엽전 칩 → 상점 | 설정 줄 · 설명 두 줄 태국어. 상점 팩 수 `1,200` · `3,000`(쉼표), 「คุ้มที่สุด」 알약 안에서 잘림 없음 |
| TB-E4 | 메신저 탭 | 제목 · 안내 말풍선 · 단추 태국어 |
| TB-E5 | 설정 › 언어 → `Burmese · မြန်မာ` → 다음 | 언어 화면 · 설정이 미얀마어. 설정 설명 두 줄의 위아래 표시가 서로 닿지 않음(`.app-lang-my` 줄 간격) |
| TB-E6 | 여정 맵 · 상점 · 메신저 탭 | 맵 이름 · 상점 팩 · 메신저 제목 미얀마어, 팩 수 쉼표 묶음 |
| TB-E7 | 메신저 › 추천 친구 하나 → 새 친구 시트 | 소개 · 직업 · 나이 태그 · 첫 말 뜻풀이가 미얀마어, 시트 단추 잘림 없음 |
