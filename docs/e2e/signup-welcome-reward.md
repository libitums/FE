# 수동 e2e — 가입 보상 (ADR-0174)

| id | 확인 | 기대 |
|---|---|---|
| SR-E1 | 손님 · 튜토리얼을 지난 지도 루트 | 바텀 내비 위 12에 크림색 카드(주머니 · 「Get 100 Yeopjeon free」 · 보조문 · Sign up), 주머니가 3초마다 한 번 튐 |
| SR-E2 | 지도를 맨 아래까지 스크롤 | 마지막 유닛이 카드 위로 올라와 가리지 않음 |
| SR-E3 | 말풍선 열기 · 더보기 메뉴 열기 · 메신저 탭 | 그동안 카드 없음, 돌아오면 다시 섬 |
| SR-E4 | 카드 누름 | 로그인 화면(Apple · Google) — 뒤로면 지도 |
| SR-E5 | 새 Google 계정으로 가입 | 지도로 돌아와 보상 모달(주머니 튐 · 엽전 여섯 톡 · +0 → +100 · 「Your guest progress is saved to your account.」), 카드 없음 |
| SR-E6 | Got it | 막 · 상자가 걷히고 엽전 여섯이 머리 칩으로 날아가 닿을 때마다 칩이 오름 → 그 뒤 엽전 출시 모달(튜토리얼을 지났으면) |
| SR-E7 | 앱 재실행 · 같은 계정 다른 기기 | 모달 다시 안 뜸(서버 already_claimed) |
| SR-E8 | 기존 계정으로 로그인 | 모달 없음(existing_account) |
| SR-E9 | 탈퇴 뒤 같은 Google 계정으로 다시 가입 | 모달 없음(identity_used) |
| SR-E10 | 설정 › 손쉬운 사용 › 동작 줄이기 | 카드 주머니 멈춤, 모달은 처음부터 +100 · 톡 없음, Got it이면 날지 않고 닫히며 칩은 최종 값 |
| SR-E12 | 튜토리얼 전 새 계정 | 첫 유닛 안내 동안 모달 없음, 튜토리얼 최종 뒤 지도에서 모달 |
| SR-E11 | VoiceOver / TalkBack | 카드 한 단추 「Get 100 Yeopjeon free. Sign up — your progress comes with you.」, 모달 제목 머리글 · 금액 「+100 Yeopjeon」 |

## 실행 기록
- 2026-11-21 — iPhone 17 Pro 시뮬레이터(iOS 26.5, 전용 기기 · 끝나고 삭제) · Android AVD Pixel_8(`-read-only -no-audio`, `assembleBundled`), `.env.local` 없는 빌드(서버 요청 없음).
  - 통과: SR-E1(손님 카드 — 영어 · 베트남어), SR-E3(더보기 메뉴가 열리면 카드 없음), SR-E4(카드 → 로그인 화면), SR-E10(동작 줄이기 — 모달이 처음부터 +100, Got it이면 날지 않고 닫힘), 첫 유닛 안내 동안 카드 없음.
  - SR-E5 · E6은 로그인이 필요해 커밋하지 않은 임시 프로브(손님 카드 탭 → 모달)로 모달 · 날기 화면만 확인 — 주머니 · 금액 줄 · 손님 문구 · 엽전 여섯이 머리 칩으로 날며 칩 숫자가 오름(두 플랫폼). 프로브 번들 · APK는 지웠다.
  - 이 확인에서 첫 유닛 안내보다 모달이 먼저 걸리면 안내 강조가 모달 위로 올라오는 것을 찾아, 모달을 튜토리얼 뒤로 미뤘다(ADR-0174 D5).
  - 실행 로그(iOS `log stream` · Android logcat)에 JS 오류 없음.
  - 미실행: SR-E2(긴 지도 끝까지 — unit SR-U8이 여백을 지킴), SR-E7 ~ E9 · E12(서버 마이그레이션 운영 적용 뒤), SR-E11(스크린리더 실청취).
