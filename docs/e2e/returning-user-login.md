# 기존 회원 로그인 — 바로 여정 맵 · 새 계정 회귀 · 소셜 로그인 스피너 가운데

서버에 기록이 있는 계정이 새 설치에서 로그인하면 언어 선택 · 여정 입장을 건너뛰고 **곧장 여정 맵**에 들어가는지, 기록이 없는 새 계정은 지금 흐름(언어 선택 → 여정 입장 → 맵)
그대로인지, 소셜 버튼의 로딩 스피너가 **버튼 가운데**에 서는지를 확인하는 **수동 절차**다.
결정은 [ADR-0069](../adr/0069-returning-learner-login.md), 전이 표는 [진입 흐름 계약](../specs/entry-flow.md) §3, 화면은 [화면 명세](../screens.md) 「진입 흐름」이 진다.
진입 흐름 전체의 절차는 [진입 흐름 e2e](entry-flow.md)이고 여기서 되풀이하지 않는다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | 판정 순수(신호 · 경로 · 학습 기록 정의 — RJ) · 조회 경주 상태 기계(가짜 타이머 · 한 번 resolve · 예외는 `unknown` — RP) · 기존 회원 UI 언어 규칙(UL5 ~ UL7) · 이벤트 팩토리(EF7) · 분석 · Airbridge 표 · 소셜 스피너 덮어쓰기 없음(CSS 문자열 — LC1 ~ LC3) |
| integration | `App.returning-login.integration.test.tsx` RL1 ~ RL12 — 두 신호 각각 · 신규 흐름 가드 · 실패 넷 · **시간 초과**(3초 직전까지 `requesting` 유지 → 언어 선택, 늦은 기록은 무시) · 전화 경로의 `verifying` 유지 · UI 언어 저장 · 알림 등록 1회 · 프로필 동기화가 판정 뒤 · 세션 갱신 부팅 회귀 |

**이 문서만 보는 것**: 실제 Supabase 서버 기록으로 갈리는 경로 · 기다리는 동안의 실제 모습과 체감 대기 · 시스템 알림 다이얼로그 · 기기에서 그려지는 스피너 자리 · 접근성 트리의 이름.

**한계(먼저 읽는다)**:

- 시뮬레이터에 VoiceOver가 없다 — 로딩 중 버튼 이름(`<라벨>, loading`)은 접근성 검사기로 보고, 발화는 `판정 불가`로 적는다.
- **시간 초과 · 판정 실패는 실제 망에서 재현 수단이 없다** — 통합 RL5 · RL6이 진다. 이 문서는 정상 망의 두 갈래만 본다.
- 소셜 제공자 설정이 막혀 실제 로그인을 지날 수 없으면([공통 전제](README.md#공통-전제) 「초기 심사 빌드」) RUE1 · RUE2 · RUE4는 `판정 불가 — 로그인 수단 없음`으로 적고 RUE3 · RUE5만 돈다.
- 기기의 언어 설정은 결과에 영향이 없다 — 호스트가 기기 언어를 넘기는 경로가 없고 고를 수 있는 언어가 영어뿐이다(ADR-0069 D5). 기기 언어를 바꿔 보는 행을 두지 않는다.

## 전제

- [공통 전제](README.md#공통-전제) — 자체 호스트 앱. 이 문서는 **로그아웃 상태(새 설치)에서 시작한다.**
- iOS: iPhone 17 Pro 시뮬레이터(전용 기기), **Release** Host + 이 브랜치의 내장 번들(`--bundle-url=main.lynx`). Debug는 `localhost:3000`의 다른 작업 트리를 읽을 수 있다([README 「자동화」](README.md#ios)).
  `apps/mobile/.env.local`의 Supabase 값이 있어야 로그인 요청이 열린다(값은 기록에 적지 않는다).
- 실제 Supabase 프로젝트. 계정 둘:
  - ⓐ **기존 계정** — 서버에 학습 진행 기록(끝낸 유닛 하나 이상)이 있는 Google 또는 Apple 계정. Apple은 서명 빌드가 필요하다.
  - ⓑ **새 계정** — 한 번도 로그인한 적 없는 계정(진행 · 학습자 프로필 행 모두 없음).
- **회차마다 앱 삭제 → 재설치.** ⓑ로 한 번 언어 선택까지 가면 그 계정은 다음부터 기존 회원일 수 있다(온보딩에서 이름을 적었다면 프로필 행이 생긴다 — ADR-0069 대가 7). ⓑ는 회차마다 새로 만든다.
- 회차마다 **빌드 commit · 빌드 설정(Release · CI/로컬 설정) · 확인자 · 시뮬레이터 UDID**를 적는다.
- 증거 이름: `returning-user-login-ios-RUE<n>-<상황>-<회차>.png`(화면 녹화는 같은 이름의 `.mov`).

## 관찰 항목 (RUE1 ~ RUE5)

통과·실패는 `통과` / `실패: <관찰>` / `판정 불가: <이유>` / `미확인`으로만 적는다.

| id | 시작점 → 행동 | 관찰(통과 조건) |
|---|---|---|
| RUE1 | ⓐ 새 설치 → 온보딩(넷째 스텝 이름 · 나라는 비움) → 소셜 로그인 | 인증 창이 닫힌 뒤 누른 버튼이 로딩(스피너 · 라벨과 로고 숨김)인 채 기다린다 → **여정 맵**이 곧장 선다 · 언어 선택(`language-select-screen-title`) · 여정 입장(`journey-entry-screen-*`)이 한 번도 보이지 않는다 · 맵이 그 계정의 진행(끝낸 유닛 표시)을 보인다 · 바텀 네비게이터가 선다 · 알림 권한 시스템 다이얼로그가 **맵 위에 한 번** 뜬다 · 문구가 영어다. **대기 시간**(인증 창이 닫힌 프레임 → 맵이 선 프레임)을 화면 녹화로 적는다 — 3초 이하 기대 |
| RUE2 | ⓑ 새 설치 → RUE1과 같은 행동 | **언어 선택**이 선다 → `Continue` → **여정 입장** → `Start` → 여정 맵 · 알림 다이얼로그가 한 번(진입 흐름 e2e T6 · T7과 같다 — 회귀). 대기 시간(인증 창 닫힘 → 언어 선택)도 적는다 |
| RUE3 | 로그인 화면에서 Apple · Google · Facebook을 각각 누른다 — 인증 창이 열리기 전 · 창이 닫힌 뒤 교환 · 판정 동안 요청 중 캡처(짧으면 macOS Network Link Conditioner `3G`로 늘린다) | **스피너 중심 x = 버튼 면 중심 x ± 1 css px · 중심 y = 면 중심 y ± 1 css px**([모션 토큰 e2e](motion-tokens.md) M5-I4의 측정법) · 로고 · 라벨 픽셀 0 · 면 폭 · 높이가 누르기 전과 ± 1 px. 수정 전 빌드(`587318e5`)의 캡처와 나란히 둔다(그 빌드는 스피너가 왼쪽 위 모서리) |
| RUE4 | RUE1 뒤 앱을 완전히 종료 → 다시 연다 | 스플래시가 세션 갱신 왕복 뒤 곧장 맵(세션 갱신 경로 회귀) · 알림 다이얼로그가 다시 뜨지 않는다 |
| RUE5 | (접근성 검사기) RUE3의 요청 중 버튼 | 버튼 이름이 `<라벨>, loading` 하나이고 Not enabled가 아니다 · 스피너가 따로 요소로 잡히지 않는다. 발화는 `판정 불가 — VoiceOver 없음` |

Android: 네이티브 변경이 없고 CSS는 같은 Lynx 레이아웃이라 절차를 따로 두지 않는다(unit · integration이 덮는다). Android Lynx에서 전면 `absolute` 래퍼의 가운데 정렬은
[모션 토큰 e2e](motion-tokens.md) M2-A3이 소셜 버튼으로도 볼 수 있는 자리다 — 이 변경으로 소셜 버튼도 기본 래퍼를 쓴다.
