# 스페셜 유닛 — 맵의 스페셜 항목 모양 · 상태 · 낭독 이름

여정 맵의 스페셜 항목(튜토리얼 표지 · 메신저 · 전화 · 비주얼 노벨 · 최종 테스트, 카탈로그의 표지 · `Culture` · `Final test`)이
레슨 노드와 **다른 모양(둥근 사각 면 · 두께 · 흰 오각 별 · 두 줄 라벨)** 으로 서고, 상태(잠김 · 열림 · 끝 · 확인 중)와 눌림이
기기에서 계약대로 그려지는지를 확인하는 **수동 절차**다. 컴포넌트는 ui-lynx `SpecialUnit`, 맵 공유 항목은 `SpecialUnitMapItem`이다.
화면 명세는 [화면 명세](../screens.md) 「여정 탭」, 동작 줄이기는 [동작 줄이기 e2e](motion-reduced.md), 진행 확인 중 상태는
[진행 저장본 e2e](progress-cache-first.md)와 이어진다.

| 이미 지는 층 | 무엇을 |
| --- | --- |
| unit | 상태 → 클래스 · 접미사 · traits · 아이콘 색 · 막 조건 · 맵 상태 표 · 라벨 톤 · 낭독 이름 · CSS 규칙 |
| ui | `SpecialUnit` · 맵 공유 항목 · 어댑터 일곱 · 맵 화면 노드 종류 · 안내 말풍선 · 확인 중 · Storybook |
| integration | 실제 내장 데이터로 앱을 띄워 — 새 설치 부팅 · 잠김 가드 · 열림 · 끝 · 카탈로그 표지 · 낭독 이름 |

**이 문서만 보는 것**: 면 · 두께 · 별 · 라벨의 색과 배치가 기기 렌더에서 계약과 같은가, 눌림 이동과 동작 줄이기 상태의 명도 변화,
스페셜 자리의 크기(124)와 줄 간격, 접근성 검사기에서 보이는 이름 · traits.

## 한계

- **VoiceOver가 시뮬레이터에 없다.** 이름은 접근성 검사기(Accessibility Inspector)로 보고, 실제 **발화는 `판정 불가`** 로 적는다.
- **키보드 focus ring은 기기에서 볼 수 없다.** 맵이 `focused`를 넘기지 않는다(맵에 키보드 focus를 넘기는 호스트 경로가 없다). ring은 Storybook과 ui 테스트로만 확인한다.
- 통과·실패는 `통과` / `실패: <관찰>` / `판정 불가: <이유>` / `미확인`으로만 적는다.

## 진행 씨앗 ⓐ ~ ⓒ

진행은 계정(서버 `learning_progress`)에 남고 기기 저장본이 앞선다. 씨앗을 바꿀 때는 앱을 삭제 · 재설치하거나 계정을 바꾼다.
서버 쪽 직접 수정으로 만드는 길은 이 기능에서 실행해 본 적이 없다 — 첫 회차가 확정한다(쓰면 방법을 회차에 적는다).

| 씨앗 | 상태 | 만드는 법 |
| --- | --- | --- |
| ⓐ 새 설치 | 튜토리얼 표지(`Episode intro`)만 열림, 나머지 스페셜 넷은 잠김 | 앱 삭제 → 재설치 → 로그인. 진행이 없는 계정이어야 한다 |
| ⓑ 튜토리얼 표지 끝 | 메신저 · 전화 · 비주얼 노벨 열림, 표지는 끝 | ⓐ에서 표지를 눌러 표지 화면의 `Next`를 끝까지 지나(또는 `Skip` 확인) 맵으로 돌아온다 |
| ⓒ 튜토리얼 최종 통과 + u01 일부 | 카탈로그 표지 끝(또는 열림) · `Culture` 열림 또는 끝 · `Final test` 잠김 또는 열림 | 튜토리얼 최종 테스트를 통과한 계정으로 u01 표지를 끝낸다. `Culture`까지 풀면 `Final test`가 열린다([문화 · 조립 화면 e2e](episode-format-screens.md) 참고) |

## 증거 파일 이름

`docs/e2e/evidence/special-unit-ios-SUE<n>-<상황>-<회차>.png` — 예: `special-unit-ios-SUE2-available-clear-1.png`.
상황은 `locked` · `available` · `clear` · `checking` · `pressed` · `reduced` 같은 짧은 영어 낱말을 쓴다. 한 행에 여러 장이면 상황으로 가른다.

## 관찰 항목 (SUE1 ~ SUE6)

| id | 시작점 → 행동 → 관찰 |
| --- | --- |
| SUE1 | ⓐ 맵 → 표지 둘레의 **안내 말풍선**이 그대로 서고 표지 라벨 두 줄(`SPECIAL` · `Episode intro`)이 흰색 · 스크림 위로 들림 → 말풍선 탭 → 표지 화면. 메신저 등 넷은 회색 둥근 사각 + 흰 오각 별 + 아래 · 오른쪽 짙은 회색 두께, 라벨 회색 · 탭해도 무반응 |
| SUE2 | ⓑ 맵: 열린 셋은 주황 면 · 진한 주황 두께 · 흰 별, `SPECIAL` 주황 글자 + 검은 제목; 끝낸 표지는 초록 면 · 짙은 초록 두께, `SPECIAL` 짙은 초록. **자물쇠 · 체크 · 배지 · 종류별 아이콘이 어디에도 없다**; 스텝 노드는 원형 그대로(자물쇠 · 체크 있음). 스페셜 자리가 레슨보다 크고(124) 줄 간격 · 칸 배치는 그대로 |
| SUE3 | ⓒ 카탈로그 구획: 표지 · `Culture` · `Final test`가 스페셜(잠김 · 열림 · 끝 중 있는 상태 전부 촬영), `Lesson n`은 원형 |
| SUE4 | 접근성 검사기로 SUE2 · SUE3의 이름: `special, A Message from Minseo` · `special, Episode intro, completed` · `special, Episode 1. Final test, locked` · traits(Button / Not enabled) · 별 · 라벨이 따로 요소로 잡히지 않음(항목당 정지 하나). 발화는 `판정 불가` |
| SUE5 | 동작 줄이기 **끈** 상태: 열린 스페셜을 누른 채 → 면이 오른쪽 아래로 내려앉아 두께가 사라짐 · 떼면 돌아옴(**보간이 보이는지 / 즉시 이동인지** 기록) · 라벨 · 이웃 불변. **켠** 상태(설정 › 손쉬운 사용 › 동작 › 동작 줄이기, 켜고 재실행): 이동 없이 면이 한 단계 어두워짐(합성 #E06216 / #319966 ±2 — 스크린샷 픽셀) |
| SUE6 | 진행 확인 중(네트워크 끔 + 저장본 없는 새 설치 — [진행 저장본 e2e](progress-cache-first.md) 절차): 스페셜이 연회색 면 · 더 연한 별 · 두께 없음 · 라벨 회색 · 탭 무반응 → 네트워크 켜면 해당 상태로 바뀜 |

SUE5의 보간은 보간이 안 돌아 즉시 이동이어도 결과 위치가 같으므로 정본 위배가 아니다 — 어느 쪽이었는지만 적는다.

## Android

네이티브 변경이 0이라 Android 절차는 두지 않는다 — CI의 unit · ui · integration이 덮는다.

## 미확인

- **Android Lynx의 `translate` 보간**(눌림 이동이 부드럽게 도는지)과 **둥근 view 겹침**(면 · 두께 · 별이 겹쳐 그려지는 모양)은 Android에서 본 적이 없다.
- VoiceOver 발화 · 키보드 focus ring(위 「한계」).
- 글자 크기 · 두 열 폴백에서의 스페셜 자리 모양.
