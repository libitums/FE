# 초급 튜토리얼 이야기·복습

관련 스펙: [tutorial-story-review](../specs/tutorial-story-review.md)

1. 진척 0, 프롤로그 미완료 상태에서 첫 인사와 최종 테스트가 잠긴 것을 확인한다.
2. 기내 프롤로그의 VN·메신저·전화·기내 복귀를 끝내고 결과의 Check로 돌아온다.
3. 인사·이름·주문·약속 일반 유닛을 각 한 문항으로 완료한다.
4. Appointment message에서 뜻·발음 안내와 한 개 답장을 확인한다. 선택 후 Send를 눌러 두 답장을 보내고 결과를 확인한다. 한글 자판은 나오지 않는다.
5. Appointment call에서 각 음원을 수동 재생한다. 안녕하세요 / 저는 지민이에요. / 내일 만나요가 화면 대사와 일치해야 한다. 재생 종료 후 답장의 뜻·발음을 읽고 선택해 3턴을 마친다.
6. 카페 이야기를 세 장면까지 읽는다. 한국어·뜻·발음이 보이고 마지막에 다시보기/나가기가 동작한다.
7. 길 묻기를 끝내면 최종 테스트가 열린다. 세 문항 모두 로마자 표기가 있는 세 보기이고 배운 다섯 표현 밖의 한국어가 없다. 인사 → 물 주문 → 내일 인사를 선택한다.
8. 결과 확인 후 맵의 최종 유닛이 clear이며 롤플레이가 열린다. 발화/손글씨 권한 요청은 없다.
9. 최종 테스트에서 오답을 선택하면 정답을 보여 준 뒤 다음으로 넘어가며 결과에 오답을 유지한다. 중도 나가기 시 완료로 저장하지 않는다.

자동 검증: App.tutorial-journey.integration.test.tsx가 외부 인증·네이티브 오디오만 대역하고 제품 데이터와 내비게이션으로 1–8을 수행한다. 기존 최종 테스트·메신저 UI 테스트가 오답·이탈·재진입을 보완한다.

네이티브 화면 검토: playground의 tutorial-specials는 메신저 → 전화 → 카페 → 최종 복습을 연결한다. 완료 저장·해금은 App 통합 테스트 대상이다.
