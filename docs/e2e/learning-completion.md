# 일반 활동 진행률과 완료 화면

2026-09-30 기준 공통 흐름입니다. 듣기·문장 순서·단어 선택·말하기·쓰기에 적용합니다.

## 확인 절차

1. 문항 3개인 활동을 엽니다. Lesson 1 / 3과 막대 약 33%를 확인합니다.
2. 답하고 Next로 이동할 때 Lesson 2 / 3, 약 67%를 확인합니다.
3. 마지막 문항에서는 답변 전부터 Lesson 3 / 3, 100%입니다.
4. 마지막 답변 후 Next를 누릅니다. N/N과 100%가 유지되고 문제 지시문이 사라집니다.
5. 체크 아이콘, All questions done, 다음 단계 안내, 3 of 3 questions completed가 보입니다. 이전 문제의 정답·오답 배지는 없어야 합니다.
6. See results를 누르면 기존 결과 전달이 한 번만 발생합니다. 제품에서는 기존 활동/평가 라우팅을 유지합니다.
7. 첫 일반 유닛 Your First Hello도 확인합니다. 문항과 완료 화면 모두 1/1, 100%이며 완료 요약은 1 of 1 question completed입니다.
8. 빈 활동 픽스처에서는 순번과 문항 수 요약 없이 0%입니다. 완료 카드와 결과 보기 동작은 유지됩니다.

## 실행 기록

iPhone 17 Pro / iOS 26.5 개발 playground에서 7번과 완료 후 맵 복귀를 확인했습니다. 체크 아이콘·카드·하단 버튼이 겹치지 않고 하단 safe area가 유지됩니다. playground의 See results는 맵으로 직접 돌아갑니다.
3문항의 비율과 빈 활동, 다섯 활동의 완료 전이는 자동 unit/UI 테스트로 확인했습니다. VoiceOver 실제 낭독과 Android 렌더링은 이번 실행에서 확인하지 않았습니다.


## 오프라인 날짜 복구 (ADR-0035 D6)

운영 배포 전 `20261001010000_replay_learning_days.sql` 적용 여부를 먼저 확인한다. 테스트용 계정과 실기기에서 다음을 수행하고 실제 실행 결과를 출시 기록에 남긴다.

1. 로그인 후 네트워크를 끊고 학습 활동 하나를 완료한다. 화면 진행은 유지돼야 한다.
2. 앱을 완전히 종료한 뒤 다시 열어 진행이 보존되는지 확인한다.
3. 연결을 복구하면 추가 활동 없이 진행과 완료 날짜가 서버에 반영돼야 한다. 오프라인 학습이 여러 날이면 원래 날짜 각각을 보존한다.
4. 같은 완료를 다시 보내도 서버 날짜 행이 중복되지 않아야 한다. 현재 날짜 기준 연속만 표시하고 과거 기록 복구만으로 축하 모달을 띄우지 않는다.
5. 전송 실패 상태에서 로그아웃 후 다른 계정으로 로그인한다. 이전 계정의 날짜가 새 계정에 저장되면 안 된다. 원래 계정으로 다시 로그인하면 재전송한다.
6. 폐기 가능한 테스트 계정을 삭제하면 서버 진행/날짜 및 기기 미전송 기록이 함께 없어져야 한다. 실제 사용자 계정으로 삭제 테스트를 하지 않는다.

앱 시간을 임의로 바꾸는 대신 날짜 이동은 자동 통합 테스트에서 검증한다. 실기기에서 여러 날짜의 실제 오프라인 사용을 검증하지 않았다면 그 항목을 통과로 적지 않는다.
