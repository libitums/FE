# 에피소드 표지 일러스트 — 여정 맵 노드 뒤 일러스트 · 좌우 번갈아 · 잠김 흐림 · 한 줄 라벨

결정은 [ADR-0099](../adr/0099-episode-cover-illustration.md)가 진다. 자동 테스트(unit · ui · integration)는 매니페스트 `cover`의 디코드 · 내장 폴백 · 홀짝 → 좌우 · 표지 노드의 그림 요소 · 클래스 · 낭독 제외 · 앱 세션의 번들 · 원격 주소를 지키지만, **기기에서 그림이 실제로 노드 뒤에 서는지(z-index · overflow) · 번들 webp가 오프라인에서 뜨는지(iOS 리소스 · Android `asset:///` 재작성) · 큰 글꼴 한 열 배치의 잘림 · 스크롤 성능**은 기기에서만 판정한다.

## 준비

- iPhone 17 Pro 시뮬레이터 · `pnpm bundle:host` 뒤 Debug 호스트 + `--bundle-url=main.lynx`(다른 작업 트리의 3000 포트를 피한다 — [호스트 실행 메모](../../apps/ios/README.md)).
- 내장 일러스트: `apps/mobile/src/assets/content/covers/` u01 ~ u06(780 × 582). u07 ~ u10은 아직 없다 — 노드만 선다.
- 판정: 스크린숏 · Accessibility Inspector · Proxyman(버킷 요청).

## 흐름

| id | 조건 · 절차 | 판정 |
|---|---|---|
| EC-1 | 로그인 뒤 여정 맵, 에피소드 1 ~ 6 구획까지 스크롤 | u01 · u03 · u05 표지 뒤 일러스트가 노드 **오른쪽 위**, u02 · u04 · u06은 **왼쪽 위**에 선다(노드는 각각 왼쪽 · 오른쪽 — 파일명 `_left` · `_right`). 노드(네모) x 위치는 같은 구획의 Final test 노드와 같다. 일러스트가 노드 위로 겹치지 않는다(노드 · 자물쇠 · 별이 온전히 보임). 표지 라벨은 한 줄 「Intro」, 열린 표지는 주황(#F46B18) |
| EC-2 | 잠긴 에피소드(앞 에피소드 미완)의 표지 | 일러스트가 흐리고(불투명도 .45) 노드는 회색 자물쇠, 라벨 회색. 끝낸 표지는 원색 + 초록 체크 + 주황 라벨 |
| EC-3 | 열린 표지 탭 → 표지 화면 → 컷 → 맵으로 돌아옴 | 크래시 0. 돌아온 맵에서 일러스트 · 노드 겹침 0. 표지 탭 영역은 노드(일러스트의 빈 자리를 눌러도 반응 없음) |
| EC-4 | 접근성 글자 크기 최대(한 열 맵) | 노드가 열 가운데 그대로, 일러스트 가장자리가 잘려도 노드 · 라벨은 온전. 겹침 0 |
| EC-5 | 네트워크 차단(Wi-Fi 끔) · 앱 재실행 | u01 ~ u03 일러스트가 보인다(내장). Proxyman에 `images/covers/` 요청 0 |
| EC-6 | VoiceOver로 표지 노드 순회 | 일러스트는 포커스 받지 않음. 표지 낭독 「special, Episode 1. Intro, …」 |
| EC-7 | Android 에뮬레이터(가능하면 — `ANDROID_HOME` · 전용 에뮬레이터) | EC-1 · EC-2 · EC-5 같은 판정. 그림은 `/static` → `asset:///` 재작성([ADR-0051](../adr/0051-android-image-url-redirect.md)) |
