# 초급 튜토리얼 일반 유닛

2026-09-30. 기존 듣기·말하기·쓰기 흐름 문서는 범용 학습형 회귀에만 적용합니다. 현재 튜토리얼 경로는 아래와 같습니다.

| 유닛 | 표현 | 조작 |
| --- | --- | --- |
| Your First Hello | 안녕하세요 | 전체 표현 한 번 선택 |
| Asking names | 이름이 뭐예요? | 전체 표현 한 번 선택 |
| Ordering | 물 주세요 | 안내대로 물 → 좀 → 주세요 (조각 셋) |
| Making plans | 내일 만나요 | 예문을 보며 내일 → 만나요 |
| Asking for directions | 역이 어디예요? | 뜻과 예문을 보며 역이 → 어디예요? |

1. 맵에서 현재 일반 유닛을 열고 Start를 누릅니다. 모든 유닛은 1/1이며 막대는 100%입니다.
   - ⟨2026-10-09⟩ **처음 열면 안내가 먼저 뜰 수 있습니다 — 탭 한 번으로 닫고 2번부터 진행합니다.** 첫 문항의 칩이
     하나뿐인 유닛을 이 기기에서 처음 열면 화면 전체를 덮는 어두운 안내(끝 줄 `Tap anywhere to continue`)가 뜨고,
     떠 있는 동안 칩은 눌리지 않습니다. 아무 데나 한 번 탭하면(Android는 시스템 뒤로가기 한 번도 같습니다) 안내만
     닫히고 문항은 그대로입니다 — 그 탭은 아래의 칩이나 `×`를 누르지 않습니다.
   - **기록이 있으면 뜨지 않습니다.** 닫은 기록은 기기에 남아, 같은 기기에서는 문장 만들기 전체를 통틀어 한 번만
     뜹니다(같은 모양의 둘째 유닛 · 재진입 · 앱 재실행 · 로그아웃 뒤에도 안 뜹니다). 앱을 지웠다 깔면 다시 뜹니다.
     칩이 둘 이상인 유닛에서는 뜨지 않습니다.
   - 어느 유닛의 첫 문항이 칩 하나인지는 위 표가 아니라 문항 데이터가 정합니다
     ([ADR-0054](../adr/0054-learning-item-guides.md) D1). 칩 하나인 유닛은 `Your First Hello` · `Asking names`이고,
     `Ordering`은 칩 셋(`주세요` · `물` · `좀`), `Making plans`는 칩 둘이라 안내가 뜨지 않습니다.
   - ⟨2026-10-09 정정⟩ 위 표의 「조작」 열은 2026-09-30의 기록이라 `Ordering`을 두 조각으로 적었습니다 — 기기와 다릅니다.
     [학습 문항 안내 e2e](learning-item-guides.md)의 r03 재실행이 Android 에뮬레이터에서 맵의 `Ordering`을 열어
     문항 `Tap 물, then 좀, then 주세요 to say 'Water, please.'`와 조각 셋을 확인했고 안내는 뜨지 않았습니다.
     같은 문서의 첫 실행이 「`Ordering` 자리에서 칩 하나가 열려 안내가 떴다」고 적은 것은 노드 식별 오류였습니다
     (그때 연 노드는 `Asking names`였습니다).
   - 안내의 문구 · 모습 · 판정은 [학습 문항 안내 e2e](learning-item-guides.md)의 E1 ~ E3 · E7이 집니다.
2. 한국어 예문 아래 로마자·영어 뜻이 보입니다. 안내 문구와 칩이 잘리지 않는지 봅니다.
3. 칩은 1~3개(`Ordering`은 셋)이고 오답용 칩이 없습니다. 순서를 바꾸려면 선택한 칩을 눌러 되돌릴 수 있습니다.
4. 정답대로 선택 → Check → Correct → Next → 공통 완료 카드 → See results로 이동합니다.
5. 제품 앱은 PERFECT LESSON!과 함께 맵에서 해당 유닛을 완료 처리하고 다음 일반 유닛을 엽니다. 개발 playground에서는 See results가 맵으로 바로 돌아갑니다.
6. 조각이 둘 이상인 유닛에서 순서를 거꾸로 제출한 경우 실패 결과를 확인하고 재시도합니다. 미통과로 다음 유닛이 열리면 안 됩니다.
7. 마이크·손글씨·긴 듣기 문제는 일반 튜토리얼에서 열리지 않습니다. 중간 스페셜과 Final test는 이번 변경 범위 밖입니다.

## 확인 범위

iPhone 17 Pro / iOS 26.5 playground에서 이름 묻기 한 문장 선택·완료와 주문하기 두 조각 조합·정답을 확인했습니다.
제품의 다섯 유닛 완료·결과·다음 일반 유닛 해제는 App 통합 테스트로 검증합니다. Android와 VoiceOver 실제 낭독은 미확인입니다.

⟨2026-10-09⟩ 위 확인은 학습 문항 안내가 들어오기 전의 것입니다. 위 「주문하기 두 조각 조합」은 당시의 기록 그대로이며, 기기의 `Ordering`은 조각이 셋입니다(1번의 정정). **이 문서의 단계는 안내가 들어온 뒤 다시 돌려진 적이 없습니다** — 1번의 안내 닫기는 이 흐름으로 실행해 본 것이 아니라 ADR-0054와 학습 문항 안내 e2e의 기록(Android 에뮬레이터 한 대, iOS 미실행)에서 옮긴 것입니다.
