# 초급 튜토리얼 일반 유닛

2026-09-30. 기존 듣기·말하기·쓰기 흐름 문서는 범용 학습형 회귀에만 적용합니다. 현재 튜토리얼 경로는 아래와 같습니다.

| 유닛 | 표현 | 조작 |
| --- | --- | --- |
| Your First Hello | 안녕하세요 | 전체 표현 한 번 선택 |
| Asking names | 이름이 뭐예요? | 전체 표현 한 번 선택 |
| Ordering | 물 주세요 | 안내대로 물 → 주세요 |
| Making plans | 내일 만나요 | 예문을 보며 내일 → 만나요 |
| Asking for directions | 역이 어디예요? | 뜻과 예문을 보며 역이 → 어디예요? |

1. 맵에서 현재 일반 유닛을 열고 Start를 누릅니다. 모든 유닛은 1/1이며 막대는 100%입니다.
2. 한국어 예문 아래 로마자·영어 뜻이 보입니다. 안내 문구와 칩이 잘리지 않는지 봅니다.
3. 칩은 1~2개이고 오답용 칩이 없습니다. 순서를 바꾸려면 선택한 칩을 눌러 되돌릴 수 있습니다.
4. 정답대로 선택 → Check → Correct → Next → 공통 완료 카드 → See results로 이동합니다.
5. 제품 앱은 PERFECT LESSON!과 함께 맵에서 해당 유닛을 완료 처리하고 다음 일반 유닛을 엽니다. 개발 playground에서는 See results가 맵으로 바로 돌아갑니다.
6. 두 조각을 거꾸로 제출한 경우 실패 결과를 확인하고 재시도합니다. 미통과로 다음 유닛이 열리면 안 됩니다.
7. 마이크·손글씨·긴 듣기 문제는 일반 튜토리얼에서 열리지 않습니다. 중간 스페셜과 Final test는 이번 변경 범위 밖입니다.

## 확인 범위

iPhone 17 Pro / iOS 26.5 playground에서 이름 묻기 한 문장 선택·완료와 주문하기 두 조각 조합·정답을 확인했습니다.
제품의 다섯 유닛 완료·결과·다음 일반 유닛 해제는 App 통합 테스트로 검증합니다. Android와 VoiceOver 실제 낭독은 미확인입니다.
