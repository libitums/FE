# 카탈로그 에피소드 음성 (컷 · 최종 테스트)

카탈로그 에피소드의 표지 컷 · 통과 뒤 컷 · 최종 테스트에서 음성이 **공개 버킷에서 스트리밍돼 나는지**, 언제 멈추는지, 실패하면 조용히 무음인지를 기기에서 확인하는 **수동 절차**다.
결정은 [ADR-0060](../adr/0060-episode-voice-remote-audio.md), 화면은 [화면 명세](../screens.md) 「여정 탭」의 카탈로그 표지(컷) · 카탈로그 최종 테스트 · 통과 뒤 컷 행,
음성 id와 버킷 업로드 현황은 [콘텐츠 계약](../specs/episode-content-json-contract.md) 부록 C가 진다.

> ⟨2026-10-16 — 데이터 교체⟩ **내장 에피소드 셋이 새 형식(version `2026-10-15.1`)으로 바뀌었다**([ADR-0061](../adr/0061-episode-format-additions.md)). 음성 id 14개는 새 본문의 **같은 자리**에
> 문장 대조로 다시 붙었다([ADR-0060](../adr/0060-episode-voice-remote-audio.md) 적용 기록) — 아래 절차의 컷 번호 · 턴과 기대 소리는 그대로다. 달라진 것: **u01 대화가 9줄**이다
> (seq 7에 녹음 없는 「감사합니다. 안녕히 가세요.」가 끼고 옛 seq 7 · 8이 8 · 9로 밀렸다 — id가 붙은 seq 1 ~ 5는 그대로). 「전제」의 「레슨을 모두 끝낸 계정」은 이제 `S1` ~ `S8`과 문화 단계 `CULT`(누르면 곧장 끝난다)까지다.
> 아래 회차(2026-10-14)는 옛 내장본 빌드의 것이다. 새 내장본으로 소리를 확인한 회차는 아직 없다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | id → 주소(규약 · 자리표시자 · 거부), 컷 `audio_url` 디코드, 내장 데이터의 id 배치 · version, 컷 · 최종 테스트의 「지금 나야 할 소리」 계산, 대화 줄 찾기(`line_id`) |
| ui | 재생 훅(key가 바뀔 때만 재생 · 정리에 정지), 컷 화면 · 최종 테스트 화면의 재생 · 정지 시점(다음 · 정답/오답 · 다음 턴 · 나가기 · 언마운트), 실패에도 흐름이 같음 |
| integration | 앱을 띄워 내장 u01 → 표지 컷 · 최종 테스트에서 재생 모듈에 실제 버킷 주소가 순서대로 닿는 것, 소리 실패에도 진행 기록이 같은 것, u02 컷 소리 |
| 네이티브 | iOS HostTests `AudioPlaybackModuleTests`(원격 판정 · 번들 id · 빈 이름 거부 · 닿지 않는 https의 `done` 한 번), Android JVM `AudioRemoteSourceTest` |

**이 문서만 보는 것**: 실제로 **들리는지** — 원격 스트리밍(범위 요청 · MIME) · 첫 소리까지의 지연 · 효과음과의 겹침 · 오프라인 무음 진행 · 무음 스위치 · 보조기술과의 겹침.
Maestro 흐름은 두지 않는다 — 소리를 판정할 수 없고, 기존 흐름이 카탈로그 컷을 지나지 않는다.

## 전제

- [공통 전제](README.md#공통-전제) — 자체 호스트 앱, 로그인된 상태.
- iOS: iPhone 17 Pro 시뮬레이터, Release Host + 내장 번들(`--bundle-url=main.lynx`)([README 「자동화」](README.md#ios)). 실기라면 무음 스위치를 끈다.
- `apps/mobile/.env.local`에 Supabase 값이 있어야 음성 주소가 만들어진다(설정이 없으면 늘 무음이다). 값은 기록에 적지 않는다.
- 버킷 `content`에 음성 14개가 올라가 있어야 한다(콘텐츠 계약 부록 C 「재사용 · 업로드 현황」).
- 최종 테스트(S6 ~ S8)는 그 에피소드의 레슨을 모두 끝낸 계정이 필요하다.
- 요청이 나갔는지는 Supabase 대시보드의 로그(`edge_logs`)에서 `content/audio/` 경로의 요청 · 응답 코드로 본다. **요청이 나간 것은 들린 것이 아니다** — 청음은 사람이 귀로 판정한다.

## 관찰 항목 (S1 ~ S10)

통과·실패는 `통과` / `실패: <관찰>` / `판정 불가: <이유>` / `미확인`으로만 적는다.

| id | 단계 | 관찰(통과 조건) |
|---|---|---|
| S1 | 맵 → u01 표지 화면 → `Next` → 컷 3 | 문소리 장면에서 「어서 오세요.」가 들린다(`audio/u01-water/pre-3.m4a`). 타자기 · 버튼 · 번역 토글은 소리 없을 때와 같다. 표지 화면에서는 소리가 없다 |
| S2 | 컷 3에서 소리가 끝나기 전 `Next`(타자기 도중이면 두 번) | 타자기 도중 첫 `Next`는 글만 마저 보이고 **소리는 계속**, 컷이 넘어가는 탭에서 소리가 끊긴다. 컷 4는 조용하다. 소리가 끝나도 저절로 넘어가지 않는다 |
| S3 | 컷 6 | 「봉투 드릴까요?」(`d-01`을 다시 씀) |
| S4 | 컷 3에서 머리 나가기 / (Android) 시스템 뒤로 | 소리가 **즉시** 멈추고 맵 |
| S5 | 마지막 컷 버튼 → `Episode start!` 배너 | 배너 동안 소리가 없다 |
| S6 | 최종 테스트 턴 1 | 상대 줄(「봉투 드릴까요?」)이 자동으로 → 정답 → 정답 효과음과 겹쳐 「아니요, 괜찮아요.」 |
| S7 | 턴 2를 일부러 오답 | 내 줄 소리가 없다. 상대 줄이 아직 나고 있었으면 그대로 이어진다. `Next` → 턴 3의 상대 줄 |
| S8 | 턴 3 정답 | 상대 줄(`d-05`)만 나고 정답 뒤 소리가 없다(`d-06`은 녹음이 없다) |
| S9 | Mac 네트워크를 끊거나 Network Link Conditioner 100 % loss로 앱을 다시 열어 컷 3 · 최종 테스트 | 소리 없이 지금과 똑같이 진행된다. 오류 표시 · 토스트 · 빈 상태가 없다 |
| S10 | 튜토리얼 듣기 문항 · 프롤로그 통화(번들 id) | 지금처럼 들린다(회귀 없음) |

Android(절차만): S1 ~ S4 · S9를 에뮬레이터에서 같은 순서로. TalkBack을 켠 채 S1 — 낭독 동안 대사가 멈췄다 이어진다(기존 동작, [효과음 계약](../specs/ios-sound-effects.md) 접근성 4).
3초 넘는 컷 음성(u02 컷 1 · 3, u03 컷 2)에서 그 조각남이 거슬리는지 기록한다. 계측 두 건은 [Android 오디오 재생 검증](android-audio-playback.md)이 진다.

## 회차 — 2026-10-14, iOS 시뮬레이터, 요청 확인까지

- 대상: `feat/episode-audio`의 `84329513` 직전 구현. iPhone 17 Pro 시뮬레이터. **레슨 판정을 무조건 통과로 바꾼 커밋하지 않은 빌드**를 썼다 — 최종 테스트에 닿으려고 레슨을 실제로 풀지 않았다.
  그래서 이 회차는 레슨 화면의 확인이 아니다.
- 판정 수단: Supabase `edge_logs`. 소리를 귀로 듣지 않았다.

| id | 결과 |
|---|---|
| S1 | 판정 불가: 청음 안 함. `audio/u01-water/pre-3.m4a` 요청을 `AppleCoreMedia`가 내고 206을 받았다 |
| S3 | 판정 불가: 청음 안 함. `audio/u01-water/d-01.m4a` 요청 · 206 |
| S6 | 판정 불가: 청음 안 함. 턴 1에 `d-01`, 정답 뒤 `d-02` 요청 · 206 |
| S7 | 미확인 — 이 회차는 턴 2도 정답으로 풀었다(`d-03` → 정답 뒤 `d-04` 요청) |
| S8 | 판정 불가: 청음 안 함. 턴 3에 `d-05` 요청, 정답 뒤 추가 요청 없음 |
| S2 · S4 · S5 · S9 · S10 | 미확인 |

- **관찰 하나**: 첫 시도에서 턴 2의 `d-03` 요청이 로그에 없었다. 같은 조작을 두 번 다시 했을 때는 재현되지 않았다. 로그 수집 누락인지 재생이 안 된 것인지 가르지 못했다.
- 버킷 쪽은 따로 확인했다 — 공개 URL 14개 전부 200, 바이트 범위 요청 206, `content-type: audio/x-m4a`.

## 미확인

- **실제 청음** 전부 — 들리는지 · 음량 · 효과음과 내 줄의 겹침 체감 · 첫 소리까지의 지연.
- S2(타자기 도중 `Next`의 두 탭) · S4(나가기 즉시 정지) · S5(배너 무음) · S7(오답에 무변화) · S9(오프라인 무음 진행) · S10(튜토리얼 회귀).
- u02 · u03 경로(3초 넘는 컷 음성 여섯 — [ADR-0060](../adr/0060-episode-voice-remote-audio.md) D8), 통과 뒤 컷의 소리.
- iOS 실기의 무음 스위치(켜면 음성이 나지 않아야 한다 — 기본 세션 카테고리) · 다른 앱 음악이 끊기는지.
- VoiceOver(오디오 덕킹 켬/끔)와 녹음의 겹침, 동작 줄이기에서 `Next` 첫 탭이 소리를 멈추는지.
- Android 전부(에뮬레이터 청음 · TalkBack · 계측 두 건).
