# 새 에피소드 형식 ③ — 따라 읽기 · 그림 보고 말하기와 권한 흐름

말하기 두 유형이 화면을 얻은 뒤 카탈로그 레슨이 기기에서 **막히지 않는지**를 확인하는 **수동 절차**다 — `Lesson 5`의 따라 읽기 셋이 문장 · 로마자 · 영어와 마이크로 서는지,
권한 창이 첫 `Speak`에서 뜨는지, 거부하면 막힌 국면(안내 + `Skip`)으로 접히고 같은 활동의 남은 문항도 처음부터 막히는지, `Lesson 6` · `Lesson 8`의 그림 보고 말하기가 그림 · 뜻 · 판정 · 정답 상자로 서는지,
건너뛴 문항이 결과 화면의 건너뜀 수에 들고 레슨 완료를 막지 않는지, 낭독이 무엇을 말하는지.
결정은 [ADR-0064](../adr/0064-episode-format-speaking.md), 화면은 [화면 명세](../screens.md) 「여정 탭」의 따라 읽기 (카탈로그) · 그림 보고 말하기 · 카탈로그 레슨 · 학습 완료 행, 파일 모양은
[콘텐츠 계약](../specs/episode-content-json-contract.md) §7.2가 진다. 인식 접점 자체(권한 상태 · 결과 상태 8종)는 [음성 인식 탐침 e2e](speech-probe.md) · [Android 음성 인식 e2e](android-speech-recognition.md)가 지고 여기서 되풀이하지 않는다.

| 이미 지는 층 | 무엇을 |
|---|---|
| unit | 두 유형의 매핑(출처 묶음 · 판정 순서 · `screen-pending` 0) · 인식 결말 분류(불가 사유 셋 · 받아쓰기 꺼짐 우선) · 활동 안 잠금 · 두 리듀서 · 걸음 · 조작 표 · 보이는 조각(부호) · 낱말 판정 · 그림 로드 전이 · 계획(단계별 표시 · 채점 수) · 통과 분모 · 이벤트 `skippedCount` · 문구 |
| ui | 마이크 부품(상태 셋) · 결선 훅(권한 → 시작 → 결과, 떠나면 멈춤) · 따라 읽기(칠하기 · 안내 줄 · `Try again` · 막힘 · `onFinish` 한 번) · 그림 보고 말하기(로딩 중 `Speak` 없음 · 판정 · 정답 상자 · 자동 넘김 · 사용자 `Skip` · 뜻 줄 비요소 · 판정 알림의 정답) |
| integration | 실제 내장본으로 앱을 띄워 — `S5` 읽기(인식 · 막힘 → `Skip` 셋 → 통과 · 실수 없음) · `S6` 낱말(정답 · 오답 · 거부) · 통과 분모 · 기록 · 이벤트 |

**이 문서만 보는 것**: 실제 권한 창 · 실제 음성 인식 · 기기에서 그려지는 모습(문장 길이 · 칠 · 그림 틀) · 접근성 트리의 이름.

**시뮬레이터 한계**: 마이크는 호스트 Mac의 것이다 · 인식 결과(특히 낱말 하나의 띄어쓰기 · 어미)는 실기와 다를 수 있다 · `restricted` · 인식기 없음은 재현 수단이 없다 · VoiceOver가 없다(접근성 트리 · 검사기로 이름만 본다).
이 자리들은 통과가 아니라 `판정 불가: <수단 없음>`으로 적고 실기 확인을 「미확인」에 남긴다.

## 미확인

- **허용 경로(SPE2)** — 창 둘을 허용하고 호스트 마이크로 실제 문장을 읽어 칠하기 · 맞은 낱말 수 문구 · `Try again`을 본다. 창이 뜨는 **순서**를 적는다.
- **그림 보고 말하기 전부(SPE3 · SPE5)** — 그림 · 뜻 줄 · 로딩 중 `Speak` 없음 · 판정 · 정답 상자 · 자동 넘김 · 사용자 `Skip`. **실제 인식 글자의 모양**(「카드」 · 「비밀번호」가 띄어쓰기 · 어미 · 부호 없이 오는지)을 적어 판정 너그러움(ADR README 보류 표 「말하기 판정의 너그러움」)을 정한다.
- **레슨 결과(SPE4 끝)** — 앞 활동을 맞게 지나 `Skip` 셋 → `LESSON COMPLETE!` · 실수 없음 · `, 3 skipped questions` · 맵에서 `Lesson 6` 열림. 설정 이동 버튼이 없음도 함께 적는다.
- **한쪽만 거부** — 마이크만 · 음성 인식만 거부한 상태. 지금 화면은 둘 다 같은 막힘으로 접는다([ADR-0026](../adr/0026-permission-entry-conditions-and-denial-handling.md) 재검토 조건 — 「하나만 거부된 상태의 처방」은 비어 있다).
- **인식기 없음 · `restricted` · 받아쓰기 꺼짐** — 시뮬레이터에서 재현 수단이 없다(받아쓰기 꺼짐은 설정에서 끌 수 있으면 본다).
- **접근성 수정(`10cd4d0f`)이 든 빌드** — 바뀐 문구 둘(`You said the first …` · `Tap Skip to continue.` — 튜토리얼 말하기의 같은 안내 포함)을 기기에서 본다.
- **VoiceOver 실청취(SPE6)** — 접근성 감사가 「기기에서만 닫힌다」로 남긴 것:
  - 뜻 줄이 따로 읽히지 않는지(고친 뒤에는 `password` 정적 글자가 트리에 없어야 한다).
  - 마이크로 녹음을 멈춰 마이크가 요소에서 빠질 때 포커스가 어디로 가는지. 낱말 말하기에서 주 버튼으로 멈춘 뒤 버튼 행이 사라지고 넘김 층이 설 때 포커스가 그 층에 닿는지.
  - **그림 로딩 중 `Skip`에 포커스를 둔 채 그림이 서면 포커스가 어디로 튀는지**(감사 S3 — 수용 · 셸 후속. 네트워크를 느리게 하거나 첫 진입 때).
  - `Speak`를 누른 직후 VoiceOver 자신의 발화(이름 변경 낭독 · 효과음)가 인식 결과에 섞이는지(앱은 듣기 시작 때 알리지 않는다).
  - 한국어 문장 · 정답 상자(`비밀번호 · bimilbeonho`)를 UI 언어 영어인 VoiceOver가 한국어 음성으로 읽는지 — 오답 알림에도 같은 문자열이 나간다.
  - 따라 읽기에서 `Next`를 눌렀을 때 새 문장이 말없이 바뀌는 것이 세 문장 연속에서 길을 잃게 하는지.
  - 글자 배율 2.0 · 320폭: 17자 문장이 음절 단위로 끊기는지, `Try again` · `Skip` 버튼이 두 줄로 접힐 때 잘리지 않는지.
- **u02 · u03** — 특히 부호가 있는 긴 문장(「미나 씨는 어느 나라에서 왔어요?」)의 칠하기와 u03 `S5-10`(정답 묶음 문장 「Hello, I'm Eunji.」).
