# Android 로그인 후 설정 화면 검증

전용 API 35 Android 에뮬레이터에서 다음을 실행한다. 스크립트가 앱 데이터를 지우고
모의 Supabase 설정으로 번들을 다시 빌드한다.

```sh
E2E_UDID=<전용 에뮬레이터 ID> pnpm test:e2e:android:signed-in
```

Android 계측 픽스처가 저장소에 테스트 세션을 넣고 갱신 요청만 모의한다.
Maestro가 320×640·160 dpi에서 글자 배율 1.0과 1.3을 차례로 적용한다.
첫 사용 안내를 닫은 뒤 접근성 이름으로 `Settings` 탭을 선택하고, 제목·프로필·알림·
피드백·개인정보처리방침·이용약관 항목을 확인한다. 두 배율의 화면을 각각 기준
이미지와 비교한다. 각 배율에서 법률 문서 하나를 선택해 Notion 호스트의 브라우저가
열리고 뒤로가기로 설정 화면에 복귀하는지 확인한다. 고정 URL 경로는
`LegalDocumentModuleTest`가 별도로 검증한다.

API 35 AOSP 에뮬레이터에서 두 배율 모두 Maestro 흐름과 계측 픽스처가 통과했다.
화면 확인에서는 다섯 항목과 하단 탐색이 320×640 안에 보였고 글자 겹침은 없었다.
외부 Notion 페이지는 테스트 브라우저에서 호환 안내로 이동할 수 있어 문서 본문의
로드 성공은 이 흐름으로 판정하지 않는다. 이 픽스처는 실제 제공자 로그인이나 실제
토큰 갱신의 근거도 아니다.
