# 시작 유닛 민서 전화 음성

## 목적 (goal)
기내에서 상상하는 민서와의 통화가 실제 목소리와 대사로 이어지게 합니다.

## 타깃 (target)
[추론] 기존 iOS Lynx 튜토리얼의 초급 사용자. 웹 브라우저 지원 범위는 해당 없음.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 음원이 있는 통화에서 작동하지 않던 음소거·음량 버튼 대신 기존 모양과 토큰으로 일시정지·재개, 다시 듣기를 제공합니다.

## 범위
- 포함(scope_in): 사용자가 다운로드한 두 Mina 음원, 시작 유닛 전화 대사 연결, 실제 재생 완료에 따른 대사 진행, 일시정지·재개·다시 듣기·종료, 다음 기내 방송 장면까지의 미리보기.
- 제외(scope_out): 새 네이티브 API, 음량·믹싱·필터, 추가 유료 생성, 기존 학습 전화 음원 변경.

## 수용 기준 (acceptance_criteria)
1. 두 파일을 AAC mono 44.1 kHz로 인코딩하고 iOS audio 폴더에 넣습니다.
2. 실제 음원이 재생 중인 동안 3초 타이머로 대사를 자르지 않습니다. 재생 완료가 다음 대사를 시작하고 마지막 완료는 Continue를 표시합니다.
3. 다시 듣기는 현재 대사를 처음부터 재생합니다. 나가기·끊기·언마운트는 재생을 중단하고 늦은 완료 신호를 무시합니다.
4. 음원 또는 네이티브 모듈이 없으면 기존 읽기 타이머로 진행합니다. 일시정지 동안 진행하지 않습니다.
5. 관련 UI·전체 여정 테스트, 전체 검증, iOS 번들 자산 검증을 통과합니다.

## 측정 (measurement)
[추론] 기존 시작 유닛 완료·이탈 기록으로 흐름을 확인합니다. 새 이벤트 없음.

## 제약 (constraints)
원본 음원은 로컬 output/audio/minseo-prologue에 보존합니다. 완료 후 다음 서사는 Continue로 직접 엽니다.

## 비고
두 파일은 사용자가 나머지 민서 음원이라고 알려준 다운로드입니다. 대사 배정은 다운로드 시간 순서를 따른 가정이며 질문에 대한 사용자 확인은 아직 없습니다. 모델이 직접 청취·전사한 것은 아닙니다. 타깃·측정·재생 제어는 기존 작업 범위에서 추론한 구현 결정입니다.
