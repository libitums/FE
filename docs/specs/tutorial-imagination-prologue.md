# 작업 스펙: 상상으로 시작하는 튜토리얼

## 목적 (goal)
사용자가 기내에서 한국의 만남을 상상하며 이야기의 주인공이 된 뒤 첫 일반 학습에 들어갈 이유를 얻습니다.

## 타깃 (target)
- 디바이스: [추론] 현재 서비스의 모바일 Lynx 앱 지원 범위를 유지합니다.
- 브라우저 하한: [추론] 네이티브 앱 작업으로 웹 브라우저 지원 확대는 없습니다.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 별도 DESIGN.md가 없어 기존 ui-lynx 컴포넌트와 화면을 기준으로 합니다.
사용자 지시에 따라 생성한 자료에서는 배경만 사용하고 대화 UI는 기존 VisualNovelDialog를 사용합니다.
벗어남: 인물 없는 독백에는 기존 narration 변형을 사용합니다. 배경 모션의 900ms 페이드와
6000ms 확대는 해당 길이의 토큰이 없어 CSS에 명시합니다.

## 범위
- 포함(scope_in): 시작 스페셜의 비주얼 노벨 → 메신저 → 비주얼 노벨 → 전화 → 비주얼 노벨 연결,
  배경 네 장, 장면 전환, 기존 다이알로그 재사용, 완료·나가기·재진입 연결.
- 제외(scope_out): 일반 학습 문항 재작성, 본편 인물 확정, 통화 음성 제작, 미리보기의 별도 UI 이식.

## 수용 기준 (acceptance_criteria)
1. 시작 독백은 기존 VisualNovelDialog를 사용하고 생성한 배경 위에 표시됩니다.
2. 배경은 기내·거리·카페·착륙 직전으로 바뀌며 특정 인물 이미지가 나타나지 않습니다.
3. 메신저 보내기와 전화 완료는 다음 구간으로 이어지고 마지막 구간에서만 완료 화면이 열립니다.
4. 중간에 나가면 완료되지 않으며 재진입은 첫 구간에서 시작합니다. 완료 화면의 기존 잠금 해제를 유지합니다.
5. 기존 단일 형식 프롤로그와 일반 학습 유닛은 기존 동작을 유지합니다.
6. 배경은 홈 인디케이터 뒤까지 채우고 safe area는 한 번만 적용합니다. 메신저 입력창은 하단 safe area 위 8px에 놓입니다.
7. 상상 속 친구는 민서(Minseo)이며 메신저·카페 독백·전화에서 같은 이름을 사용합니다. 본편 인물 확정과는 무관합니다.

## 측정 (measurement)
[추론] 기존 표지 진입·계속·이탈·서사 완료 이벤트로 시작 유닛 완료율을 봅니다.
혼합 서사의 완료 이벤트는 prologueKind: sequence로 식별하며 각 구간 완료로 중복 발행하지 않습니다.

## 제약 (constraints)
Lynx 요소와 opacity·transform 애니메이션을 사용합니다. 이미지 로드 후 전환하고 이전 배경은 전환 완료 뒤 해제합니다.
전화 음성은 기존 화면과 마찬가지로 연결하지 않습니다. 대본·번역은 검토 가능한 초안으로 별도 모듈에 둡니다.

## 시각 레퍼런스 (visual_reference)
대화에서 만든 기내·상상 속 거리·카페·착륙 배경과 사용자 기존 VisualNovelDialog.

## 비고
- [추론] 타깃·제외 범위·측정 방식은 기존 서비스 유지라는 요청 맥락에서 결정했으며 별도 사용자 확인은 받지 않았습니다.
- 이번 구현은 작업분배의 시작 스페셜에 해당합니다. 일반 학습과 응용 스페셜 콘텐츠 작업은 별도입니다.
