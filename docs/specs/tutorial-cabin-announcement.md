# 작업 스펙: B 기내 안내방송 연결

## 목적 (goal)
상상 속 민서와의 만남에서 실제 비행기 안으로 돌아올 때 딩동과 승무원의 기내 방송으로 전환을 느끼게 합니다.

## 타깃 (target)
- 디바이스: [추론] 기존 iOS Lynx 앱 지원 범위.
- 브라우저 하한: 해당 없음 — 네이티브 음원 재생을 사용합니다.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 벗어남: 없음. 기존 기내 배경과 비주얼 노벨 다이알로그를 사용합니다.

## 범위
- 포함(scope_in): 사용자가 선택한 B 음원, 딩동과 방송이 합쳐진 번들 파일, 승무원 장면 진입 재생, 다음 장면·나가기·완료·언마운트 시 중단, 개발용 해당 장면 미리보기.
- 제외(scope_out): 런타임 오디오 필터·믹서·음량 조절, 새 네이티브 API, 다른 인물 음원, 음원 종료 시 자동 넘기기.

## 수용 기준 (acceptance_criteria)
1. 선택한 B 비교본의 딩동 → 0.22초 간격 → 승무원 음성을 하나의 음원으로 재생합니다.
2. 실제 튜토리얼의 승무원 대사에만 새 audioSource를 연결합니다. 무음 서사는 음원을 요청하지 않습니다.
3. 재생 종료만으로 대사를 넘기지 않으며, 사용자가 장면을 넘기거나 나가면 재생을 중단합니다. 늦은 완료 콜백은 진행에 영향을 주지 않습니다.
4. 기존 음원 접점으로 실행하며 네이티브 모듈이 없는 환경에서도 대사를 읽고 완료할 수 있습니다.
5. 관련 수명주기 테스트, 전체 여정 통합 테스트, CI, iOS 앱 번들 음원 해시를 검증합니다.

## 측정 (measurement)
[추론] 기존 시작 유닛 완료·이탈 기록으로 흐름을 확인합니다. 새 이벤트는 추가하지 않습니다.

## 제약 (constraints)
사용자가 선택한 B 효과를 그대로 유지하며 대사와 배경은 바꾸지 않습니다. 음원 종료 시 자동 진행하지 않습니다.

## 시각 레퍼런스 (visual_reference)
기존 tutorial-prologue 기내 복귀 장면.

## 비고
사용자가 B 비교본을 선택했습니다. 재생 수명주기·대사 읽기 유지와 타깃·측정은 선택을 기존 앱에 적용하기 위한 구체화입니다.
