# 작업 스펙: 민서 전화 음원과 자연스러운 주문 표현

## 목적 (goal)
초급 학습자가 민서의 실제 한국어 음성을 듣고 같은 인물과 전화하는 경험을 하며 자연스러운 부탁 표현을 익힙니다.

## 타깃 (target)
- 디바이스: [추론] 기존 iOS Lynx 앱 지원 범위.
- 브라우저 하한: 해당 없음 — 기존 네이티브 음원 파일 교체입니다.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 벗어남: 없음.

## 범위
- 포함(scope_in): 사용자가 생성·대사 확인한 Mina / v4 음원으로 전화 3턴 교체, 첫 음원의 인사·소개 분리, 공유하는 튜토리얼 듣기 음원 교체, 주문·카페·최종 복습의 ‘물 좀 주세요’ 표현과 로마자 통일.
- 제외(scope_out): 추가 유료 생성, 음성 복제, 실시간 ElevenLabs API, 신규 재생 UI·네이티브 메서드, 카페 자동 낭독·격려 음원 재생 연결.

## 수용 기준 (acceptance_criteria)
1. 전화 3개 audioSource ID를 유지하고 각각 ‘안녕하세요’, ‘저는 민서예요’, ‘내일 만나요’ 음원을 연결합니다. 원본 MP3는 보존합니다.
2. 인사·소개 분리는 두 문장 사이의 무음 안에서 수행하며 PCM·AAC 디코딩과 파일 길이를 확인합니다.
3. 튜토리얼 주문·카페·최종 복습에는 ‘물 좀 주세요’와 ‘mul jom juseyo’를 사용합니다. 조합은 ‘물’ + ‘좀 주세요’ 두 조각입니다.
4. 전화 재생·다시 듣기·완료 후 응답, 듣기 공유 경로, 문장 조합과 최종 복습의 기존 테스트 및 CI를 통과합니다.

## 측정 (measurement)
[추론] 기존 전화·듣기·주문 유닛의 완료와 이탈을 확인합니다. 이번 음원 교체로 새 이벤트를 추가하지 않습니다.

## 제약 (constraints)
기존 불투명 audioSource와 네이티브 재생 수명주기를 유지합니다. 사용자가 제공한 네 파일의 대사는 사용자 확인이며 모델의 청취 검수를 뜻하지 않습니다.

## 시각 레퍼런스 (visual_reference)
기존 민서 카페 아트·전화 화면을 유지합니다.

## 비고
타깃·측정은 기존 작업 범위에서 추론했습니다. 사용자가 첫 작업 범위 진행, ‘물 좀 주세요’ 표현, 다운로드한 네 음원의 대사를 확인했습니다. 사용되지 않는 물·격려 원본은 로컬 제작 폴더에 보관합니다.
