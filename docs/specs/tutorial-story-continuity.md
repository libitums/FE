# 작업 스펙: 튜토리얼 서사 연결

## 목적 (goal)
기내에서 시작한 상상의 여정이 민서와의 메신저·전화·카페, 짧은 학습, 최종 복습과 착륙까지 한 이야기로 이어지게 합니다.

## 타깃 (target)
- 디바이스: [추론] 기존 모바일 Lynx 앱 지원 범위.
- 브라우저 하한: [추론] 네이티브 앱이며 웹 지원 확대 없음.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 기존 스페셜·학습·최종 이야기 컴포넌트와 토큰을 사용합니다. 벗어남: 없음.

## 범위
- 포함(scope_in): 중간 스페셜·알림·맵·롤플레이에 보이는 이름과 제목 통일, 상황 설명, 학습 전환 안내, 민서 소개 음원, 전체 여정 미리보기와 검증.
- 제외(scope_out): 문항 수·정답·통과 기준·저장 ID 변경, 새 이미지, 본편 인물 확정, 인증 경로 변경.

## 수용 기준 (acceptance_criteria)
1. 사용자에게 보이는 인물 이름은 Minseo/민서로 통일합니다. 내부 jimin 식별자와 유닛·대사 ID는 호환성을 위해 유지합니다.
2. 중간 메시지와 전화는 기내 상상임을 알리는 설명과 다음 장면 안내를 제공합니다. 카페는 상상 속 다음 날의 방문임을 밝히고 마지막에 다음 학습 순서를 안내합니다.
3. 전화 둘째 턴의 한국어·번역·로마자·실제 음원은 ‘저는 민서예요.’로 일치합니다. 기존 Yuna 테스트 음원 제작 방식을 유지합니다.
4. 듣기·말하기·쓰기 안내와 최종 도입은 같은 민서·카페를 이어받고, 선택적 Skip을 쓴 사용자에게 하지 않은 활동을 했다고 단정하지 않습니다.
5. 시작 서사부터 최종 시험·엔딩·Perfect lesson까지 흐름을 검증합니다. 최종 시험 전에는 결과 화면이 나오지 않고 엔딩 후 기존 결과를 표시합니다.
6. 개발용 전체 여정 미리보기는 진척 0의 실제 AppSession을 사용하고 제품 인증 동작을 바꾸지 않습니다.

## 측정 (measurement)
[추론] 기존 유닛 완료·중도 이탈 기록으로 튜토리얼 완주를 확인합니다. 새로운 이벤트를 추가하지 않습니다.

## 제약 (constraints)
영어 UI·한국어 학습 대사와 로마자를 유지합니다. 내부 ID를 일괄 개명하지 않습니다. 원어민 음성 품질 평가는 별도입니다.

## 비고
사용자가 승인한 네 단계 후속 작업을 구현합니다. 새 제목·상황 설명의 정확한 문구, 타깃·측정은 사용자 요청에서 구체화한 미확인 추론입니다.
