# 튜토리얼 상상 진입 전환

## 목적 (goal)
첫 유닛에서 기내 현실을 떠나 상상 속 한국 골목으로 들어간다는 감각을 장면 전환으로 전달합니다.

## 타깃 (target)
[추론] 기존 iOS Lynx 튜토리얼 사용자. 웹 브라우저는 해당 없음.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 기존 배경과 비주얼 노벨 다이알로그를 유지합니다. 상상 진입에만 약 2초의 기내 확대·따뜻한 빛·골목 정착 연출을 추가합니다. 전용 서사 모션 길이는 기존 토큰에 없으므로 CSS에 근거를 남깁니다.

## 범위
- 포함(scope_in): 첫 VN의 기내→골목 beat에 상상 전환 의미값, 로드 후 시작하는 특수 배경 전환, 명시적 reducedMotion 경로, 실제 첫 유닛 연결과 검증.
- 제외(scope_out): 새 이미지·음원, 대사·다이알로그 교체, 런타임 blur 필터, 반복 섬광, 자동 장면 넘김.

## 수용 기준 (acceptance_criteria)
1. 기내→골목 전환만 특별 연출을 사용하며 기존 다른 장면의 일반 페이드는 유지합니다.
2. 새 이미지 로드 전에는 이전 배경을 보존하고, 주 전환이 끝나기 전 자식 애니메이션 종료만으로 이전 배경을 제거하지 않습니다.
3. reducedMotion은 확대와 빛 효과를 사용하지 않습니다. 이 설정을 OS 설정에 자동 연결했다고 주장하지 않습니다.
4. 빠른 장면 이동과 나가기는 유지하며 전환 종료가 대사·진행을 자동 변경하지 않습니다.
5. 관련 경계 테스트·전체 검증·iOS 시뮬레이터 전환 관찰을 기록합니다.

## 측정 (measurement)
[추론] 기존 시작 유닛의 완료·이탈로 흐름을 확인합니다. 새 이벤트 없음.

## 비고
사용자가 첫 유닛의 상상 진입 느낌 부족을 지적했습니다. 타깃·모션 구성·측정은 기존 제품 흐름을 기준으로 구체화한 결정입니다. 다른 작업의 미커밋 타입라이터·음성 동기화 변경은 독립 작업으로 보존합니다.
