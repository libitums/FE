# 작업 스펙: 상상 뒤에 연습하는 첫 인사

## 목적 (goal)
사용자가 시작 이야기에서 상상한 첫 만남을 위해 인사를 듣고 직접 답하면서 일반 학습의 조작을 익힙니다.

## 타깃 (target)
- 디바이스: [추론] 현재 서비스의 모바일 Lynx 앱 지원 범위를 유지합니다.
- 브라우저 하한: [추론] 네이티브 앱 작업이며 웹 브라우저 지원을 확대하지 않습니다.

## 디자인 (design_ref)
DESIGN.md 표준 따름. 별도 DESIGN.md가 없어 기존 LearningShell·듣기·문장 만들기 화면을 기준으로 합니다.
벗어남: 없음.

## 범위
- 포함(scope_in): [추론] 다음 작업의 첫 단위로 greeting 유닛의 제목·설명과 문장 만들기 세 문항을 시작 이야기와 연결합니다. 미리보기에서 맵 → 듣기 → 문장 만들기를 연결합니다.
- 제외(scope_out): 나머지 일반 유닛·응용 스페셜의 개편, 새 음성 생성, 학습 엔진·채점·보상 규칙 변경.

## 수용 기준 (acceptance_criteria)
1. 첫 일반 유닛은 Your First Hello로 표시되며 듣기 3문항 뒤에 문장 만들기 3문항이 이어집니다.
2. 기존 듣기 문장·오디오 식별자를 유지하고 문장 만들기는 인사·반가움·작별의 답장으로 구성합니다.
3. 첫 조합은 정답 한 조각, 다음 두 조합은 두 조각이며 오답 조각도 제공합니다.
4. 모든 활동을 마친 뒤의 기존 평가·보상·다음 유닛 잠금 해제와 중간 이탈 동작을 유지합니다.

## 측정 (measurement)
[추론] 기존 학습 진행·결과 기록을 바탕으로 첫 일반 유닛의 완료와 정답 결과를 확인합니다. 새 이벤트는 추가하지 않습니다.

## 제약 (constraints)
기존 녹음과 듣기 제시문을 일치시킵니다. 대본은 별도 언어 검수 전 초안입니다.
