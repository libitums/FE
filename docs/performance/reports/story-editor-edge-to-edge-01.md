## 시나리오

- 단계: 메신저 탭 → 내 스토리 「+」 → 색 바탕 또는 사진 바탕 편집 → Aa 쓰기.

## 이 변경이 무엇을 건드렸나

- 사진(`image`)의 자리를 캔버스 안에서 편집 층 전체로 옮겼다. 이미지는 여전히 하나이고 디코드 크기는 화면 크기(aspectFill)다.
- 사진일 때만 위에 `linear-gradient` 층(높이 = 위 인셋 + 120)을 하나 더 그린다. 스토리 보기 머리와 같은 방식이다.
- 단추 배경색, 도구 이름 `text-shadow` 하나, 상태 표시줄 표지 하나(Android 호스트의 기존 트리 순회가 읽는다)를 바꿨다.
