## 시나리오

- 단계: 서버 모드 메신저 목록 진입 → 출처가 `companion_friends`를 읽음(목록에 들어올 때마다 한 번 더) → 보이는 친구가 있으면 목록 맨 위 가로 줄 → 카드 → 프로필 시트 → 「친구 추가」(필요하면 성인 확인 대화상자) → 방이 열리고 `companion-greet`(`trigger: "unlock"`) 한 번 → 목록에 마지막 말 · 안 읽음 1 · NEW.
- 방 머리 아바타 → 프로필 시트(아홉 인물).
- 하지 않은 것: 프레임 시간 · 메모리 계측, 실기 왕복 시간 계측, 화면 확인.

## 이 변경이 무엇을 건드렸나

- 서버 출처를 만들 때와 목록에 들어올 때 RPC 한 번(`companion_friends`)이 는다. 읽는 중이면 겹쳐 부르지 않는다. 성인 확인은 확인할 때만 RPC 한 번(`companion_ack_adult`).
- 목록 스크롤 안 맨 위에 가로 스크롤 줄 하나(카드 최대 넷, 움직임 없음). 목록 줄 아바타에 탭 하나, 방 머리에 아바타 단추 하나.
- 친구 추가는 해금 선톡과 같은 길(서버 호출 하나 · 출처 알림 한 번)이다.
- 공용 체험: 엽전을 쓰지 않은 턴 뒤 지갑 읽기가 덕수쌤 방 밖에서도 일어난다(턴당 최대 한 번, 전과 같은 RPC).
- 다시 켤 때 추가한 친구 방도 열린 방이라 목록 미리보기 기록 읽기(`previewOnStart`)가 그 수만큼 는다.
