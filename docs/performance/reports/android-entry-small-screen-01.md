# Android 진입 작은 화면·문구 대비 — 01

## 실행 조건

- 상태: 미측정 — 렌더링 시간·프레임·메모리 캡처를 수행하지 않았다.
- 대상 commit: `c95cb5aa` 이후 320×640 고정 버튼 표시 순서와 진입 문구 대비 변경.
- 기기: Android 15 API 35 ARM 에뮬레이터, 320×640·160 dpi, 글자 배율 1.0·1.3.
- OS: Android 15.
- Lynx SDK: 4.0.1.
- 빌드: 번들 포함 Android APK.

## 시나리오

온보딩 첫째·둘째 카드와 고정 `Next`, 세 번째 단계 뒤 로그인 화면을 확인했다.
작은 화면에서 카드가 고정 버튼 위에 그려지던 현상을 수정하고, 온보딩·로그인
안내와 약관 일반 문구에 더 높은 대비의 기존 의미 색상을 적용했다.

## 분석 결과

- 320×640에서 `Next`를 세 번 눌러 소셜 로그인 화면에 도달했다.
- 글자 배율 1.0·1.3에서 세 소셜 버튼과 약관 문구가 보였다.
- `fg-neutral-muted` `#555D6D`와 배경 `#FFFDFC`의 계산상 대비는 약 6.53:1이다.
- Android 접근성 트리에서 `Next`와 소셜 버튼 이름은 여전히 누락됐다.
- 렌더링 시간·프레임·메모리 수치는 수집하지 않았다.

## 해석

작은 화면의 시각적 가림과 안내 문구 대비는 개선됐다. 성능 지표는 미측정이므로
추가 그리기 순서가 프레임·메모리에 미친 영향은 판정하지 않는다.

## 결론과 후속

실제 TalkBack 탐색과 Lynx 버튼의 Android 접근성 이름은 호스트에서 별도로
해결해야 한다.
