# 상상 튜토리얼 시작 유닛 — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건

- 상태: 미측정 — 네이티브 화면과 조작을 확인했지만 PerformanceEntry·메모리·Trace를 수집하지 않았습니다.
- 대상 commit: `7c94fe8` 위의 미커밋 작업 트리입니다.
- 기기: iPhone 17 Pro 시뮬레이터.
- OS: iOS 26.5.
- Lynx SDK: 4.0.1, 기존 iOS Host.
- 빌드: Rspeedy 개발 번들의 playground에서 화면을 확인했습니다. 크기는 production 빌드입니다.
- 확인 일시: 2026-09-30.

## 시나리오

시작 유닛을 열어 기내 독백 → 상상 속 거리 → 메신저 보내기 → 카페 독백 → 통화 →
기내 복귀로 진행합니다. 생성한 자료에서는 배경만 가져오고 다이알로그·메신저·통화는 기존 컴포넌트입니다.
인물 얼굴은 표시하지 않습니다.

제품 App의 완료·잠금 해제·이벤트와 단일 형식 호환은 통합 테스트로 확인합니다.
playground는 로그인 없이 실제 화면들을 확인하는 개발용 경로이며 완료 시 맵으로 돌아갑니다.

## 제한 사항

런타임 성능은 미측정입니다. 화면과 조작 확인만 했으며 성능 판정은 하지 않았습니다.
이 기록을 기준선으로 사용할 수 없습니다.

로드가 끝난 그림에만 900ms 페이드와 6000ms의 단발 확대를 적용합니다. 교차 전환 중에는
이전 그림을 유지하고 전환 완료 뒤 해제합니다. 타이머로 매 프레임 React 상태를 바꾸지 않습니다.
기존 전화의 대사 타이머와 메신저의 수신 타이머는 화면을 나갈 때 정리됩니다.

## 결론과 후속

새 의존성이나 크기 상한 확대 없이 혼합 시작 유닛을 연결했습니다. 일반 학습 문항은 변경하지 않았습니다.
실기에서 그림 디코딩 시점의 프레임과 메모리를 측정해야 합니다. 통화 음성은 기존 화면과 같이 아직 없습니다.
원본 캡처·계정 정보·로컬 절대 경로는 이 보고서에 싣지 않았습니다.
