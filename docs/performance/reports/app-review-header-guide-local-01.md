# 상단 젬 칩과 재방문 가이드 — 로컬 검증 — 01

## 실행 조건

- 상태: 미측정 — iOS 렌더링·프레임·메모리 수집은 실행하지 않았다.
- 대상 commit: `49ead081` 위의 작업 트리.
- 기기: Mac 빌드 호스트. 실제 iPhone 및 시뮬레이터 화면 확인은 별도다.
- OS: macOS.
- Lynx SDK: 4.0.1, ReactLynx 0.125.0.
- 빌드: Node 22.23.2, Rspeedy production. 운영 환경변수를 넣지 않은 검증용 빌드.
- 확인 일시: 2026-10-01.

## 시나리오

여정·롤플레이·설정·일반 학습·학습 완료의 상단 바에서 젬 칩과 구매 진입점을 제거한다.
재방문 로그인 후 서버 진행 조회가 지연되거나 실패할 때 신규 사용자 가이드를 표시하지 않는다.
정상 응답과 로컬 미전송 진행을 합친 뒤 기록이 비어 있는 사용자에게만 안내한다.
이야기 장면 진행 기록도 재방문 판단에 포함한다.

## 분석 결과

공통 TopBar의 젬 요소를 렌더에서 제거하고 AppHeader의 구매 화면 연결을 제거했다.
진행 동기화는 유효한 서버 응답을 적용한 뒤에만 초기 조회 완료를 알린다.
실패·잘못된 응답·계정 변경 후 오래된 응답은 초기 조회 완료로 취급하지 않는다.
지연 응답·신규 계정·기존 완료 기록·조회 실패·자동 재시도·미전송 기록에 대한 자동 회귀 검증을 추가했다.
검증 결과:

- `pnpm verify` 통과: 포맷·타입·린트·전체 unit/UI/integration 테스트·정책 검사·모바일/Storybook 빌드·번들 상한 검사.
- Vitest 3,779개 테스트 통과. 재방문 가이드 회귀 8개와 기존 첫 사용자 안내 테스트를 포함한다.
- 로컬 PostgreSQL integration 109개 통과. 샌드박스의 localhost 포트 제한으로 첫 실행이 중단되어 권한을 부여한 뒤 전체 검증을 다시 실행했다.
- 모바일 `main.lynx.bundle`: 1,375,729 bytes. 기존 번들 상한을 변경하지 않았다.
- 신규 이미지·음원·의존성 추가 없음. 구매 화면 연결 제거로 사용하지 않는 코드는 제품 번들에서 제외된다.

## 제한 사항

자동 테스트의 인증·저장소·서버 응답은 대역이다. 실기기의 음성·VoiceOver·레이아웃 및 운영 DB 상태를 증명하지 않는다.
현재 체크아웃에는 빌드된 iOS Host와 Pods가 없어 네이티브 캡처를 실행하지 않았다.
렌더링 성능 수치는 미측정이며 baseline 또는 성능 통과로 해석하지 않는다.

## 결론과 후속

심사 재제출 전 운영 환경변수로 새 번들을 만들고 iPhone에서 젬 칩 숨김 및 기존 계정 재실행을 확인한다.
영향 화면의 네이티브 렌더링·메모리 캡처는 새 Host 빌드에서 후속 확인한다.
