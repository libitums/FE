## 시나리오

튜토리얼의 중간 전화·카페 특별 유닛을 기존 디자인 컴포넌트로 표시합니다. 재생·응답·완료·다시보기와 다음 일반 유닛·최종 복습 해금은 기존 흐름을 유지합니다.

## 분석 결과

- 카페의 임시 불투명 대화 패널을 기존 VisualNovelDialog의 translucent 표면으로 교체했습니다. 배경을 전체 화면으로 확장하고 헤더·대화·버튼에 safe area를 적용했습니다. 여정·롤플레이 모두 같은 화면을 사용합니다.
- 전화에는 기존 CallCaller·CallLineBubble과 Button·RoundButton을 연결했습니다. 대사·로마자·번역과 접근성 이름을 유지하며 시계의 시작·정지·다시보기 초기화를 검증합니다. 1초 시계 갱신은 기존 CallClock 안에 한정됩니다.
- 지정된 시뮬레이터에서 카페·전화 첫 화면을 확인했습니다. 전화 루트가 최소 높이 없이 접히는 문제를 발견해 부모 콘텐츠 높이를 채우도록 수정했습니다. 미리보기도 앱과 같은 높이·배경의 셸을 사용합니다.
- 로컬 캡처: `middle-cafe-designed.png`, `middle-call-designed.png`. UI 변경 시점의 캡처입니다. 아래 아트 교체 후 `middle-cafe-matched-art.png`로 카페 합성을 다시 확인했습니다. 음원은 추가하지 않았습니다.

- 포맷·타입·린트, 워크스페이스 단위·UI·통합 테스트와 별도 Node 정책 테스트, 프로덕션 빌드·용량·보고서 정책 검사를 통과했습니다. 아이콘 나가기 버튼에 맞춰 기존 통합 테스트를 접근성 이름과 실제 복귀 동작으로 갱신했습니다.
- 프로덕션 번들 1,342.3 kB / 상한 1,353.0 kB, 정적 이미지 8,588.3 kB, UI dist 465.3 kB입니다. 기존 번들 예산을 변경하지 않았습니다.

- 추가 아트 교체: 초반 imagined-cafe와 최종 final-cafe를 참조해 카페 외관, 지민 기본/미소의 세 PNG를 새로 생성했습니다. 기존 temporary 세 파일을 교체하고 관련 import와 치수 계약을 갱신했습니다. 두 인물 PNG의 alpha와 동일 치수 1086×1448을 확인했습니다. 생성 프롬프트는 디자인 문서에 기록했습니다.
- 아트 교체 후 관련 단위·UI·튜토리얼 통합 테스트 11파일 70개, 포맷·모바일 타입·린트, 모바일 프로덕션 빌드·용량 검사를 통과했습니다. 정적 이미지 총량은 교체 전 11,404.6 kB에서 8,588.3 kB로 감소했습니다.

## 제한 사항

성능 수치·Android·실제 VoiceOver 낭독은 미측정입니다. 전체 흐름의 수동 탭·실제 통화 오디오 재생은 이번 네이티브 캡처 검증에 포함하지 않았습니다. 완료·다시보기·해금은 자동 UI·App 통합 테스트로 검증합니다.

## 결론과 후속

기존 도입·최종 서사와 같은 대화창·통화 컴포넌트를 중간 스페셜에도 적용합니다. 현재 미리보기는 카페부터 열립니다.
