# 일반 학습 완료 화면 — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건

- 상태: 미측정 — 네이티브 화면·조작만 확인했습니다.
- 대상 commit: `0f880d3c` 위의 미커밋 작업 트리입니다.
- 기기: iPhone 17 Pro 시뮬레이터.
- OS: iOS 26.5.
- Lynx SDK: 4.0.1, 기존 iOS Host.
- 빌드: Rspeedy 개발 번들의 playground.
- 확인 일시: 2026-09-30.

## 시나리오

Your First Hello의 안녕하세요를 선택하고 Check → Next → See results로 이동합니다.
문항과 완료 화면에서 진행 막대, 완료 카드와 하단 버튼의 배치를 확인합니다.

## 분석 결과

- 1/1 문항에서 진행 막대가 100%이며 완료 화면에서도 유지됩니다.
- 완료 화면에서 문제 지시문이 사라지고 토큰 기반 체크 아이콘·완료 제목·설명·문항 수 요약이 표시됩니다.
- 완료 카드는 기존 학습 카드 안에 표시되며 하단 See results와 safe area가 유지됩니다.
- See results 후 playground 맵으로 돌아와 첫 일반 유닛 완료와 다음 유닛 활성화를 확인했습니다.
- 관련 unit/UI 테스트 225개가 통과했습니다. 실제 문항 수 기준 비율·빈 활동·완료 화면·기존 결과 전달과 낭독 호출을 검증합니다.

## 제한 사항

런타임 성능 수치는 미측정이며 프레임·메모리·Trace를 수집하지 않았습니다. 기준선이나 성능 개선의 근거가 아닙니다.
실제 VoiceOver 낭독, Android 화면, 제품의 평가 전환은 이번 네이티브 실행 범위 밖입니다. 제품 라우팅은 기존 자동 테스트로 검증합니다.

## 결론과 후속

진행 막대가 문항 순번과 일치하고 완료 화면이 별도 문항으로 세어지지 않습니다. 다섯 일반 활동에서 공통 완료 카드를 재사용합니다.
