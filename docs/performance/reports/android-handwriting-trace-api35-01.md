# Android 손글씨 안내·판정 성능 기록

## 실행 조건

- 상태: 부분 측정 — Debug APK 크기와 기능 경로를 기록했다. 안내 생성·판정의 응답 시간,
  CPU·메모리는 미측정.
- 대상 commit: `06e1475d` (`origin/main`) 기준 `feat/android-handwriting-trace` 작업 트리.
- 기기: Android 15 API 35 AOSP ARM 에뮬레이터, 390×844·160 dpi·글자 배율 1.0.
- OS: Android 15.
- Lynx SDK: 4.0.1.
- 빌드: Debug APK, 로컬 미리보기 Lynx 번들.
- 실행 회차: 01.

## 시나리오

모의 로그인·진행 데이터로 튜토리얼 쓰기 화면을 열어 `나`의 안내 PNG를 기다린다.
한 획을 그은 뒤 판정 버튼을 누르고 결과 화면을 확인한다. 계측 테스트는 PNG의
불투명 픽셀 수와 판정의 안내 영역이 같은지 확인한다.

## 분석 결과

- Debug APK 크기는 62,746,069 bytes다. 직전 음성 인식 작업의 동일 구성
  62,738,069 bytes보다 8,000 bytes 크다.
- 순수 Java 단위 3건, Android 계측 3건, Maestro 1건이 통과했다.
- 전용 에뮬레이터에서 안내 글자 표시·획 입력·판정 전이가 확인됐다.
- 안내 생성·판정의 응답 시간, 반복 입력 시 메모리, 실기 배터리 사용량은 측정하지 않았다.

## 해석

APK 크기와 기능 연결만 확인됐다. 안내 생성·판정의 지연과 메모리 비용은 미측정이므로
이 기록으로 성능 영향을 판정할 수 없다.

## 결론과 후속

글꼴·손글씨가 다른 실제 기기에서 응답 시간과 메모리 사용량을 재고, 기존 문턱값의
통과율·오탐률을 함께 조정해야 한다.
