# 베트남어 UI (문구표 · 콘텐츠 번역표 · 강조 글꼴) — 미측정 — 01

## 시나리오

- 번들 크기: 같은 회차에 기준(`feat/content-level-3`)과 이 변경을 같은 설정으로 빌드해 견줬습니다.
- 런타임: 미측정 — 언어가 바뀔 때 카탈로그 전체에 번역을 한 번 적용하는 비용(`localizeCatalog`, 메모)을 실기에서 잴 후보로 남깁니다.

## 이 변경이 무엇을 건드렸나

- 순수 함수: 번역표 정규화(episode-core) · 에피소드 영어 칸 바꾸기 · 앱 뿌리 클래스.
- 문구: 베트남어 문구표(영어와 같은 모양의 완전한 표)와, 화면에 하드코딩돼 있던 영어를 옮긴 새 구획.
- 결선: `AppSession`이 UI 언어로 카탈로그를 한 번 바꿔 아래로 내립니다.
- 호스트: League Spartan 글꼴 파일 하나(92 KB, 앱 크기) — Lynx 번들 크기와 무관합니다.

## 해석

- 늘어난 몫은 베트남어 문구 문자열이 번들에 실린 것입니다. 언어별 표는 앱 시작 때 한 번 지어 두므로(같은 언어면 같은 객체) 렌더마다 생기는 비용은 없다고 보지만 재지 않았습니다.
- 번역 적용은 에피소드를 통째로 복사하는 걸음입니다. 번역표가 있는 에피소드만 복사하고 같은 (카탈로그, 언어)는 메모로 다시 쓰지만, 에피소드 열 개 이상에서 언어를 바꾸는 순간의 시간은 실기 자료가 없습니다.

## 결론과 후속

- 미측정이며 이 기록은 성능 판정이 아닙니다.
- 후속: 번역표가 실린 콘텐츠가 버킷에 오른 뒤, 베트남어 첫 실행의 지도 진입 시간을 영어와 견줍니다.
