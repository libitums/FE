# Android 음성 인식 호스트 성능 기록

## 실행 조건

- 상태: 부분 측정 — Debug APK 크기와 서비스 부재 기능 경로만 기록했다. 실제 인식 지연·CPU·메모리는 미측정.
- 대상 commit: `0caa2763` (`origin/main`) 기준 `feat/android-speech-recognition` 작업 트리.
- 기기: Android 15 API 35 AOSP ARM 에뮬레이터, 390×844·160 dpi·글자 배율 1.0.
- OS: Android 15.
- Lynx SDK: 4.0.1.
- 빌드: Debug APK, 로컬 미리보기 Lynx 번들.
- 실행 회차: 01.

## 시나리오

모의 로그인·진행 데이터로 말하기 학습을 열고 Android 마이크 권한을 허용한다.
인식 서비스가 없는 기기에서 사용 불가 안내로 전환되는 경로를 Maestro로 확인한다.

## 분석 결과

- Debug APK 크기는 62,738,069 bytes다. 직전 완료 안내 작업 빌드보다 6,633 bytes 크다.
- 단위 3건, 계측 2건, Maestro 1건이 통과했다.
- 이 AOSP 이미지에는 `android.speech.RecognitionService`가 없으므로 실제 인식
  시작·완료 지연과 메모리·CPU 사용량은 측정하지 않았다.

## 해석

권한 창과 서비스 부재 처리의 기능 경로는 확인됐다. 한국어 전사 성능과
온디바이스 모델 실행은 이 기록으로 판정할 수 없다.

## 결론과 후속

서비스가 없는 AOSP 기기에서 말하기는 건너뛰기 가능한 상태로 끝난다. 배포 후보
기기에서 한국어 음성 인식의 응답 시간·콜백 수·온디바이스 보장을 측정한다.
