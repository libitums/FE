# 메신저 생년 시트를 목록 가운데에서 열기 — 01

## 실행 조건

- 상태: 미측정 — 렌더링 · 메모리 캡처(`performance:capture`)를 돌리지 않았습니다.
- 기능 PR: #659 (`fix/age-picker-default`)
- 대상 commit: `32a7e959` 위의 변경
- 기기: iPhone 17 Pro 시뮬레이터(iOS 26.5) · Pixel 8 에뮬레이터 — 화면 확인만, 측정하지 않음
- OS: 위와 같음
- Lynx SDK: 4.0.1
- 빌드: iOS Host Debug + 시트만 그린 임시 번들, Android `assembleBundled` + 같은 임시 번들

## 시나리오

- 없음. 생년 시트가 열릴 때 스크롤 칸의 첫 자리만 바뀝니다(맨 위 올해 → 목록 가운데, 고른 연도가 있으면 그 연도).

## 이 변경이 무엇을 건드렸나

- `scroll-view`에 `initial-scroll-to-index` 하나를 줍니다. 값은 시트를 처음 그릴 때 한 번 계산합니다(배열 `indexOf` 한 번, 101개).
- 그리는 줄 수(101줄)와 시트 구조는 그대로입니다. 호스트 코드는 바뀌지 않았습니다.

렌더링 · 메모리 값은 **없습니다** — 재지 않았습니다.

## 해석

- **미측정 기록입니다.** 측정 한계: 처음 스크롤 자리만 바뀌어 그리는 양은 같다고 보지만 재지 않았으므로 판정하지 않습니다.
- 두 플랫폼 화면에서 시트가 가운데 연도(1978 ~ 1974)로 바로 열렸습니다. 위로 밀면 새 연도까지 올라갔습니다.

## 결론과 후속

- 미측정이며 이 기록은 성능 판정이 아닙니다.
- 후속: 실기기에서 시트가 열릴 때 스크롤 칸이 맨 위에서 가운데로 튀는 장면이 보이지 않는지 확인합니다.
