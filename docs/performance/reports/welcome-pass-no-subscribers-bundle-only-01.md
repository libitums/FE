## 시나리오

- 번들 크기: 이 변경을 빌드해 `pnpm size:check`로 천장과 견줬다. main 대비 증감은 PR의 번들 크기 댓글(CI)이 잰다.
- 런타임: 요금제 결선이 렌더마다 구독 상태를 한 번 판정한다(권한 줄 수 · 등급 · 티켓 무제한을 보는 비교 셋). 새 요청 · 타이머 · 화면 · 애니메이션은 없다. 기기에서 재지 않았다.

## 이 변경이 무엇을 건드렸나

- 순수 함수 둘(`subscriptionStateOf` · `welcomeTicketUntilMs`)과 `welcomePassOf`의 인자 하나.
- 결선: `use-plans`가 구독 상태를 내고, `use-map-notices`가 그것을 첫날 결선에 넘긴다.
- 새 컴포넌트 · 문구 · 의존성 · 미디어 · 네이티브 코드는 없다.
