# 첫날 무제한 티켓 — 번들만 — 01

## 실행 조건

- 상태: 미측정 — 번들만. 렌더링 · 메모리 · 네트워크 캡처를 돌리지 않았다. 화면은 iPhone 17 Pro 시뮬레이터(iOS 26.5)에서 새로 깐 비회원으로 한 번 봤다(성능 값 아님).
- 기능 PR: 첫 실행 뒤 24시간 동안 레슨이 티켓을 쓰지 않는다(비회원 포함). 근거 [ADR-0186](../../adr/0186-first-day-unlimited-tickets.md). 사용자 결정 2026-11-24.
- 대상 commit: 이 보고서와 같은 PR의 첫날 무제한 티켓 브랜치 HEAD
- 기기: 측정 기기 없음(번들 크기만)
- OS: 해당 없음(번들 산출물)
- Lynx SDK: 4.0.1
- 빌드: `pnpm build` 산출 `apps/mobile/dist/main.lynx.bundle`(로컬 설정), 판정은 `pnpm size:check`
- 측정 일시: 2026-11-24

## 시나리오

- 번들 크기: 이 변경을 빌드해 `pnpm size:check`로 천장과 견줬다. main 대비 증감은 PR의 번들 크기 댓글(CI)이 잰다.
- 런타임: 실행마다 진입점에서 저장소 읽기 최대 네 번 · 첫 실행에 쓰기 한 번, 세션이 설 때 읽기 한 번, 이용권이 살아 있으면 끝 시각에 맞춘 타이머 하나.
  새 화면 · 요청 · 애니메이션은 없다. 이 값들은 기기에서 재지 않았다.

## 이 변경이 무엇을 건드렸나

- 새 모듈 둘: 첫날 이용권의 기록 · 판정(`lib`)과 결선 훅(`app`). 시간 한정 이용권의 끝 시각 모듈에 값 하나.
- 결선: `use-map-notices`가 머리 칩의 시간 한정 이용권을 푸시 보상과 합치고, 진입점이 시작 시각을 한 번 적는다.
- 화면은 이미 있는 무제한 칩 · 무제한 모달(timed, ADR-0175)이다. 새 컴포넌트 · 문구 · 의존성 · 미디어 · 네이티브 코드는 없다.

## 제한 사항

- 번들만 쟀고 렌더 · 메모리 · 네트워크는 미측정이다 — 이 수치는 성능 판정의 근거가 아니다.
- 시뮬레이터에서 본 것은 새로 깐 비회원의 지도 머리 무제한 칩과 남은 시간 모달(「24 hours left」 · 「Ends Nov 25」)뿐이다. 레슨 시작 · 24시간 뒤 숫자 칩으로 돌아오는 흐름 · Android는 기기에서 확인하지 않았다(통합 테스트 IT15 ~ IT17의 관찰뿐).

## 결론과 후속

- 미측정이며 이 기록은 성능 판정이 아니다.
- 후속: Android 기기 · 회원 계정에서 첫날 칩 · 모달 · u01 레슨 시작을 확인한다.
