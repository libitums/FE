## 이 변경이 무엇을 건드렸나

- 메인 · 백그라운드 두 스레드에 실리는 것: 학습 화면 셋의 데이터 활동(`ListeningActivity` · `SentenceOrderActivity` · `WordChoiceActivity`), 소리 없는 듣기 프롬프트와
  꺼진 재생 조작, 타자 입력 활동과 리듀서, 카탈로그 최종 테스트 화면과 리듀서, 맵의 유닛 노드, 순수 모듈(문항 매핑 · 섞기 · 활동 구간 · 최종 모델 · 이벤트 만들기),
  결선(`catalog-lesson-wiring.ts` · `catalog-wiring.ts` · `render-catalog.tsx`), 영어 문구, CSS.
- 2026-10-13 수정이 더한 것: 대화 조립 컴포넌트(`SentenceOrderDialogue`)와 CSS, 레슨 전체 카운터(활동 위치 계산), 오디오 없는 듣기 건너뜀 갈래.
  소리 없는 듣기 프롬프트는 실데이터 경로에서 닿지 않게 됐지만 번들에 남아 있습니다(오디오 일부 누락 대비 — ADR-0058 D3).
- 백그라운드만: 최종 테스트 문항(`ROLEPLAY_TURN`)의 엄격 디코드 스키마.
- ui-lynx: 변화 없음.
- 새 이미지 · 음원 · 의존성은 없습니다.
