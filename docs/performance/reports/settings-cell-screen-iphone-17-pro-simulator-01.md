# 설정 화면(ui-lynx 설정 셀) — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건

- 상태: 미측정 — 렌더링 · 메모리 캡처(`performance:capture`)를 돌리지 않았습니다. 번들
  크기만 재었습니다.
- 기능 PR: 설정 화면의 항목 행을 ui-lynx `SettingsCell` · `SettingsGroup`(#132)으로 옮기고, 사용자
  프로필 · 약관의 머리를 동그란 뒤로 버튼으로 맞춘 변경(이 보고서와 같은 PR)
- 대상 commit: `087e330` 위의 작업 트리
- 기기: iPhone 17 Pro 시뮬레이터 — 화면과 스크린리더 구조만 확인했습니다(Lynx Explorer, dev 서버 번들)
- OS: iOS 26.5
- Lynx SDK: 4.0.1 — Explorer 릴리스 기준
- 빌드: 번들 크기는 `pnpm build`의 `main.lynx.bundle`, 화면 확인은 `pnpm dev` 번들입니다.
  Release Host는 빌드하지 않았습니다.

## 시나리오

- 번들 크기: `main`(`087e330`)과 이 작업 트리를 각각 `pnpm build`로 빌드해
  `apps/mobile/dist/main.lynx.bundle` 크기를 비교했습니다.
- 화면 확인: 설정 탭에서 토글 하나를 끄고 사용자 프로필로 이동하는 것을 눈으로 확인했고, 접근성
  트리에서 셀 넷이 각각 버튼으로 서는 것을 확인했습니다. 수치를 남기지 않았습니다.

## 이 변경이 무엇을 건드렸나

- 설정의 항목 행 넷이 앱 컴포넌트 둘(`SettingsNavItem` · `SettingsToggleItem`)에서 ui-lynx
  `SettingsGroup` 둘(계정 · 학습)로 바뀝니다. 그룹마다 상자 · 구분선이 늘었습니다.
- 앱이 `SettingsCell` · `SettingsGroup`과 그 안의 `Avatar`를 처음 싣습니다.

## 해석

- **미측정 기록입니다.** 설정 탭 진입 비용이 달라졌는지 판정할 수 없습니다.
- 번들 증가가 작은 것은 `Avatar`를 에피소드 서사(#134)가 이미 싣고 있고, 앱 컴포넌트 둘과 머리의
  글자 나가기를 걷은 몫이 설정 셀 · 그룹의 몫을 일부 덜어 내기 때문으로 보입니다. 나눠 재지 않아
  근거는 없습니다. 새
  서드파티 의존은 0건입니다.
