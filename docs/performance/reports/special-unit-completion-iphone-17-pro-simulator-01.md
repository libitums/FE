# 중간 서사 완료·재진입 — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건

- 상태: 미측정 — UI와 조작을 확인했으며 프레임·메모리·Trace는 수집하지 않았습니다.
- 대상 commit: `e4fffe33` 위 중간 서사 완료·재진입 수정 작업 트리.
- 기기: iPhone 17 Pro 시뮬레이터.
- OS: iOS 26.5.
- Lynx SDK: 4.0.1, 기존 iOS Host.
- 빌드: Rspeedy 개발 playground와 프로덕션 모바일 빌드.
- 확인 일시: 2026-09-30.

## 시나리오

개발용 초기 진척을 임시로 설정해 실제 AppSession의 카페 서사를 열었습니다. 상대 인사 → Me 인사 → 두 번째 장면 진행을 네이티브 화면에서 확인했습니다. 확인 후 임시 초기값은 원복했습니다.

자동 테스트에서는 메신저 완료 후 첫 메시지부터 다시 풀기, 비주얼 노벨 세 장면의 상대·내 대사와 최종 Continue, 통화 세 답장 후 PERFECT LESSON, 결과 화면의 Check 후 맵·롤플레이 복귀, 완료 기록 보존과 최초 완료 이벤트 중복 방지를 확인했습니다.

## 분석 결과

- 완료 기록과 새 화면 세션을 분리해 메신저·통화의 재진입이 처음부터 시작합니다.
- 비주얼 노벨은 각 장면에 내 응답을 추가했고 마지막 응답을 읽은 뒤 완료합니다. 기존 배경·캐릭터·배치를 유지합니다.
- 통화·비주얼 노벨은 기존 LessonCompleteScreen을 공유하고 Start over 버튼을 제거했습니다.
- 신규 이미지·음원·의존성은 없습니다.
- 프로덕션 모바일 번들은 1,400,358 bytes로 수정 전 1,400,606 bytes보다 248 bytes 줄었으며 기존 상한 1,401,000 bytes를 통과했습니다.

## 제한 사항

개발 시뮬레이터의 일부 화면 확인이며 완료 화면까지의 전체 네이티브 흐름은 자동 테스트로 보완했습니다. 실제 기기 성능, Android, VoiceOver 실제 낭독은 미측정입니다.

## 결론과 후속

중간 서사도 기존 학습 완료 화면과 같은 종료 경로를 사용합니다. 기능 회귀는 자동 테스트로 검증하며 실제 기기 프레임·메모리 측정은 후속 과제입니다.
