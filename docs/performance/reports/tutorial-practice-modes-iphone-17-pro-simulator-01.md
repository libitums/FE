## 시나리오

중간 카페 이야기 → 기존 길 묻기 → 듣기 한 문제 → 인사 따라 말하기 → 나 한 글자 쓰기 → 최종 이야기·복습·엔딩·결과를 검증합니다. 말하기와 쓰기는 명시적 Skip으로 완료할 수 있으며 Perfect 결과에서는 제외합니다.

## 분석 결과

- 실제 앱 배정과 문항으로 듣기 정답·오답, 말하기 인식 성공·권한 거절 후 Skip, 쓰기 빈 입력 차단·성공, 별도 유닛 순서와 최종 해금을 자동 검증합니다. 전체 튜토리얼 통합 테스트는 기존 다섯 연습·스페셜·세 체험·최종 시험까지 진행합니다.
- 지정된 시뮬레이터에서 세 학습 첫 화면을 직접 띄워 안내·번역·발음·두 보기·쓰기 안내 글자·Skip 버튼·safe area를 검토했습니다. 로컬 캡처는 `tutorial-listening.png`, `tutorial-speaking.png`, `tutorial-writing.png`입니다.
- 쓰기의 기존 중첩 화면 루트가 네이티브에서 좁게 접히는 현상을 발견했습니다. 명시적인 세로 flex 루트와 전체 폭으로 수정하고 캡처로 정상 폭을 확인했습니다.
- 한 글자 체험에서는 별도 음절 진행 칸을 생략하여 캔버스와 Skip이 화면 안에 들어오도록 했습니다. 기존 다중 음절 쓰기의 진행 칸은 유지합니다.
- 검토용 시작 상태 변경은 복원했습니다. 미리보기는 듣기부터 열리며 결과 확인 → 맵 → 다음 유닛 → 최종 복습으로 직접 진행할 수 있습니다.
- 프로덕션 번들 1,348.6 kB, 정적 이미지 11,404.6 kB, UI dist 465.3 kB입니다. 앞선 PR #173의 번들 1,340.3 kB 대비 약 8.3 kB 증가했으며, 새 유닛 데이터·초급 안내·선택적 Skip·쓰기 루트 배치가 추가되었습니다. 기존 여유를 유지하도록 실제 증가분을 반영해 JS 상한만 1,344,000 → 1,353,000 bytes로 조정합니다.
- 신규 이미지·음원은 없습니다. 듣기는 기존 `phone-call-confirm-01` 녹음을 사용합니다.

- 포맷·타입·린트, 워크스페이스 단위·UI·통합 테스트, 별도 Node 정책 테스트, 프로덕션 빌드·용량·성능 보고서 정책 검사를 통과했습니다. 기존 맵 개수 기대값을 여덟 일반 유닛·열셋 맵 항목으로 갱신했습니다.

## 제한 사항

성능 수치·Android·실제 VoiceOver 낭독은 미측정입니다. 시뮬레이터에서 전체 흐름을 수동 탭으로 진행하거나 실제 음성·필기 인식 정확도를 평가하지 않았습니다. 화면 배치는 네이티브 캡처로, 인식 결과 전달·권한 거절·완료·해금은 네이티브 모듈 응답을 대역한 App 통합 테스트로 검증합니다.

## 결론과 후속

초급 사용자가 같은 인사와 익숙한 문장 한 글자로 세 학습 방식을 각각 경험할 수 있습니다. 전역 음성·필기 채점 기준은 유지합니다.
