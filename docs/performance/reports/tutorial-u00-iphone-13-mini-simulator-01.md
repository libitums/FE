## 결론과 후속

- 번들은 305.6 kB, 정적 이미지는 4.71 MB 줄었습니다. 옛 튜토리얼 화면과 그림이 빠진 몫이 내장 본문 · 그림 표 · WebP 14장이 더한 몫보다 큽니다.
- 런타임에서 재야 할 것(미측정): 제품 번들(`pnpm bundle:host`)로 새 설치 후 맵이 첫 프레임을 그리기까지의 시간, 표지 컷 전환 · 배너 애니메이션 프레임, 내장 WebP 디코드가 맵 · 표지 메모리에 더하는 몫. `performance:capture`로 잽니다.
- 오프라인(네트워크 차단)에서 제품 번들의 `/static` 그림이 iOS 리소스 · Android `asset:///`로 서는지는 기기 회차에서 봐야 합니다 — 이번 관찰은 개발 서버가 그림을 HTTP로 내준 것입니다.

## 제한 사항

- 빌드 표본은 commit마다 1회입니다. 같은 설정(.env.local 없음)으로 쟀지만 운영 설정은 note 기록상 약 +189 bytes 큽니다.
- 화면 관찰은 개발 번들 · 플레이그라운드의 임시 결선입니다. 서버 진행 불러오기 · 티켓 원장 · 음성 · 머리 칩이 빠져 있어, 실제 앱의 첫 실행과 같은 경로가 아닙니다. 위 시간은 성능 판정의 근거가 아니며 기준값이 아닙니다.
- 렌더링 · 메모리 · 화면 전환 시간 · 애니메이션 프레임 · Android는 미측정입니다.
