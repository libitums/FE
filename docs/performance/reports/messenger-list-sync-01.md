## 시나리오

- 없음(미측정). 앱이 앞으로 올 때 · 연결이 돌아올 때 · 목록 화면에 들어올 때 · 내 스토리 답이 늘었을 때 목록 요약
  (`companion_list_characters`) 한 번 + 서버 마지막 메시지가 바뀐 닫힌 방 수만큼 기록 읽기가 더해졌습니다. 주기 읽기(폴링)는 없습니다.
- 처음 켤 때는 요약 한 번을 먼저 읽고 대화가 있는 방만 미리 읽습니다 — 대화 없는 방의 기록 읽기가 빠집니다(인물 9명 기준 최대 9 → 대화
  있는 방 수).

## 이 변경이 무엇을 건드렸나

- 배경 스레드의 출처 코드(요약 해석 · 바뀐 방 고르기 · 인물별 맞춘 값 지도 하나)와 목록 화면의 마운트 효과 하나. 그리는 일은 바뀌지
  않았고, 다시 읽은 방은 지금의 앞에서 받은 푸시(`pullRoom`)와 같은 길로 한 번 갱신됩니다.
