# 초급 이야기·최종 복습 — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건

- 상태: 미측정 — 화면·조작 검증이며 성능 수치는 수집하지 않음.
- 기기: iPhone 17 Pro 시뮬레이터.
- OS: iOS 26.5.
- Lynx SDK: 4.0.1.
- 빌드: Rspeedy 개발 playground, 새 전화 음원을 포함한 Debug Host.
- 대상 commit: `426820c` 위 codex/tutorial-story-review 작업 트리.
- 일시: 2026-09-30.

## 시나리오

메신저의 두 안내 답장, 전화의 세 재생·답장, 카페의 세 장면, 최종 복습의 세 선택 문항을 순서대로 확인합니다. 별도 App 통합 테스트는 진척 0에서 프롤로그·일반 유닛·스페셜·복습·결과 확인·롤플레이 해금까지 검증합니다.

## 분석 결과

- App 전체 여정 통합 테스트가 프롤로그부터 롤플레이 해금까지 통과합니다.
- iPhone 17 Pro에서 메신저 선택·전송·완료와 전화의 3개 음원 재생 종료·답장·완료를 확인했습니다.
- 전화 음원은 대본으로 새로 생성했고 AAC 파일 디코딩 정보를 확인했습니다.
- 카페 배경·인물이 비는 현상을 발견해 Resource/ 접두사를 제거하고 실제 이미지 표시를 재확인했습니다.
- 카페 세 장면과 최종 복습의 뜻·로마자 표시가 잘리지 않는 것을 확인했습니다.
- 성능 수치는 미측정이므로 프레임·메모리 개선 여부는 판정할 수 없습니다.

## 제한 사항

성능은 미측정이며 프레임·메모리 Trace를 수집하지 않아 성능 개선 여부는 판정할 수 없습니다. Android와 실제 VoiceOver 낭독은 미확인입니다. 전화 음원은 기존 macOS Yuna 방식의 테스트 자산이며 전문 성우 콘텐츠는 아닙니다.

## 결론과 후속

중간 스페셜과 최종 복습의 난이도를 일반 유닛의 초급 표현에 맞춥니다. 본 에피소드 1과 서버 콘텐츠 공급 경로는 범위 밖입니다.
