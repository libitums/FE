## 시나리오

- 전제: 앱 데이터를 지우고 픽스처로 로그인한다. 진행은 측정용 임시 인자(저장소에 넣지 않음)로 튜토리얼 표지 · 스텝 둘을 끝낸 상태다. (A) 티켓은 새 설치 기본값 3장. (B) 티켓 원장을 「가득 차는 시각 = 지금 + 2.5시간」으로 심어 0장, 오늘 무료 받기 전.
- 단계(A): 맵에서 `Ordering`(끝내지 않은 레슨)을 눌러 말풍선을 연다(`Start` 옆 티켓 「1」 태그) → 녹화를 켜고 `Start` → 학습 화면이 서면 `×` → `Leave`로 맵 → 티켓 칩을 눌러 모달을 열고 닫는다 → 말풍선을 열고 맵 빈 곳 · 머리 빈 곳을 눌러 닫히는지 본다 → `Your First Hello`(끝낸 레슨) `Start`를 녹화하며 누른다(다시 하기).
- 단계(B): `Ordering` → `Start` → 「Out of tickets」 대화상자 → `Get more tickets`(칩 0 → 1) → 녹화를 켜고 `Start lesson`.
- 관찰 구간: `adb shell screenrecord`(6 Mbps) 5초, 프레임을 60 fps로 뽑았다. 녹화기는 화면이 바뀔 때만 프레임을 쓰므로, 움직임이 이어지는 동안의 프레임 간격(약 17 ms)과 마지막 변화 시각은 실제 시간에 가깝다.
- 하지 않은 것: 동작 줄이기, 연타, 결과 화면 `Try again`.

## 해석

- 칩 pop(1.14) · 숫자 굴림 · 테두리 물듦은 기기에서 보이고 잘리지 않는다. 학습은 움직임이 끝난 직후(약 0.65 초) 열린다 — 새 레슨 `Start`와 대화상자의 `Start lesson` 둘 다 계약대로다.
- 머리 올림과 흰 알약으로 「−1」이 띠에 가리지 않고 띠 위에서도 읽힌다(글자 : 알약 5.46:1, 알약 : 띠 2.59:1). 떨어지며 옅어지는 모양이 시안대로 보인다.
- 재생이 끝나면 머리가 다시 막 아래로 돌아간다 — 칩 탭 · 말풍선 바깥 탭이 평소대로 동작했다.
- 번들이 상한을 5,061 bytes 넘는다 — 상한 조정이 필요하다.
- 한계: 단일 회차 · 에뮬레이터 한 대 · 글자 배율 1.0 · 애니메이션 배율 1. 동작 줄이기(숫자 페이드), 연타, 결과 화면 `Try again`, iOS, TalkBack은 판정할 수 없다. 녹화가 가변 프레임이라 움직임의 매끄러움은 프레임 수로만 봤다. 런타임 성능 값이 없으므로 이 기록은 성능 기준선이나 회귀 통과의 증거가 아니다.
