# 심사 빌드 Plus 노출 숨김 — 로컬 검증 — 01

## 실행 조건

- 상태: 미측정 — iOS 렌더링·프레임·메모리 수집은 실행하지 않았다.
- 대상 commit: `49ead081` 위의 작업 트리.
- 기기: Mac 빌드 호스트. 실제 iPhone 화면 확인은 새 빌드에서 별도다.
- OS: macOS.
- Lynx SDK: 4.0.1, ReactLynx 0.125.0.
- 빌드: Node 22.23.2, Rspeedy production. 운영 Supabase 접속 값을 넣은 Host 번들과 Xcode Release 아카이브.
- 확인 일시: 2026-10-01.

## 시나리오

결제와 유료 롤플레이 콘텐츠가 준비되기 전까지 실제 앱의 롤플레이 탭에 Plus 줄·카드·
안내 창이 나타나지 않아야 한다. 기존 일반 롤플레이는 잠김과 완료 상태에 맞게 유지한다.

## 분석 결과

- 앱의 구획 생성에서 Plus 예고 항목 공급을 끊었다. 카드와 안내 창의 컴포넌트는 이후
  콘텐츠 준비를 위해 남겨 두되, 제품 경로에서는 입력이 없어 렌더되지 않는다.
- 잠긴 에피소드와 완료된 에피소드의 제품 결선 테스트에서 Plus 줄·안내 창이 없고 일반
  롤플레이가 남는 것을 확인했다.
- 관련 integration 테스트 27개 통과, 모바일 타입 검사 통과.
- 운영 Supabase 접속 값을 포함해 `pnpm bundle:host`를 다시 실행했고 번들 크기 예산을
  통과했다. `Buy Gems` 문구가 없으며 로그인 URL·공개 키가 포함된 것을 값 노출 없이 확인했다.
- Xcode Release 아카이브 `Duru 1.0 (4)` 생성 성공. 이 아카이브는 아직 실기기 설치나
  App Store Connect 업로드로 검증하지 않았다.

## 제한 사항

자동 테스트의 인증·진행 데이터는 대역이라 검증 범위에 한계가 있다. 실기기의 렌더링·성능이나 App Store에
제출한 바이너리를 검증한 결과는 아니다. 아카이브는 Apple Development 인증서로
서명됐고 로컬 `codesign --verify`는 신뢰 체인 오류를 반환했다. 배포 서명·업로드 가능 여부는
Xcode Organizer에서 별도 확인해야 한다. 새 아카이브와 실제 iPhone 설치 후 확인한다.

## 결론과 후속

Plus 진입점은 로컬 제품 경로와 자동 테스트에서 숨겨졌다. iOS 렌더링·성능은 미측정이며
성능 baseline 또는 실기 통과로 판정할 수 없다. 새 아카이브를 실기기에 설치해 롤플레이
탭을 확인하고 렌더링·메모리를 후속 측정한다.
