- 상태: 미측정 — 프레임·렌더링·메모리는 재지 않았다. 아래 번들 크기와 기능 테스트만 확인했다.
- 대상 commit: main `5d7a4c9` 위의 이 PR 작업 트리.
- 기기: Mac 빌드 호스트. iPhone 13 mini의 기기 검증은 별도 출시 기록으로 관리한다.

- 기능 PR: 이 보고서를 포함하는 오프라인 학습 날짜 복구·개인정보 선언 PR.

## 시나리오

오프라인 활동 날짜를 사용자별 저장소에 남긴 뒤 재실행·통신 복귀 시 원래 날짜로 보낸다. 서버 응답을 받은 날짜만 지우며 현재 날짜 기준 연속을 표시한다. 늦은 응답·계정 전환·동시 날짜 추가·64일 초과 배치·서버 RPC 미배포를 검증한다. 개인정보 선언은 실제 코드 경로 및 App Store Connect 공개 7개 항목과 대조한다.

## 분석 결과

| 항목 | 기준 main | 변경 후 | 차이 |
| --- | --- | --- | --- |
| main.lynx.bundle | 1,402,356 bytes | 1,403,857 bytes | +1,501 bytes (+0.107%) |
| Supabase·PostHog 운영 설정 포함 번들 | CI와 설정이 다름 | 1,404,046 bytes | CI와 직접 성능 비교하지 않음 |
| 이미지·음원·의존성 | 기존 자산 | 추가 없음 | 변경 없음 |
| 렌더링·프레임·메모리 | 미측정 | 미측정 | 비교하지 않음 |

새 저장소·재전송 로직은 background only 함수와 기존 effect에 연결된다. 실패 시 지수형 대기(최대 60초), 한 번에 한 요청, 최대 64일 배치로 제한한다. 새로운 화면과 자산은 없다. 번들 상한은 측정된 증가분을 반영하여 1,403,000 → 1,405,000 bytes로 조정한다.

회귀 테스트는 기존 훅에서 8개 실패·1개 통과를 확인했고 수정 후 9개 모두 통과했다. 이후 리뷰의 성공 직후 새 날짜 추가 경계도 실패를 재현했고, 수정 후 날짜 복구 10개가 통과했다. PostgreSQL 통합 테스트 109개에는 새 날짜 RPC 13개가 포함된다. 실제 렌더링 성능 판정을 뜻하지 않는다.

## 제한 사항

렌더링은 미측정이다. 기능 테스트와 번들 크기만 검증했다. 네트워크·인증을 모의한 모바일 테스트와 로컬 PostgreSQL 결과는 운영 DB 적용이나 실제 기기 사용 흐름의 성공을 대신하지 않는다.

## 결론과 후속

미측정 보고서다. 번들 증가량만 확인했으며 성능 개선·퇴행을 판정하지 않는다. 새 날짜 RPC를 운영 DB에 먼저 적용해야 한다. 공개 개인정보처리방침 보완 문안과 아직 남은 실기기/TestFlight 확인은 출시 검증 기록을 따른다.
