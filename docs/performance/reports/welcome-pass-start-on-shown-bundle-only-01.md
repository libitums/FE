## 시나리오

- 번들 크기: 이 변경을 빌드해 `pnpm size:check`로 천장과 견줬다. main 대비 증감은 PR의 번들 크기 댓글(CI)이 잰다.
- 런타임: 첫날 결선이 렌더 뒤마다 저장소 값 둘(창 기록 · 가입 보상 기록)을 더 읽는다(첫날 결선이 이미 세션을 읽던 자리). 창이 처음 설 때 저장소에 한 번 쓴다. 새 요청 · 타이머 · 화면 · 애니메이션은 없다. 기기에서 재지 않았다.

## 이 변경이 무엇을 건드렸나

- 순수 함수 넷(`welcomePassStartFrom` · `welcomePassOnShown` · `signupWindowAhead` · `welcomePassShownFrom`)과 기기 기록 하나(가입 보상 창이 처음 선 시각, 계정마다).
- 결선: 첫날 이용권 · 가입 보상 · 지도 안내 훅.
- 새 컴포넌트 · 문구 · 의존성 · 미디어 · 네이티브 코드는 없다.
