# Android FCM data 메시지 전송 성능 기록

## 실행 조건

- 상태: 부분 검증 — 요청 구성 및 서버 계약 테스트만 실행. 실제 FCM 발송·기기 수신 지연은 미측정.
- 대상 commit: `1eb2d7f0` (`origin/main`) 기준 `fix/push-fcm-data-only` 작업 트리.
- 기기: 사용하지 않음 — 서버 전송 계약 테스트.
- OS: macOS 로컬 테스트 호스트.
- Lynx SDK: 적용 대상 아님 — 서버 요청 형식만 변경.
- 빌드: Node 22 단위·통합 테스트. Firebase 프로젝트 및 서비스 계정 미설정.
- 실행 회차: 01.

## 시나리오

APNs와 FCM 기기를 한 요청에서 발송하고 FCM HTTP v1 payload를 검사한다. FCM 발송은 테스트 대역으로 처리한다.

## 분석 결과

- 단위 4건과 send-push 통합 25건이 통과했다.
- FCM 요청의 `notification` 필드를 제거하고 `data`에 제목·본문·닫힌 목적지를 넣었다. Android 우선순위는 `HIGH`로 설정했다.
- 네트워크 지연, CPU, 메모리, 실제 기기 수신 시간은 측정하지 않았다.

## 해석

서버의 기기 조회, OAuth 횟수, APNs 경로는 기존 계약을 유지한다. 실제 배달·수신 시간은 미측정이므로 성능 영향을 아직 판정할 수 없다. Firebase 설정과 Android 앱 등록 후 계측한다.

## 결론과 후속

로컬 요청 계약은 통과했다. Firebase 구성 후 데이터 메시지의 배경 수신과 알림 게시 시간을 실기에서 측정한다.
