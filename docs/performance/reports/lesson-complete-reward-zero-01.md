# 레슨 완료 화면의 맵 복귀 라벨 — 01

## 실행 조건

- 상태: 미측정 — 문구와 복귀 라벨 전달 변경이며 렌더링·메모리는 재측정하지 않았다.
- 기능 PR: 레슨 완료 버튼을 실제 동작에 맞는 Back to map·Back to list로 변경. 앞선 PR의 젬 보상 0은 유지한다.
- 대상 commit: `abbebc00` 위의 작업 트리.
- 기기: iPhone 13 mini 빌드 대상. 이 변경의 화면은 기존 자동 UI·통합 테스트로 확인한다.
- OS: iOS 26.6.2.
- Lynx SDK: 4.0.1.
- 빌드: Rspeedy production 번들, 서명된 Debug Host. Release/TestFlight 검증은 별도다.

## 시나리오

일반 레슨·서사·메신저·최종 복습에서 공유하는 완료 버튼을 목적지에 맞춰 바꾼다. 여정에서는 Back to map, 롤플레이에서는 Back to list를 표시한다. 레슨 통과 또는 만점 화면의 젬 카드는 + 0 REWARD를 표시하며 Back to map 버튼으로 기존 목적지에 돌아간다. 기존 앱에는 레슨 보상으로 젬 잔액을 올리는 경로가 없고, 이 변경도 잔액을 추가하거나 제거하지 않는다.

## 분석 결과

최종 운영 설정 제품 번들은 1,407,416 bytes로, 같은 설정의 변경 전 1,407,178 bytes 대비 +238 bytes다. 기존 상한 1,408,000 bytes 안이다. 새 요소·네이티브 호출·의존성·자산을 추가하지 않았다. 전체 기능 테스트 3,775개와 타입·린트·포맷·제품/Storybook 빌드·번들 크기·정책 검사를 포함한 pnpm verify를 통과했다. 기존 롤플레이 통합 테스트에서도 맵·목록 복귀 라벨을 함께 확인한다.

## 제한 사항

렌더링 시간·메모리는 미측정이므로 성능 개선이나 통과를 주장하지 않는다.

## 결론과 후속

성공 화면은 보상 0과 실제 목적지의 복귀 라벨을 표시하고, 기존 완료·재시도 라우팅은 유지한다. 복귀 목적지를 라벨에 전달하며 기존 라우팅은 바꾸지 않았다. Release/TestFlight 확인은 별도다.
