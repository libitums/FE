# 유닛 표식 탭 — Android에서 눌림 이동이 탭을 취소함 — 01

## 실행 조건

- 상태: 미측정 — 렌더링 · 메모리 캡처(`performance:capture`)를 돌리지 않았습니다.
- 기능 PR: `SpecialUnit` · `LearningUnit`의 시각 층이 터치를 받지 않게 해 Android에서 탭이 취소되지 않게 하는 변경(이 보고서와 같은 PR)
- 대상 commit: `main` 위의 `fix/unit-badge-tap-android`
- 기기: 갤럭시 S25(SM-S931N) — 탭 성공 여부만 봤습니다.
- OS: Android 17
- Lynx SDK: 4.0.1
- 빌드: `bundled` APK(release 설정 · 디버그 서명)

## 시나리오

- 여정 맵의 「Final test」 표식을 3px 움직이며 120ms 누르는 탭(`adb shell input swipe`)을 반복했습니다. 사람 손가락의 미세한 움직임을 흉내 낸 것입니다.

## 이 변경이 무엇을 건드렸나

- `SpecialUnit`의 halo(시각 층 전체) · `LearningUnit`의 visual에 `user-interaction-enabled={false}`. 탭은 움직이지 않는 바깥 상자가 받습니다.
- 그리는 방식 · 눌림 모양(`:active`)은 바뀌지 않습니다.

## 분석 결과

| 조건       | 결과                                                     |
| ---------- | -------------------------------------------------------- |
| 수정 전    | 6 / 6 실패 — logcat `tap failed:false false -1 (Face)` |
| 수정 뒤    | 3 / 3 말풍선 열림                                        |

렌더링 · 메모리 값은 **없습니다** — 재지 않았습니다.

## 해석

- Android Lynx는 누르는 사이 탭 대상이나 그 조상이 속성 변화로 옮겨지면(`[props]`) 탭을 취소합니다. 스페셜 항목의 Face가 눌림에 `translate(5px, 6px)`로 내려가 손가락 아래 아이콘이 옮겨졌습니다. adb의 즉시 탭은 이동 전에 끝나 성공했고, 사람 손가락은 되다 안 되다 했습니다.
- 단일 기기(갤럭시 S25) · 흉내 낸 탭의 결과라 다른 기기와 실제 손가락으로 일반화하려면 확인이 더 필요합니다. 렌더링은 미측정입니다.

## 결론과 후속

- 탭 성공만 확인한 기록이며 성능 판정이 아닙니다.
- 후속: iOS 실기기 탭 확인.
