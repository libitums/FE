## 이 변경이 무엇을 건드렸나

- 문구: 인도네시아어 문구표(영어와 같은 모양의 완전한 표).
- 순수 함수: 언어 목록 · 기기 태그(`in` → `id`) · 번역표 언어.
- 화면: 설정 항목 하나와, 진입 흐름의 언어 선택 화면을 설정 탭 스택에 다시 쓰는 결선.

## 해석

- 늘어난 몫은 문구 문자열입니다. 기준은 전날 같은 설정으로 잰 값이라 같은 회차의 측정이 아니고, 차이는 대략으로만 말할 수 있습니다. 렌더는 미측정이라 이 수치로 성능을 판정할 수 없습니다.
- 언어가 하나 늘 때마다 문구표가 약 40 kB 늘어납니다. 상한까지 남은 여유(약 246 kB)로 보면 언어 여섯쯤에서 문구표를 따로 받는 방식을 검토해야 합니다.

## 결론과 후속

- 미측정이며 이 기록은 성능 판정이 아닙니다.
- 후속: 언어가 셋 이상이 되면 콘텐츠 번역표와 함께 문구표 크기도 다시 봅니다.
