# 시작 유닛 민서 음성 — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건
- 상태: 미측정 — 기능·자산 확인, 성능 추적 없음.
- 대상 commit: d06c9858 위 codex/tutorial-prologue-minseo-voice 작업 트리.
- 기기: iPhone 17 Pro 시뮬레이터.
- OS: iOS 26.5.
- Lynx SDK: 4.0.1.
- 빌드: Rspeedy 개발 playground / Debug Host.
- 일시: 2026-09-30.

## 시나리오
상상 속 민서의 두 대사를 재생하고 일시정지·재개·다시 듣기·끊기 및 완료 후 기내 방송 장면 이동을 확인합니다.

## 분석 결과
재생은 기존 AudioPlaybackModule 접점을 사용합니다. 실시간 필터·믹서·네이티브 API는 추가하지 않습니다. 원본을 자르지 않고 mono 44.1 kHz AAC로 변환합니다. 음원 없는 환경의 3초 읽기 타이머는 유지합니다.

## 제한 사항
대사 배정은 다운로드 순서이며 사용자 확인 대기입니다. 음질·발음은 직접 청취 판정하지 않았습니다. Android·실기·VoiceOver·성능 수치는 미측정입니다.

## 결론과 후속
- `pnpm verify` 전체 통과: 포맷·타입·린트·전체 테스트·빌드·크기·보고서 정책.
- 새 음원 UI 수명주기 테스트 7개, 기존 통화 UI 테스트 14개, 실제 튜토리얼 전체 여정 통합 테스트 통과.
- main 번들 1349.9 / 1353.0 kB, 이미지 8588.3 / 11520.0 kB, UI 패키지 465.3 / 481.0 kB. 예산 변경 없음.
- 독립 Debug Host 빌드 성공. `.app/audio`에 복사된 두 자산의 SHA-256이 저장소 자산과 각각 일치합니다(해시는 자산 명세 참조).
- AAC 메타데이터: 1채널, 44100 Hz, 각각 2.507755초와 2.690612초.
- 시뮬레이터에서 민서 통화의 마지막 대사와 Continue 노출을 확인했습니다. 이후 화면은 사용자 조작으로 맵으로 이동하여 추가 UI 조작을 중단했습니다. Continue 이후 승무원 장면 연결은 전체 여정 통합 테스트로 검증했습니다.
- 실제 소리의 청취 판정과 기기에서 일시정지·재개의 수동 검증은 하지 않았습니다. 네이티브 재생 제어 호출·늦은 완료 무시·무음 환경의 읽기 진행은 자동 테스트로 검증했습니다.
