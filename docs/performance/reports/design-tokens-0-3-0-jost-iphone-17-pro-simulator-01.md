- 상태: 미측정 — 렌더링 · 메모리 캡처(`performance:capture`)를 돌리지 않았습니다. 번들 크기와 화면만 확인했습니다.
- 기능 PR: `@libitums/design-tokens` · `@libitums/icons`를 0.3.0으로 올리고, Accent family의 Jost를 호스트 앱에 넣는 변경(이 보고서와 같은 PR)
- 대상 commit: main `ca18331` 위의 작업 트리
- 기기: iPhone 17 Pro 시뮬레이터 — 화면 확인만 했습니다(Debug 호스트 앱 내장 번들).
- OS: iOS 26.5
- Lynx SDK: 4.0.1
- 빌드: 번들 크기는 `pnpm build`의 `main.lynx.bundle`입니다. Release Host는 빌드하지 않았습니다.

## 시나리오

- 번들 크기: main과 이 작업 트리를 각각 `pnpm build`로 빌드해 비교했습니다.
- 화면 확인: 온보딩 3단계의 Accent 제목(「Just 5 minutes」)이 Jost로 그려지는지 눈으로 확인했습니다. 수치를 남기지 않았습니다.

## 이 변경이 무엇을 건드렸나

- 디자인 토큰 값 — Accent family 순서, 새 token(`color.black` · `opacity` · `brand.gem`). 화면 CSS는 바꾸지 않았습니다.
- 호스트 앱 리소스 — `fonts/Jost.ttf`(134,996 bytes)와 `UIAppFonts` 등록.

## 분석 결과

| 번들 | 크기 |
|---|---|
| main (`ca18331`) | 1,216,338 bytes |
| 이 작업 트리 | 1,216,099 bytes |
| 차 | −239 bytes |

토큰 CSS에 새 변수가 더해졌지만 번들은 오히려 239 bytes 줄었습니다 — 원인(어느 토큰 값이 짧아졌는지)은 따로 보지 않았습니다. 모바일 번들 상한(1,259,000 bytes) 안입니다. 폰트 파일은 Lynx 번들이 아니라 앱 번들에 들어갑니다. 렌더링 · 메모리 값은 **없습니다** — 재지 않았습니다.

## 해석

- **미측정 기록입니다.** 폰트 등록은 앱 시작 때 시스템이 합니다. 첫 화면 렌더 비용에 주는 영향은 재지 않았습니다.
- Accent 글자 폭이 Futura보다 좁아 제목 줄바꿈이 달라질 수 있습니다. 확인한 화면은 온보딩 3단계 하나입니다.

## 결론과 후속

- 번들 −239 bytes, 상한 안. 렌더링 · 메모리는 미측정이며 이 기록은 성능 판정이 아닙니다.
- 후속: Accent를 쓰는 다른 화면(에피소드 헤더 · 롤플레이 카드 · 낱말 고르기)의 줄바꿈을 확인합니다.
