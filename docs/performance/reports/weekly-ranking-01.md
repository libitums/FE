## 해석

- 기능만으로는 천장(5,327,000 B)을 72.9 kB 넘었다. 문구 다섯 언어 · 화면 · CSS가 두 스레드에 겹쳐 실린 몫이 크다.
- `extractStr`(같은 문자열 리터럴을 한 번만 싣기)이 앱 전체에서 102.9 kB를 줄여 천장 안으로 돌아왔다.
- ADR-0169 위로 쌓은 뒤에는 `extractStr`이 이미 켜져 있어 이 기능 몫(+85,244 B, th · my 문구 포함)이 그대로 더해진다. 사용자 결정으로 올린 천장 5,850,000 B 안이다.
- 측정 한계: `extractStr`의 기기 동작(iOS · Android)과 첫 실행 시간 변화는 재지 않았다.
