# Android 로그인 큰 글자 화면 관찰 — 01

## 실행 조건

- 상태: 미측정 — 렌더링 시간·프레임·메모리 캡처를 수행하지 않았다.
- 대상 commit: `e59a4fea`의 로그인 버튼 스타일 변경.
- 기기: API 35 ARM 에뮬레이터, 320×640 세로 화면.
- OS: Android 15.
- Lynx SDK: 4.0.1.
- 빌드: `pnpm bundle:android` 뒤 `assembleBundled`로 만든 로컬 검증 APK.

## 시나리오

시스템 글자 크기 100%와 130%에서 앱을 각각 재실행했다. 온보딩 세 단계를 거쳐
로그인 화면의 소셜 버튼과 약관 링크를 확인했다. 130%에서 Facebook 버튼의 문구가
로고와 겹쳐, 글자 영역에 좌우 여백을 추가한 뒤 두 크기에서 다시 확인했다.

## 분석 결과

- 100%에서는 수정 후에도 세 소셜 버튼의 로고·문구와 약관 링크가 화면에 보였다.
- 130%에서는 Facebook 문구가 두 줄로 접히고 로고와 겹치지 않았다. 세 버튼과
  약관 링크가 320×640 화면 안에 남았다.
- 비교 화면은 [100%](../../e2e/evidence/android-login-font-100.png)와
  [130%](../../e2e/evidence/android-login-font-130.png)에 남겼다.
- 렌더링 시간·프레임·메모리 수치는 수집하지 않았다.

## 해석

시각적 겹침 해소는 확인했다. 성능 수치가 없는 미측정 기록이므로 스타일 변경의
렌더 비용이나 메모리 영향을 판정할 수 없다. 한 에뮬레이터 크기와 두 글자 배율만
확인했으며, 다른 화면 크기와 실제 기기에 일반화할 수 없다.

## 결론과 후속

130%에서 관찰한 로고·문구 겹침을 수정하고 같은 조건에서 다시 확인했다.
실제 전화번호 로그인과 로그인 뒤 화면은 이 시나리오에 포함되지 않았다. 후속으로
다른 화면 크기와 실제 기기의 표시를 확인할 수 있다.
