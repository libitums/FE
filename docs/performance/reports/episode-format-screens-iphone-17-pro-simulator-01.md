## 해석

- 화면 둘 · 부품 둘 · 매핑 셋이 든 변경으로 +45 kB는 3d-1(화면 셋, +58.7 kB)과 같은 크기 단위입니다. 화면 모듈이 메인 스레드에 이중으로 실린 흔적(내장 JSON 중복)은 없었습니다.
- 런타임: 새 활동은 레슨 안에서만 서고 맵 · 부팅 경로에 새 계산은 맵 구획의 문화 키 판별(유닛 문항 유형을 한 번 훑음) 하나입니다 [추론]. 재지 않았습니다.
- 측정 한계: 런타임은 미측정이라 새 두 활동의 첫 렌더 · 문화 단계 열기 시간 · 메모리에 대해서는 아직 판정할 수 없습니다. 번들 수치도 설정별 단일 빌드입니다.

## 결론과 후속

- 결론: 이 commit의 `main.lynx.bundle`은 CI 설정 2,092,614 · 운영 설정 2,092,803 bytes이고, 직전 대비 +45,456 bytes는 전부 새 화면 · 매핑 코드입니다. 상한은 2,094,000 bytes입니다.
- 후속: 문화 카드 · 음절 조립의 첫 렌더 타이밍과 문화 단계 열기 시간, 메모리는 재지 않았습니다. 병합 직전에 main이 앞서 있으면 그 위에서 번들을 다시 잽니다.
