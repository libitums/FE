  크기만 재었습니다.
- 기능 PR: 온보딩 셋째 스텝 카드 안의 상태 표시(`StatusIndicator`)를 ui-lynx `LearningUnit`
  표식으로 바꾼 변경(이 보고서와 같은 PR)
- 대상 commit: `ffe659b` 위의 작업 트리
- 기기: iPhone 17 Pro 시뮬레이터 — 화면 확인만 했습니다(Lynx Explorer, dev 서버 번들)
- OS: iOS 26.5
- Lynx SDK: 4.0.1 — Explorer 릴리스 기준
- 빌드: 번들 크기는 `pnpm build`의 `main.lynx.bundle`, 화면 확인은 `pnpm dev` 번들입니다.
  Release Host는 빌드하지 않았습니다.

## 시나리오

- 번들 크기: 분기점(`ffe659b`)과 이 작업 트리를 각각 `pnpm build`로 빌드해
  `apps/mobile/dist/main.lynx.bundle` 크기를 비교했습니다.
- 화면 확인: 온보딩 첫 스텝에서 `Next`를 두 번 눌러 셋째 스텝에 닿고, 표식이 학습 중에서
  완료로 바뀌는 것을 눈으로 확인했습니다. 수치를 남기지 않았습니다.

## 이 변경이 무엇을 건드렸나

- 셋째 스텝 카드 안의 `StatusIndicator` 하나가 `LearningUnit` 하나로 바뀝니다. 제목 · 메타
  글자는 그대로이고, 표식을 감싸는 상자가 하나 늘었습니다(낭독 가림용).
- `LearningUnit`은 여정 맵이 이미 싣고 있어 새 모듈이 번들에 들어오지 않습니다.

  판정할 수 없습니다.

  사용처가 남아 있는지 나눠 재지 않았으므로 원인을 단정할 근거가 없습니다. 단일 빌드의
  비교입니다.
