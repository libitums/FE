## 이 변경이 무엇을 건드렸나

- 메신저 목록 마운트마다 RPC 하나(`companion_friend_stories`) — 추천 친구 RPC와 같은 때. 못 읽으면 추천 줄 그대로.
- 스토리 그림은 번들에 넣지 않고 버킷에서 읽는다(보기를 열 때 한 장씩). 목록 줄은 그림을 읽지 않는다(아바타만).
- 보기의 진행 막대는 CSS 애니메이션 하나(지금 칸만, 6초, 모션 줄이기면 없음) · 넘김 타이머 하나 — 렌더는 장이 바뀔 때만.
- 본 것 표시는 기기 저장 한 번(장이 설 때). 서버에 쓰지 않는다.
- 서버 chat-send는 `story_id`가 있을 때만 RPC 하나(무료 판정)가 관문 앞에 더해진다 — 모델 호출은 늘지 않는다(지시 한 줄만 길어짐).
