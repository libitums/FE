## 실행 조건

- 상태: 미측정 — 번들만. 렌더링 · 메모리 · 네트워크 캡처를 돌리지 않았다. Android 에뮬레이터(`bundled`, 값 없는 빌드)에서는 요청 0 회귀만 봤다(성능 값 아님).
- 기능 PR: 이미 PostHog로 가는 다섯 이벤트(티켓 소진 · 첫 채팅 · 요금제 보기 · 고름 · 구매 단추)를 Airbridge로도 보낸다. 근거 [ADR-0063](../../adr/0063-airbridge-events.md) 적용 기록 2026-11-24. 사용자 요청 2026-11-24.
- 대상 commit: 이 보고서와 같은 PR의 브랜치 HEAD
- 기기: 측정 기기 없음(번들 크기만)
- OS: 해당 없음(번들 산출물)
- Lynx SDK: 4.0.1
- 빌드: `pnpm build` 산출 `apps/mobile/dist/main.lynx.bundle`(`.env.local` 없이 — CI와 같은 조건), 판정은 `pnpm size:check`
- 측정 일시: 2026-11-24

## 시나리오

- 번들 크기: 같은 조건으로 `origin/main`(`56f8b754`)과 이 브랜치를 빌드해 바이트를 견줬다.
- 런타임: 이벤트가 날 때마다 매핑 한 번(switch · 문자열 결합 · `Number` 한 번)과 호스트 모듈 호출 한 번. 값이 없는 빌드는 호스트 모듈이 없어 매핑도 돌지 않는다.
  새 화면 · 요청 · 타이머 · 애니메이션은 없다. 기기에서 재지 않았다.

## 이 변경이 무엇을 건드렸나

- 매핑(`lib/airbridge-events.ts`)에 다섯 줄, 진입점 조립(`lib/airbridge-events-module.ts`)이 첫 경험 마일스톤을 Airbridge 합성 바깥에서 만든다(PostHog 세션에서 옮김).
- 화면 · 컴포넌트 · 문구 · 의존성 · 미디어 · 네이티브 코드는 바뀌지 않았다.
