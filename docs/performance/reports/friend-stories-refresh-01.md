## 시나리오

- 단계: 메신저 목록을 연 채로 둠 → 5분마다 · 앱이 앞으로 올 때 스토리 RPC를 다시 읽음 → 새 스토리가 줄에 섬. 보기가 열려 있으면 결과를 보류했다가 닫은 뒤 반영.
- 하지 않은 것: 프레임 시간 · 메모리 계측, 서버 RPC 지연, 배터리.

## 이 변경이 무엇을 건드렸나

- 목록이 서 있는 동안 타이머 하나(`setInterval` 5분) — 목록이 내려가면 멈춘다.
- 다시 읽기마다 RPC 하나(`companion_friend_stories`) — 5분에 한 번 + 앞으로 올 때 한 번, 목록이 서 있을 때만. 결과가 오면 목록 한 번 다시 그림.
- 그림은 줄에서 읽지 않으므로(아바타만) 다시 읽기가 그림 내려받기를 늘리지 않는다.
