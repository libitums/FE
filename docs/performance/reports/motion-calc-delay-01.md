- CSS 세 파일의 `animation-delay` 값과 단축 속성 길이 하나만 바뀌었습니다. JS · 렌더 트리는 바뀌지 않았습니다.
- 지연이 생겨 애니메이션이 도는 시간 창이 늘어납니다. 순위는 약 1.3 s, 출시 모달은 약 2 s입니다.
- 주머니 통 튐은 카드가 떠 있는 동안 3 s마다 transform 애니메이션 하나를 돌립니다.
