## 분석 결과

- 표시 이름·제목은 민서로 통일하고 내부 ID는 유지합니다. 상황 설명은 기존 스크롤 또는 헤더 안의 짧은 텍스트이며 새 타이머·미디어·네이티브 모듈은 없습니다.
- 전화 둘째 음원을 기존 macOS Yuna 방식으로 ‘저는 민서예요.’로 교체했습니다. 나머지 음원과 이미지 파일은 유지합니다.
- 실제 AppSession을 진척 0에서 시작하는 개발용 미리보기를 추가했습니다. 제품 번들에는 개발용 진입점이 포함되지 않습니다.
- 기존 전체 여정 통합 테스트에 민서 표시·상황 설명·스페셜 사이 연결을 추가 확인합니다.

## 제한 사항

성능 수치·Android·실제 VoiceOver 낭독과 원어민 발음 평가는 미측정입니다. 자동 검증의 음성 완료·인식 응답은 테스트 대역을 사용합니다. 실제 기기 검증 결과는 아래 결론에 구분해서 기록합니다.

## 결론과 후속

- iPhone 17 Pro / iOS 26.5에서 실제 AppSession을 진척 0으로 시작해 도입, 일반 학습 5개, 메신저·전화·카페, 듣기, 말하기·쓰기 건너뛰기까지 직접 조작했습니다. 진척은 12/13이 되고 최종 시험이 열렸습니다.
- 최종 복습 3문제 정답 후 민서의 인사 → 착륙 → 공항 도착 → 마지막 대사 4장면을 진행하고 Perfect Lesson 결과 화면을 확인했습니다. 사용자가 누를 수 있도록 결과 화면을 열어 두었습니다.
- 전화 3개 음원의 실제 네이티브 재생 완료 후 응답 활성화, ‘저는 민서예요.’ 자막, 통화 종료 및 다음 카페 안내를 확인했습니다. 교체 음원과 설치한 Host.app 내부 파일의 SHA-256은 `24dd5bdf832dc0289608298719ca2ce24460ac9a459e0ea0007edba02caeace1`로 일치합니다. 음원은 macOS Yuna, rate 150, mono AAC 22.05 kHz입니다.
- 카페 마지막 장면을 스크린샷으로 확인했습니다. 긴 연결 문구가 잘리지 않고 인물·다이얼로그와 겹치지 않으며 하단 safe area까지 배경이 이어집니다.
- 듣기 정답은 Perfect Lesson, 말하기·쓰기 Skip은 Lesson Complete로 이어집니다. 마이크 권한 부여·실제 발음 인식·손글씨 입력은 이번 수동 경로에서 수행하지 않았습니다.
- 포맷·타입·린트·단위·UI·통합 테스트와 CI 정책 검사, 프로덕션 빌드가 통과했습니다. 번들 1347.8 kB / 1353.0 kB, 이미지 8588.3 kB / 11520.0 kB, UI 패키지 465.3 kB / 481.0 kB로 예산 안입니다. 메인 번들 잔여 예산은 약 5.2 kB입니다.
