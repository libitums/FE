# 젬 결제 준비 중 안내 — iPhone 17 Pro 시뮬레이터 — 01

## 실행 조건

- 상태: 미측정 — 렌더링 · 메모리 캡처(`performance:capture`)를 돌리지 않았습니다. 번들
  크기만 재었습니다.
- 기능 PR: 젬 구매 화면의 `Pay` · 결제 수단 줄이 「결제 준비 중」 안내를 띄우게 한 변경(이 보고서와
  같은 PR)
- 대상 commit: `main`(`047348d`) 위에 이 변경을 얹은 작업 트리
- 기기: iPhone 17 Pro 시뮬레이터 — 화면 확인만 했습니다(iOS 호스트 앱 Debug, `--bundle-url=main.lynx`).
- OS: iOS 26.5
- Lynx SDK: 4.0.1
- 빌드: 번들 크기는 `pnpm build`의 `main.lynx.bundle`입니다. Release Host는 빌드하지 않았습니다.

## 시나리오

- 번들 크기: `main`(`047348d`)과 이 작업 트리를 각각 `pnpm build`로 빌드해
  `apps/mobile/dist/main.lynx.bundle` 크기를 비교했습니다.
- 화면 확인: 여정 맵 → 젬 칩 → 구매 화면 → `Pay`를 눌러 안내가 구매 화면 위에 뜨는지 눈으로
  확인했습니다. 수치를 남기지 않았습니다.

## 이 변경이 무엇을 건드렸나

- 구매 화면에 Dialog 하나(안내)와 그 열림 상태가 늘었습니다. 안내는 `Pay` · 결제 수단 줄을 누를
  때만 섭니다.
- 젬을 더하던 임시 동작(App의 setter · 머리의 콜백)을 걷었습니다.
- 팩 카드를 `GemPackCard.tsx`로 뗐습니다 — 그리는 것은 같습니다.

- **미측정 기록입니다.** 안내를 여닫는 비용을 판정할 수 없습니다.
- 늘어난 것은 이미 번들에 있는 ui-lynx `Dialog`를 한 자리 더 쓰는 코드뿐이라 새 의존은 0건입니다.

- 후속: 결제 연동이 붙을 때 구매 흐름 전체(구매 화면 열기 · 결제 · 닫기)를 Release Host에서 잽니다.
