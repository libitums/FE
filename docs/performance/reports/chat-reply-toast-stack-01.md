## 이 변경이 무엇을 건드렸나

- 카드가 최대 3장 — 카드마다 타이머 하나 · CSS 애니메이션 하나. 출처 구독은 예전처럼 카드가 떠 있는 동안 하나(장 수와 무관).
- 갈아 끼울 때 그 카드만 다시 마운트된다(key가 바뀜). 다른 카드는 다시 그려도 타이머 · 낭독이 다시 돌지 않는다.
- 리듀서(`replyToastReducer`)는 예전처럼 `background only` — 메인 스레드 번들에 판정 코드를 싣지 않는다.
